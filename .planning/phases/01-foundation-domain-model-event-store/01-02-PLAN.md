<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Config file → Application | .m31a/config.toml is user-writable; malicious config could set dangerous paths |
| Environment variables → Config | M31A_* env vars override config; injection vector if not validated |
| Keychain → Config | OS keychain read at runtime; unavailable keychain falls back to env |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-02-01 | Tampering | Config file path traversal | high | mitigate | Validate EventStore.Path with filepath.Clean + EvalSymlinks; ensure under workspace root |
| T-02-02 | Information Disclosure | API keys in config.toml | critical | mitigate | Config struct has NO APIKey fields; ResolveAPIKeys only reads from env/keychain; SaveWithKeychain strips keys when keychain available |
| T-02-03 | Tampering | Malicious env var injection | medium | mitigate | Validation rejects out-of-range values; enum fields validated against allowlist |
| T-02-04 | Denial of Service | Keychain unavailable blocks startup | low | accept | Cached wrapper with 5min blacklist TTL; falls back to env var with warning |

</threat_model>

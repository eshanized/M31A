## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Domain types → EventStore | Domain mutations serialize to events; malicious payload could exploit JSON unmarshaling |
| Event payload → Projections | Projections consume events; malformed payload could panic projection logic |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-01 | Tampering | Event payload unmarshaling | medium | mitigate | Use json.RawMessage + explicit UnmarshalEventPayload[T]; never unmarshal into interface{}; validate payload structure in projection Apply() |
| T-01-02 | Information Disclosure | Event metadata/tags | low | accept | Metadata contains only schema_version, tags, source — no secrets; secrets never in events (D-03, PERSIST-03) |
| T-01-03 | Denial of Service | Malformed event payload causes panic | medium | mitigate | All unmarshaling in projection.Apply() wrapped with recover(); structured error returned |
| T-01-SC | Supply Chain | github.com/google/uuid | low | mitigate | Package legitimacy verified in RESEARCH.md; pinned version in go.mod |
</threat_model>

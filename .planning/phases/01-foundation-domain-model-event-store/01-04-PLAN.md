- Start goroutine that:
  - Tracks lastSeq = afterSeq
  - Polls every 100ms (configurable via const SubscriptionPollInterval = 100 * time.Millisecond)
  - Calls Query(ctx, Query{AfterSeq: lastSeq, Limit: 100})
  - For each event, send to channel (select with ctx.Done())

Config: Poll interval as constant for now (100ms). Could be made configurable via Config.EventStore.SubscriptionPollMs in future.

| Boundary | Description |
|----------|-------------|
| Backup destination → Disk | Backup writes to user-specified path; path traversal must be prevented |
| Subscription channel → TUI | Events delivered to TUI; malformed event could panic UI |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-01 | Tampering | Backup path traversal | high | mitigate | Validate dstPath with filepath.Clean + EvalSymlinks; ensure under allowed backup directory or user home |
| T-04-02 | Denial of Service | Backup blocks writers | critical | mitigate | Incremental Step(5) + 10ms ticker verified non-blocking; test confirms concurrent appends work |
| T-04-03 | Information Disclosure | Backup contains all events | medium | accept | Events don't contain secrets (PERSIST-03); backup is user-initiated for disaster recovery |
| T-04-04 | Tampering | Subscription delivers stale events | low | mitigate | Monotonic SEQ ensures ordering; lastSeq updated after each delivery |
| T-04-SC | Supply Chain | modernc.org/sqlite backup API | low | mitigate | Verified in RESEARCH.md; standard SQLite online backup |
</threat_model>

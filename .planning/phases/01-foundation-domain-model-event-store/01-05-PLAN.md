Create projection.go with Projection interface and ProjectionManager per RESEARCH.md pattern:

Projection interface:
- Name() string
- Apply(event types.Event) error
- State() any
- Checkpoint() ([]byte, error) — serializes full projected state
- Restore(data []byte) error — restores from checkpoint

ProjectionManager:
- store *SQLiteEventStore
- projections map[string]Projection (protected by sync.RWMutex)
- Register(p Projection) — adds to map
- Rebuild(ctx context.Context, name string) error:
  1. Load last_seq from projections table (SELECT last_seq WHERE name = ?)
  2. Query events from last_seq (store.Query with AfterSeq)
  3. For each event: p.Apply(event); lastSeq = event.Seq
  4. Create checkpoint: data, _ := p.Checkpoint()
  5. UPSERT projections table with name, lastSeq, updated_at (same pattern as RESEARCH.md line 1044-1048)
- GetState(name string) any — returns p.State()

Checkpoint frequency: Per D-13, configurable (default 100 events). For now, Rebuild is called explicitly. Automatic checkpointing on every N events can be added in EventStore.AppendEvents later (Phase 5).

Retention: Per D-16, keep last N checkpoints (default 10). Implement cleanup in Rebuild after successful checkpoint write: DELETE FROM projections WHERE name = ? AND updated_at NOT IN (SELECT updated_at FROM projections WHERE name = ? ORDER BY updated_at DESC LIMIT 10).

Error handling: Wrap all errors with errors.Wrap. Projection.Apply errors include event seq for debugging.

Sentinel errors: ErrProjectionNotFound, ErrProjectionApplyFailed in internal/core/errors/errors.go.

| Event log → Projections | Projections consume events; malicious event could corrupt projected state |
| Artifact writes → Disk | Files written to .m31a/; path validation prevents escape |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-01 | Tampering | Malformed event corrupts projection | medium | mitigate | Projection.Apply validates event payload structure; returns error on invalid data; recover() in projection manager |
| T-05-02 | Tampering | Symlink escape in artifact writes | high | mitigate | fileutil.ValidatePath with EvalSymlinks on both path and workspace root before every write |
| T-05-03 | Information Disclosure | Secrets in projections | low | accept | Projections only contain domain data; secrets never in events (PERSIST-03) |
| T-05-04 | Denial of Service | Large projection checkpoint OOM | medium | mitigate | Checkpoint size bounded by projected state; retention limits count (D-16) |

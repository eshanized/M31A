### Task 4: Fix WebFetch SSRF DNS rebinding TOCTOU (M-4)

**read_first:**
- `internal/tools/webfetch.go`
- `internal/tools/webfetch_security_test.go`

**action:**
Implement a custom `DialContext` on the HTTP client that:
1. Resolves DNS once
2. Checks if the IP is private via `isPrivateIP()`
3. Pins that IP for the connection
4. Re-checks after connect

This prevents TOCTOU races where DNS could be rebinned between the initial check and the actual connection.

**acceptance_criteria:**
- Custom `DialContext` is used for all HTTP requests
- DNS resolution and IP check happen at connection time
- `TestWebFetch_DialContext_IPPinned` passes
- `go test ./internal/tools/...` exits 0

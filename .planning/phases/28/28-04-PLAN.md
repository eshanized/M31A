### Task 5: Extract diffLineStyle helper (L-4)

<read_first>
- internal/tui/diff_view.go (renderSplitView lines 64-83, renderUnifiedView lines 160-190)
</read_first>

<action>
Add to `internal/tui/diff_view.go`:

```go
func diffLineStyle(lineType DiffLineType, th *theme.Theme) (lipgloss.Style, string) {
    switch lineType {
    case DiffAdded:
        return lipgloss.NewStyle().Foreground(lipgloss.Color(th.Success)), "+"
    case DiffDeleted:
        return lipgloss.NewStyle().Foreground(lipgloss.Color(th.Error)), "-"
    case DiffHunk:
        return lipgloss.NewStyle().Foreground(lipgloss.Color(th.Brand)), "@@"
    case DiffHeader:
        return lipgloss.NewStyle().Foreground(lipgloss.Color(th.Thinking)), "++"
    default:
        return lipgloss.NewStyle().Foreground(lipgloss.Color(th.TextSecondary)), " "
    }
}
```

Replace both switch blocks in `renderSplitView` and `renderUnifiedView` with calls to `diffLineStyle`.
</action>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI flags/env → config | Untrusted user input parsed into config structs |
| TOML config file → config.Load | Local file read, could be malicious content |
| OS keychain → API keys | Secrets retrieved from system keyring |
| Provider APIs (OpenRouter/Zen/Nvidia) → LLM responses | External network calls, untrusted responses |
| User input (TUI) → tool execution | Arbitrary commands, file paths, code execution |
| Subagent worktrees → git operations | Isolated git worktrees, filesystem operations |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-01 | Spoofing | config.Load TOML parsing | medium | mitigate | TOML parser validates structure; keychain resolution separates secrets |
| T-01-02 | Tampering | Provider API responses | high | mitigate | Response validation in provider clients; JSON schema for tool calls |
| T-01-03 | Repudiation | Session ledger writes | low | accept | Append-only LEDGER.md; not a security audit log |
| T-01-04 | Info Disclosure | Keychain API key retrieval | critical | mitigate | Keys never logged; cached wrapper prevents repeated D-Bus calls |
| T-01-05 | DoS | Tool dispatcher rate limiting | medium | mitigate | Token bucket per tool; dangerous tools stricter limit; concurrency semaphore |
| T-01-06 | Elevation | Subagent worktree creation | high | mitigate | Worktrees isolated; subagent dispatcher filtered by profile; max subagents configurable |
| T-01-07 | Tampering | Config hot-reload | medium | mitigate | Validation on reload; only specific fields hot-reloadable |
| T-01-SC | Supply Chain | go.mod dependencies | high | mitigate | go.sum verification; vendoring not used but CI verifies checksums |
</threat_model>

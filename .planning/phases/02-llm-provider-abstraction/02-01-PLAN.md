## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User Input → LLM Request | User prompts flow through ChatRequest to provider; no sanitization in this phase (provider handles safety) |
| Provider API Response → SSE Parser | Streaming response from NVIDIA API parsed by SSEParser; malicious oversized lines bounded by sseMaxLineLength=1MB |
| API Key → HTTP Headers | NVIDIA_API_KEY read from env/keychain, passed in Authorization header; masked in logs via BaseClient.APIKey() |

| T-02-02 | Tampering | Provider request body injection | low | mitigate | buildNvidiaBody constructs typed map; no string interpolation of user input into JSON structure |

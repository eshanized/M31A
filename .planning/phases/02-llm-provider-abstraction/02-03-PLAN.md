   - MaxAttempts int (default 3)
   - BaseDelay time.Duration (default 1s)

3. Add retry logic helper: retryStream(ctx, req, doStreamFunc, retryConfig) (*StreamIterator, error)
   - "none": no retry, return error immediately
   - "initial_only": retry only on first chunk failure (connection establishment), max MaxAttempts
   - "full_resume": on mid-stream failure, re-issue request with full context preserved (restart request with exponential backoff), max MaxAttempts
4. Update NewBaseClient to accept StreamRetryConfig parameter (from config).
In nvidia/client.go, openrouter/client.go, zen/client.go:

8. For "full_resume" mode: on any stream failure (including mid-stream EOF), restart the entire request with preserved messages/context up to MaxAttempts with exponential backoff (BaseDelay * 2^attempt).
Per D-13: default initial_only balances UX and cost. Per RESEARCH.md resolution: full_resume restarts request with exponential backoff, preserving context.

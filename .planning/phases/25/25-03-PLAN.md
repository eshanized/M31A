In `internal/tools/permissions.go:115`, `matchAnyParamValue` iterates parameter values but doesn't recurse into nested maps/slices. Add type-guard recursion:

```go
func matchAnyParamValue(params map[string]any, pattern string) bool {
    for _, v := range params {
        if matchValue(v, pattern) {
            return true
        }
    }
    return false
}

func matchValue(v any, pattern string) bool {
    switch val := v.(type) {
    case string:
        matched, _ := doublestar.Match(pattern, val)
        return matched
    case map[string]any:
        for _, inner := range val {
            if matchValue(inner, pattern) {
                return true
            }
        }
    case []any:
        for _, item := range val {
            if matchValue(item, pattern) {
                return true
            }
        }
    default:
        // int, bool, etc. — stringify for matching
        s := fmt.Sprintf("%v", val)
        matched, _ := doublestar.Match(pattern, s)
        return matched
    }
    return false
}
```

2. Import `fmt` and `doublestar` if not already imported.
</action>

func extractJSONObject(s string) (string, error) {
    dec := json.NewDecoder(strings.NewReader(s))
    
    // Skip to the first '{' or '['
    var raw json.RawMessage
    if err := dec.Decode(&raw); err != nil {
        return "", fmt.Errorf("extract JSON: %w", err)

    return string(raw), nil
}

### Task 7: W-32 — Fix WebFetch DNS Double-Resolution

<read_first>
- `internal/tools/webfetch.go` (lines 250-350) — `resolveAndCheck` and `Execute` methods
</read_first>

<action>
In `internal/tools/webfetch.go:280-340`, the URL is resolved twice: once in `resolveAndCheck` and again in `client.Do(req)` via the dialer. Fix by removing the redundant resolution and relying on the dialer's resolver:

1. Remove the `resolveAndCheck` call from `Execute`. The `client.Do(req)` will handle resolution via the transport's dialer.

2. Keep the SSRF protection by configuring the dialer's resolver with IP filtering:

```go
// In Execute, before client.Do:
transport := &http.Transport{
    DialContext: func(ctx context.Context, network, addr string) (net.Conn, error) {
        host, port, _ := net.SplitHostPort(addr)
        ips, err := net.LookupIP(host)
        if err != nil {
            return nil, err
        }
        // Check for private IPs
        for _, ip := range ips {
            if isPrivateIP(ip) {
                return nil, fmt.Errorf("SSRF blocked: %s resolves to private IP %s", host, ip)
            }
        }
        // Connect to first valid IP
        return net.Dial(network, net.JoinHostPort(ips[0].String(), port))
    },
}
```

3. Remove the standalone `resolveAndCheck` function if it's no longer needed.
</action>

</read_first>

<action>
In `internal/provider/cache.go:46-63`, the singleflight deduplication layer is dead code because both clients bypass `cache.Refresh()` with direct `cache.Set()`. Fix by:

1. Add a `singleflight.Group` field to the cache struct:

```go
type ModelCache struct {
    mu       sync.RWMutex
    models   []types.ModelInfo
    lastFetch time.Time
    ttl      time.Duration
    sf       singleflight.Group
}
```

2. In `Refresh()`, wrap the refresh operation in `sf.Do`:

```go
func (c *ModelCache) Refresh(fetchFn func() ([]types.ModelInfo, error)) ([]types.ModelInfo, error) {
    key := "refresh"
    result, err, _ := c.sf.Do(key, func() (interface{}, error) {
        models, err := fetchFn()
        if err != nil {
            return nil, err
        }
        c.mu.Lock()
        c.models = models
        c.lastFetch = time.Now()
        c.mu.Unlock()
        return models, nil
    })
    if err != nil {
        return nil, err
    }
    return result.([]types.ModelInfo), nil
}
```

3. In both OpenRouter and Zen client `FetchModels`, call `cache.Refresh(fetchFn)` instead of bypassing the cache.

4. Import `golang.org/x/sync/singleflight` (verify it's already in `go.sum` or `go.mod`; if not, add it).
</action>

    // Case 3: ErrContextExceeded with autoFallback=false → false
    assert.False(t, IsContextExceeded(ErrContextExceeded, false))
    
    // Case 4: Other error → false
    assert.False(t, IsContextExceeded(errors.New("other"), true))
}

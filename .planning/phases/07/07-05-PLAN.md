    - `"github.com/eshanized/M31A/internal/types"`

    Define types:

    1. `LedgerEntry` struct — fields (all exportable, JSON-tagged for serialization):
       - `SessionID string` — 8-char session ID
       - `Timestamp time.Time` — when the session shipped
       - `Model string` — the model used
       - `Provider string` — the provider used
       - `ProjectType string` — from types.ProjectState.ProjectType (e.g., "go", "node", "python")
       - `GoalKeywords []string` — from ProjectState.Goal, split into individual words
       - `Framework string` — from ProjectState.Framework (e.g., "bubbletea", "express")
       - `TaskCount int` — total tasks in the session
       - `FailedTasks int` — tasks that failed
       - `SkippedTasks int` — tasks that were skipped
       - `CostEstimate float64` — estimated cost of the session (in USD)
       - `DurationMinutes int` — session duration in minutes
       - `CommitCount int` — number of commits made during the session (from git log --oneline)

    2. `Ledger` struct — fields:
       - `mu sync.RWMutex`
       - `path string` — full path to LEDGER.md
       - `entries []LedgerEntry` — parsed entries cache

    3. `LedgerStats` struct — fields:
       - `TotalSessions int`
       - `AvgTaskCount float64`
       - `AvgCost float64`
       - `AvgDurationMinutes float64`
       - `TotalFailedTasks int`
       - `TopFailures []string` — most common failure project types (max 5)
       - `TopFrameworks []string` — most common frameworks (max 5)
       - `ByProjectType map[string]int` — count per project type

    Functions:

    4. `func New(filePath string) *Ledger` — constructor:
       - Ensure directory exists: `os.MkdirAll(filepath.Dir(filePath), 0755)`
       - If file exists, parse it into entries slice
       - Return Ledger with path and entries

    Methods:

    5. `func (l *Ledger) Append(entry LedgerEntry) error` — lock mu.Lock:
       - Dedup: check if SessionID already exists in entries; if so, skip (return nil)
       - Append to in-memory slice
       - Marshal entry to markdown row: "| {SessionID} | {Timestamp} | {Model} | {ProjectType} | {TaskCount} | {FailedTasks} | {CostEstimate:.2f} | {DurationMinutes} |"
       - Append line to file: open in append mode, write line + newline
       - If file doesn't exist, create it with a header row first: "| Session ID | Timestamp | Model | Project Type | Tasks | Failed | Cost | Duration |\n|---|---|---|---|---|---|---|---|\n"
       - Return error from file operations

    6. `func (l *Ledger) Entries() []LedgerEntry` — lock mu.RLock, return copy of entries slice sorted newest-first by Timestamp

    7. `func (l *Ledger) EntriesFiltered(projectType string, keywords []string, maxResults int) []LedgerEntry` — lock mu.RLock:
       - Filter by projectType (exact match, case-insensitive; if empty, skip filter)
       - Filter by keywords: entry passes if ANY keyword matches in GoalKeywords (substring match, case-insensitive)
       - Sort by Timestamp descending (newest first)
       - Limit to maxResults (if <= 0, default to 5)
       - Return filtered slice
       - If no matches, return empty slice (nil error)

    8. `func (l *Ledger) Stats() LedgerStats` — lock mu.RLock:
       - Compute from all entries
       - TotalSessions = len(entries)
       - AvgTaskCount, AvgCost, AvgDurationMinutes = mean of all entries
       - TotalFailedTasks = sum of all FailedTasks
       - TopFailures: find most common ProjectType values where FailedTasks > 0, take top 5
       - TopFrameworks: find most common Framework values, take top 5
       - ByProjectType: count entries per ProjectType
       - Handle empty entries: return zero-valued Stats (don't panic on division by zero)

    9. `func (l *Ledger) Truncate(maxEntries int) error` — lock mu.Lock:
       - If maxEntries <= 0, default to 100 (from LedgerConfig default)
       - If len(entries) <= maxEntries, do nothing
       - Otherwise, keep the newest maxEntries entries (sort by Timestamp descending, take first maxEntries)
       - Rewrite the entire file with the remaining entries
       - Update in-memory slice

    10. `func (l *Ledger) Reload() error` — lock mu.Lock:
        - Re-read file from disk, re-populate entries slice
        - Useful if file was modified externally

    File format (LEDGER.md):
    ```markdown
    # Cross-Session Learning Ledger

    | Session ID | Timestamp | Model | Project Type | Tasks | Failed | Cost | Duration |
    |---|---|---|---|---|---|---|---|
    | abcdef01 | 2026-05-28T10:30:00Z | claude-sonnet-4-20260514 | go | 10 | 1 | 0.42 | 45 |
    | abcdef02 | 2026-05-27T14:00:00Z | gpt-4o-2026-05-06 | node | 5 | 0 | 0.15 | 20 |
    ```

    Parse method `func parseEntry(line string) (LedgerEntry, error)`:
    - Strip leading/trailing whitespace
    - Split by "|" delimiter
    - Expect 9 fields (including leading/trailing empty fields from markdown table syntax)
    - Parse each field: SessionID, Timestamp (RFC3339), Model, ProjectType, TaskCount(int), FailedTasks(int), CostEstimate(float64), DurationMinutes(int)
    - Skip lines starting with "#", empty lines, separator lines (contain only "---" and "|")
    - Return error for malformed lines

    Package-level helper `func NewEntry(session types.Session, taskCount, failedTasks, skippedTasks, commitCount int, costEstimate float64) LedgerEntry`:
    - Build a LedgerEntry from a Session struct and summary data
    - GoalKeywords: split session.Project.Goal by spaces, filter common words (a, an, the, and, or, but, in, on, at, to, for, of, with)

<objective>
Build the AutoDream context consolidation engine — automatically compact conversation history when context usage exceeds thresholds.

**Purpose:** Prevent context window overflow during long sessions by summarizing the oldest 50% of messages into a single "memory" segment. This lets the agent stay in long sessions without losing historical context entirely.

    Create `pkg/autodream/autodream.go` in `package autodream` with imports:
    - `"fmt"`, `"math"`, `"sync"`, `"time"`
    - `"github.com/eshanized/M31A/internal/types"`

    Define types:

    1. `ConsolidationResult` struct — fields:
       - `Success bool`
       - `MessagesRemoved int` — count of messages that were consolidated
       - `TokensSaved int` — estimated tokens removed (words × 1.3 per CONTEXT.md formula)
       - `DurationMs int64` — time the consolidation took
       - `Summary string` — the summary text that replaced the oldest messages
       - `Error string`

    2. `Consolidator` struct — fields:
       - `mu sync.RWMutex`
       - `messages []types.Message` — copy of the messages being managed
       - `paused bool`
       - `lastConsolidation time.Time`
       - `totalConsolidations int`

    3. `func New(messages []types.Message) *Consolidator` — constructor:
       - Creates internal copy of messages (don't hold the original reference to prevent mutation)
       - paused = false
       - lastConsolidation = zero time

    Methods:

    4. `func (c *Consolidator) CanConsolidate() bool` — lock mu.RLock:
       - If paused: return false
       - If len(messages) <= 1: return false (nothing meaningful to consolidate)
        - Check if all candidate messages (non-protected) already have segment type "memory" — if no non-"memory" candidates remain, return false
       - Return true

     5. `func (c *Consolidator) Consolidate() *ConsolidationResult` — lock mu.Lock:
        - Start timer
        - Check CanConsolidate (call internally); if false, return result with Success=false and descriptive error
        - Determine which messages to protect (never consolidated):
          a. All system messages (msg.Role == "system")
          b. Last 5 messages (regardless of role)
          c. All tool call messages (msg.ToolCalls != nil and len(msg.ToolCalls) > 0)
          d. First message (initial goal/context) — c.messages[0]
        - Build a set of protected indices using a map[int]bool
        - Remaining messages (not protected) are candidates for consolidation
        - If no candidates remain, return Success=false with "no messages to consolidate"
        - Consolidation target: oldest 50% of candidate messages (len(candidates) / 2) — sort candidates by index ascending, take first half
        - Concatenate target content: `c.rawText(targetMessages)` using candidate message Content
        - Tokens saved: estimate by `len(strings.Fields(rawContent)) * 1.3` (word count × 1.3, per CONTEXT.md spec)
        - Build summary segment: `MessageSegment{Type: "memory", Content: summaryText, Visible: false}`
          where summaryText is: `[AutoDream Context Summary] ` + timeframeDescription(targetMessages) + ` — ` + first 500 tokens of raw content (estimated as `strings.Fields(rawContent)[:int(500/1.3)]`)
        - Create summary message: `Message{Role: "system", Content: summarySegment.Content, Segments: []MessageSegment{summarySegment}, CreatedAt: time.Now()}`
        - Build result: protected messages + summary message + any non-consolidated candidate messages (those not in target)
          `result := append([]types.Message{summaryMsg}, kept...)` where kept = all non-target messages preserving order
        - Update c.messages = result
        - Increment totalConsolidations
        - Capture duration
        - Return ConsolidationResult with Success=true

    6. `func (c *Consolidator) Pause()` — lock mu.Lock, set paused=true

    7. `func (c *Consolidator) Resume()` — lock mu.Lock, set paused=false

    8. `func (c *Consolidator) IsPaused() bool` — lock mu.RLock, return paused

    9. `func (c *Consolidator) Messages() []types.Message` — lock mu.RLock, return copy of messages slice (to prevent external mutation)

    10. `func (c *Consolidator) Stats() map[string]interface{}` — lock mu.RLock, return map with:
        - `"total_messages"`: int — len(messages)
        - `"total_consolidations"`: int
        - `"paused"`: bool
        - `"last_consolidation"`: string (ISO8601 formatted, empty if never)
        - `"estimated_tokens"`: int — rough count from all content: sum(len(strings.Fields(msg.Content)) * 1.3 for msg in messages)

    Helper: `func (c *Consolidator) rawText(msgs []types.Message) string` — joins all Message.Content with newlines

    Helper: `func timeframeDescription(msgs []types.Message) string` — returns "N messages from role1, role2" or "9 minutes ago" based on CreatedAt timestamps. If timestamps missing, returns "N messages" count.

    Edge cases:
    - Protected messages (system, last 5, tool calls, first) overlap with candidates → excluded from consolidation; at least one non-protected message must exist
    - Exactly 1 non-protected message + 5 protected → consolidate that 1 message
    - All messages protected → CanConsolidate returns false (no candidates)
    - 0 messages → CanConsolidate returns false
    - Empty content messages → still consolidate (no crash, tokens saved may be 0)
    - System message at index 0 is both first message and system → protected once

    2. `CommandHandler func(args []string, ctx CommandContext) CommandResult`

     3. `CommandContext` struct — fields: `Registry *provider.Registry`, `SessionManager *session.Manager`, `SessionID string`, `Config *config.Config`, `Dispatcher *tools.Dispatcher`, `Git *git.Git`, `Ledger *ledger.Ledger`, `Rollback *rollback.Rollback`, `AutoDream *autodream.Consolidator`

    4. `CommandRegistry` struct (unexported) — field: `handlers map[string]CommandHandler`, `descriptions map[string]string`
       - `func NewCommandRegistry() *CommandRegistry` — initializes empty maps
       - `func (r *CommandRegistry) Register(name string, handler CommandHandler, description string)` — adds to both maps
       - `func (r *CommandRegistry) Get(name string) (CommandHandler, bool)` — returns handler from map
       - `func (r *CommandRegistry) List() []string` — returns sorted keys
       - `func (r *CommandRegistry) Execute(input string, ctx CommandContext) (CommandResult, bool)` — parses input, finds handler, returns (result, found). If not found, returns CommandResult{Success: false, Message: "unknown command: /foo. Type /help for available commands."}

    5. `func ParseCommand(input string) (name string, args []string, ok bool)` — uses `strings.TrimPrefix(input, "/")` to strip leading `/`, then `strings.Fields()` to split. Returns (name, args, true) if input starts with `/` and has at least a command name. Returns ("", nil, false) if input doesn't start with `/`.

    6. `func DefaultCommands() *CommandRegistry` — factory registering all 16 handlers with descriptions:
       - `/help` → help command "List all available commands"
       - `/clear` → clear command "Clear current conversation context"
       - `/status` → status command "Show current session info"
       - `/model` → model command "Show or switch model"
       - `/provider` → provider command "Show or switch provider"
       - `/reset` → reset command "Reset to first-run screen"
       - `/quit` → quit command "Exit the application"
       - `/undo` → undo command "Restore latest checkpoint"
       - `/compress` → compress command "Trigger context consolidation"
       - `/ledger` → ledger command "Show recent session entries"
       - `/rollback` → rollback command "Show commit chain or reset to commit"
       - `/sessions` → sessions command "List recent sessions"
       - `/goal` → goal command "Set or show session goal"
       - `/phase` → phase command "Show or transition to phase"
       - `/config` → config command "Show or set config value"
       - `/models` → models command "List all cached models"

    7. Implement each handler function in package scope:
       - `handleHelp(args, ctx)`: returns list formatted as `"Available commands:\n  /help — description\n  /clear — description\n  ..."` sorted alphabetically
       - `handleClear(args, ctx)`: returns `{Success: true, Message: "Context cleared."}`
       - `handleStatus(args, ctx)`: returns formatted string with `ctx.SessionID`, phase, model from `ctx.Registry.Active()`, provider, message count, token usage from context
        - `handleModel(args, ctx)`: if no args, show current model from `ctx.Registry.ActiveProvider().GetModel(...)` and hint "Use /model <name> or /models to browse". If args, call `ctx.Registry.Get(args[0])` and show model info. Validate via registry lookup. Returns `{Success: true, Screen: &ScreenModelSelector}` if args is "--selector" to trigger model selector UI from 07-07.
       - `handleProvider(args, ctx)`: if no args, show current via `ctx.Registry.Active()`. If args, call `ctx.Registry.SetActive(args[0])`, return success/error
       - `handleReset(args, ctx)`: returns `{Success: true, Screen: &screenFirstRun, Message: "Resetting to first-run..."}` where `screenFirstRun` is `ScreenFirstRun` as a pointer
       - `handleQuit(args, ctx)`: returns `{Success: true, Message: "Goodbye!"}` (TUI handles quit via tea.Quit based on Message)
       - `handleUndo(args, ctx)`: calls `ctx.SessionManager.LatestCheckpoint(ctx.SessionID)`. If found, returns message with phase/timestamp. If ErrCheckpointNotFound, returns error message
        - `handleCompress(args, ctx)`: if `ctx.AutoDream != nil`, calls `ctx.AutoDream.Consolidate()` and returns result with messages removed/saved. If nil, returns "AutoDream not available"
        - `handleLedger(args, ctx)`: if `ctx.Ledger != nil`:
          - `/ledger stats` subcommand: calls `ctx.Ledger.Stats()`, returns formatted aggregates (avg tasks, total cost, top failures, top frameworks)
          - `/ledger <projectType>` subcommand: calls `ctx.Ledger.EntriesFiltered(projectType, nil, 5)`, returns formatted entry rows
          - No args: calls `ctx.Ledger.Entries()`, returns last 5 entries as formatted list
          - If `ctx.Ledger` nil: returns "Ledger not available"
        - `handleRollback(args, ctx)`: if `ctx.Rollback != nil`:
          - No args: calls `ctx.Rollback.Chain()` (returns last 10 commits), renders as commit list with `[HEAD]` marker on first
          - `/rollback <hash>`: calls `ctx.Rollback.Rollback(hash, false)` for soft reset, returns result with "N commits undone" message
          - `/rollback --hard <hash>`: calls `ctx.Rollback.Rollback(hash, true)` for hard reset
          - If `ctx.Rollback` nil: falls back to `ctx.Git.Log(false, "")`, takes first 10 commits as raw list
       - `handleSessions(args, ctx)`: calls `ctx.SessionManager.ListSessions()`. Returns formatted table of sessions
       - `handleGoal(args, ctx)`: if no args, returns message about session goal. If args, returns goal set confirmation (stored via config)
       - `handlePhase(args, ctx)`: if no args, shows current phase from session. If args, validates phase name against allowed values (idle/initialize/discuss/plan/execute/verify/ship)
       - `handleConfig(args, ctx)`: if no args, shows current config as key-value table. If args (key [value]), parses dot-notation key and sets value (e.g., "ui.theme dark")
       - `handleModels(args, ctx)`: lists all cached models from `ctx.Registry.ActiveProvider().FetchModels()`. Returns formatted list with ID, context length, pricing

    Use `fmt.Sprintf` for all formatted output. Validate arg counts in each handler.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User input → ParseCommand | Untrusted user input enters via /command strings; parsed with strings.Fields() |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-01-01 | Tampering | ParseCommand input splitting | mitigate | strings.Fields() is safe against injection; args are validated per-handler (not shell-executed) |
| T-07-01-02 | Information Disclosure | /status exposes session details | accept | Session ID and phase are non-sensitive; no API keys or secrets exposed |
| T-07-01-03 | Denial of Service | Large /rollback output | mitigate | git.Log capped at 10 entries in handler; no unbounded output |
| T-07-01-04 | Spoofing | /provider SetActive with invalid name | mitigate | Registry.SetActive validates provider exists; returns error for unknown names |
</threat_model>

    2. `CostEstimate` struct — fields:

       - `Provider string`

       - `TotalCost float64` — combined cost

    3. `ArbitrageRecommendation` struct — fields:
       - `RecommendedModel CostEstimate`
       - `Alternatives []CostEstimate` — next cheapest options
       - `Complexity ComplexityLevel`
       - `Savings float64` — savings vs most expensive option
       - `Reason string` — why this model was chosen

    4. `Scorer` struct — fields:
       - `SimpleThreshold int` — max tokens for "simple" (default 2000)
       - `ComplexThreshold int` — min tokens for "complex" (default 8000)

    5. `func NewScorer(simpleThreshold, complexThreshold int) *Scorer` — constructor. If args <= 0, use defaults: SimpleThreshold=2000, ComplexThreshold=8000.

    Methods:

    6. `func (s *Scorer) Score(task types.Task) (ComplexityLevel, int)` — estimates complexity based on per D-02 (CONTEXT.md):
       - Count files: `len(task.Files)`
       - Count dependencies: `len(task.Dependencies)`
       - Word count: `len(strings.Fields(task.Description))`
       - Action keywords (check task.Action and task.Description):
         - ComplexitySimple keywords: "fix", "add", "update", "change", "rename"
         - ComplexityModerate keywords: "implement", "create", "refactor", "restructure"
         - ComplexityComplex keywords: "design", "architect", "migrate", "rewrite", "system"
       - Base score: if any Complex keyword found → Complex. If any Moderate keyword → Moderate. If any Simple keyword → Simple. Default → Simple.
       - Boost: if files > 3 move up one level. If deps > 3 move up one level.
       - Return complexity level and estimated token count (from EstimateTokens)

    7. `func (s *Scorer) EstimateTokens(complexity ComplexityLevel, task types.Task) (input int, output int)` — per D-02 (CONTEXT.md):
       - Simple: input 1000-3000, output 500-1500
       - Moderate: input 3000-8000, output 1500-4000
       - Complex: input 8000-20000, output 4000-10000
       - Adjustment: add 500 tokens per file (len(task.Files) * 500 both input and output)
       - Use midpoint of range for deterministic estimate: Simple→2000/1000, Moderate→5500/2750, Complex→14000/7000

    Functions:

    8. `func CompareModels(models []types.ModelInfo, inputTokens, outputTokens int) []CostEstimate` — per D-02:
       - For each model, compute: `inputTokens * (model.Pricing.InputPerMToken / 1_000_000.0) + outputTokens * (model.Pricing.OutputPerMToken / 1_000_000.0)`
       - If both Pricing fields are 0, skip the model (no pricing data)
       - Sorting: ascending by TotalCost
       - Return sorted slice

    9. `func Recommend(models []types.ModelInfo, task types.Task, threshold float64) (*ArbitrageRecommendation, error)` — per D-02:
       - Create Scorer with defaults
       - Score the task → complexityLevel, estimatedTokens
       - Call EstimateTokens to get input/output counts
       - Call CompareModels to get sorted cost estimates
       - If no models: return error
       - Pick cheapest model as recommended
       - Determine if compatibility needed: Complex tasks need large context window (>64000); Simple tasks any model works
       - Apply threshold: if cheapest doesn't meet capability needs, check next model that costs no more than cheapest*(1+threshold)
       - Build recommendation with reason string: "Cheapest model suitable for {complexity} task."
       - Alternatives: up to 3 next cheapest models after recommended
       - Savings: difference between recommended and most expensive model
       - Return recommendation

    10. `func ShouldArbitrage(currentCost, alternativeCost, threshold float64) bool` — per D-02:
        - Returns true if `(currentCost - alternativeCost) / currentCost > threshold`
        - If currentCost is 0, return false (no basis for comparison)
        - If alternativeCost >= currentCost, return false

    Helper: `func classifyText(text string) ComplexityLevel` — checks text against keyword lists in order: complex first, moderate second, simple last. Returns matching level or ComplexitySimple as default.

    Define types:

    1. `RollbackEntry` struct — fields:
       - `CommitInfo git.CommitInfo`
       - `Diff string` — diff from this commit to HEAD
       - `IsCurrent bool` — true if this is the current HEAD
       - `HasCheckpoint bool` — true if a checkpoint exists after this commit

    2. `RollbackResult` struct — fields:
       - `Success bool`
       - `PreviousHead string`
       - `NewHead string`
       - `ChangesStashed bool`
       - `Message string`

    3. `Rollback` struct — unexported field: `git *git.Git`

    4. `func New(g *git.Git) *Rollback` — constructor

    Methods:

    5. `func (r *Rollback) Chain(limit int) ([]RollbackEntry, error)` — core method:
       - If limit <= 0, set to 20 (per CONTEXT.md: "Chain() limits to 20 commits by default")
       - Call `r.git.Log(false, "")` for full commit history
       - Get current HEAD via `r.git.HeadHash()`
       - Take first `limit` entries from log output (log returns newest-first already)
       - For each entry: compute diff with `r.git.Diff(entry.Hash, "HEAD")`
       - Mark entry with `IsCurrent = true` if hash matches HEAD
       - Mark `HasCheckpoint` — load checkpoints from session (skip if session not provided, always false for now)
       - Handle empty repo: return empty slice, nil error

    6. `func (r *Rollback) CurrentHead() (string, error)` — calls `r.git.HeadHash()`

    7. `func (r *Rollback) Preview(hash string) (string, error)` — calls `r.git.Diff(hash, "HEAD")`, caps output at `types.BashOutputLimit` (50,000 chars). If output exceeds limit, truncate and append "\n... [output truncated]"

    8. `func (r *Rollback) SoftReset(hash string) (*RollbackResult, error)` — per D-04 (CONTEXT.md: "All reset methods stash first if uncommitted changes exist"):
       - Check `r.HasUncommittedChanges()`
       - If dirty: `r.git.StashPush("rollback-soft-auto-stash")`
       - `r.git.ResetSoft(hash)`
       - Build RollbackResult with previous HEAD, new HEAD, stash status, user-friendly message
       - Message format: "Rolled back from abc123 to def456. N commits undone. Changes stashed."

    9. `func (r *Rollback) HardReset(hash string) (*RollbackResult, error)` — same stash-first pattern, then `r.git.ResetHard(hash)`

    10. `func (r *Rollback) SafeReset(hash string) (*RollbackResult, error)` — same stash-first, reset hard, then `r.git.StashPop()` to restore stashed changes

    11. `func (r *Rollback) HasUncommittedChanges() (bool, error)` — calls `r.git.Status()`, returns true if output indicates dirty state (contains "Changes not staged", "Untracked files", "Changes to be committed", or "modified:" / "new file:" / "deleted:")

    Helper: `func (r *Rollback) stashIfDirty() (bool, error)` — checks HasUncommittedChanges, if true calls StashPush with appropriate message, returns (true, nil) on success. If no changes, returns (false, nil).

    Helper: `func (r *Rollback) countCommitsBetween(startHash, endHash string) (int, error)` — calls `r.git.Log(false, "")` and filters by hash range to count commits between two hashes (for nice "N commits undone" messages). Note: git.Log() returns all commit history; this helper filters in-memory for the range.

    Sentinel errors: define locally or use internal/errors:
    - `var ErrInvalidHash = errors.New("invalid commit hash")` — returned when hash not found in git log

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User → Rollback methods | User provides commit hash strings; not validated against git output |
| Rollback ↔ Git CLI | All git operations go through internal/git.Git wrapper (not raw shell) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-02-01 | Tampering | Hash injection via SoftReset/HardReset args | mitigate | Hash validated by git.ResetSoft/ResetHard — git rejects invalid refs; stash-first protects uncommitted work |
| T-07-02-02 | Denial of Service | Large diff in Preview() | mitigate | Preview caps output at types.BashOutputLimit (50,000 chars); truncation appended |
| T-07-02-03 | Information Disclosure | Chain() exposes commit history | accept | Git log is public information within the repo; no sensitive data |
| T-07-02-04 | Data Loss | HardReset without stash | mitigate | All reset methods stash uncommitted changes first (per CONTEXT.md locked decision) |
</threat_model>

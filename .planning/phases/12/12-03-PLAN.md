<objective>
Create persistent prompt history with frecency ranking — store submitted prompts to `~/.m31a/prompt_history.json`, rank by frequency and recency, and navigate via arrow-up/down with prefix matching showing top 10 results.

**Purpose:** Users frequently repeat similar prompts. Persistent history with frecency scoring surfaces the most relevant prompts first, improving REPL efficiency. This matches OpenCode's prompt history behavior (adoption #11).

**Output:** `internal/tui/history.go` (new file) with `FrecentHistory` struct, methods `Load`, `Save`, `Upsert`, `Search`; modifications to `internal/tui/repl.go` for arrow-up/down integration; tests.
</objective>

    5. `func (h *FrecentHistory) Load() error`:
       - Read file at `h.filePath` with `os.ReadFile`
       - If file does not exist, set `h.entries = []HistoryEntry{}` and return nil (D-04: graceful start)

    6. `func (h *FrecentHistory) Save() error`:
       - Build `HistoryData{Entries: h.entries}`
       - Marshal to JSON with `json.MarshalIndent(data, "", "  ")`
       - Write atomically: create temp file in same directory, write, `os.Rename`
       - **Eviction**: before saving, if `len(h.entries) > h.maxSize` (1000), sort by frecency ascending and remove lowest-scored entries until within limit. D-04: "Max entries: 1000; oldest evicted by frecency score on save."

    7. `func (h *FrecentHistory) Upsert(text string)`:
       - Normalize text: `strings.TrimSpace(text)`, skip if empty
       - Search for existing entry by exact text match
       - If found: increment `Frequency`, set `LastUsed = time.Now()`
       - If not found: append new entry with `Text: text, Frequency: 1, FirstUsed: time.Now(), LastUsed: time.Now()`
       - D-04: "On each submit, upsert the prompt text: if exists, bump frequency and update last_used; if new, append with frequency=1"

    8. `func (h *FrecentHistory) Search(prefix string, limit int) []HistoryEntry`:
       - If prefix is empty, return top `limit` entries sorted by frecency descending
       - If prefix is non-empty, filter entries where `strings.HasPrefix(entry.Text, prefix)` or `strings.Contains(entry.Text, prefix)`, then sort by frecency descending and return top `limit`
       - D-04: "Arrow-up navigates through history; shows top 10 frecency-ranked matches matching current input prefix"

    9. `func (h *FrecentHistory) Frecency(entry HistoryEntry) float64`:
       - `hoursSinceLastUse := time.Since(entry.LastUsed).Hours()`
       - `return float64(entry.Frequency) / (hoursSinceLastUse + 1.0)`
       - D-04: "Frecency score: `score = frequency / (hours_since_last_use + 1)`"

    10. `func (h *FrecentHistory) All() []HistoryEntry`:
        - Return a copy of all entries sorted by frecency descending

    11. `func (h *FrecentHistory) Size() int`: return len(h.entries)

    12. `func (h *FrecentHistory) Clear()`: reset entries to empty slice

    File imports: `"os"`, `"encoding/json"`, `"strings"`, `"sort"`, `"time"`, `"path/filepath"`, `"crypto/rand"`, `"encoding/hex"`.

<objective>
Implement shell mode — when user input starts with `!`, strip the prefix and execute the command directly via the Bash tool without any LLM involvement. The command output appears as an assistant message but does not count as a conversation turn (not appended to message history for subsequent LLM requests).

**Purpose:** Users can run quick shell commands (git status, ls, cat, etc.) without waiting for an LLM round-trip. This matches OpenCode's shell mode behavior and dramatically improves REPL responsiveness for operational tasks.

**Output:** Modified `internal/tui/repl.go` with shell mode detection and Bash execution; new or modified `internal/tui/repl_test.go` with shell mode tests.
</objective>

       ```go
       func (m *ReplModel) executeShellCommand(command string) ([]tea.Cmd, bool) {
           // 1. Show the command in the viewport immediately as an assistant message
           displayMsg := types.Message{
               Role:    "assistant",
               Content: fmt.Sprintf("$ %s\nRunning...\n", command),
               Segments: []types.MessageSegment{{
                   Type:    "content",
                   Content: fmt.Sprintf("$ %s\nRunning...\n", command),
                   Visible: true,
               }},
               CreatedAt: time.Now(),

           m.renderMessages()
           m.viewport.GotoBottom()

           // 2. Execute via goroutine that calls dispatcher
           return []tea.Cmd{func() tea.Msg {
               if m.dispatcher == nil {
                   return ShellResultMsg{
                       Command: command,
                       Output:  "Error: dispatcher not available",
                       Err:     "dispatcher not available",
                   }
               }

               // Construct ToolCall for Bash
               params := map[string]any{
                   "command":    command,
                   "description": "shell mode command",
                   "timeout_ms": 300000, // 5 minutes
               }
               paramsJSON, _ := json.Marshal(params)
               toolCall := types.ToolCall{
                   ID:    fmt.Sprintf("shell_%d", time.Now().UnixNano()),
                   Name:  "bash",
                   Input: paramsJSON,
               }

               ctx, cancel := context.WithTimeout(context.Background(), 300*time.Second)
               defer cancel()

               result, err := m.dispatcher.Execute(ctx, toolCall)
               if err != nil {
                   return ShellResultMsg{
                       Command: command,
                       Output:  result.Output,
                       Err:     err.Error(),
                   }
               }
               return ShellResultMsg{
                   Command: command,
                   Output:  result.Output,
                   Err:     "",
               }
           }}, false
       }
       ```

| User input → shell command execution | !-prefixed input passed directly to Bash tool without LLM mediation |
| Shell command → terminal | Arbitrary command execution on user's machine |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-12-02-01 | Tampering | ! command → Bash execution | accept | User explicitly typed ! to request shell execution; Bash tool's existing risk-level and PermissionRule protections apply |
| T-12-02-02 | Denial of Service | Long-running shell command | mitigate | Shell commands use 5-minute context timeout; Bash tool has 30-minute absolute timeout |
| T-12-02-03 | Information Disclosure | Command output displayed in TUI | accept | User typed the command — they see their own command's output; no additional disclosure |
| T-12-02-04 | Elevation of Privilege | ! prefix bypassing permission modal | mitigate | Dispatcher PermissionRule patterns still apply (glob matching); only interactive modal is skipped — rules like "deny rm -rf /" still block |

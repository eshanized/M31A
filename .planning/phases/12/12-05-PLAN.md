<objective>
Implement editor context auto-include — when user input contains `@filepath` references, automatically resolve them relative to cwd and replace the reference with the file contents before sending the LLM request. Skip binary files (show placeholder), respect 100KB size limit, and silently leave unresolvable references as-is.

**Purpose:** Users frequently paste file contents or describe file paths when asking the LLM to modify code. `@filepath` syntax eliminates manual copy-paste and directly mirrors OpenCode's editor context feature (adoption #14).

**Output:** Modifications to `internal/tui/repl.go` — add `expandFileRefs` method and integrate it into the chat request building path; tests.
</objective>

@filepath patterns to match:
- `@./path/to/file.go` — explicit relative path
- `@path/to/file.go` — implicit relative path
- `@/absolute/path/file.go` — absolute path
- NOT matching: `@user` (no dot or slash), `@mention`, email addresses (but those usually don't look like file paths)

Resolve logic:
1. Use regex or prefix scan to find `@` followed by a file path
2. Accept: `@./foo`, `@../foo`, `@foo/bar`, `@/absolute/path`
3. Reject: `@foo` without path separator (not ambiguous enough), standalone `@`
4. For matches: resolve relative to cwd (process working directory)
5. If path exists and is a file:
   - Check size ≤ 100KB (D-06)
   - Check binary (first 512 bytes mime sniff)
   - If binary: replace with `@path/to/file [binary, N bytes]`
   - If too large: replace with `@path/to/file [file too large: N bytes, max 100KB]`
   - Else: read content, replace with `--- path/to/file ---\n{content}\n---`
6. If path doesn't exist: leave `@filepath` as-is (D-06: no error)

D-06: "Before sending a chat request, scan input for `@filepath` patterns" — the expansion happens at the point where the user message is prepared for the LLM request, not in the display layer. The REPL view shows the original `@filepath`, and the expanded content goes into the ChatRequest.

       ```go
       // expandFileRefs scans input for @filepath references, resolves file contents,
       // and replaces them with inline content blocks. Unresolvable references remain as-is.
       func (m *ReplModel) expandFileRefs(input string) string {
           if m.cwd == "" {
               return input
           }
           
           return fileRefPattern.ReplaceAllStringFunc(input, func(match string) string {
               path := match[1:] // strip the @ prefix
               
               // Resolve relative to cwd
               resolvedPath := path
               if !filepath.IsAbs(path) {
                   resolvedPath = filepath.Join(m.cwd, path)
               }
               resolvedPath = filepath.Clean(resolvedPath)
               
               // Stat the file
               fi, err := os.Stat(resolvedPath)
               if err != nil {
                   // File not found or inaccessible — leave reference as-is per D-06
                   return match
               }
               
               if fi.IsDir() {
                   return match // directories not supported, leave as-is
               }
               
               // Size check: 100KB limit per D-06
               const maxFileSize = 100 * 1024
               if fi.Size() > maxFileSize {
                   return fmt.Sprintf("%s [file too large: %d bytes, max 100KB]", match, fi.Size())
               }
               
               // Read first 512 bytes for binary detection
               f, err := os.Open(resolvedPath)
               if err != nil {
                   return match
               }
               defer f.Close()
               
               header := make([]byte, 512)
               n, _ := f.Read(header)
               
               // Detect content type via mime sniff
               contentType := http.DetectContentType(header[:n])
               if !strings.HasPrefix(contentType, "text/") && contentType != "application/json" && 
                  contentType != "application/xml" && contentType != "application/javascript" &&
                  contentType != "application/x-sh" && contentType != "application/yaml" {
                   // Binary file per D-06
                   return fmt.Sprintf("%s [binary: %s, %d bytes]", match, contentType, fi.Size())
               }
               
               // Read full content
               f.Seek(0, 0)
               content, err := io.ReadAll(f)
               if err != nil {
                   return match
               }
               
               // Format: --- path/to/file ---\n{content}\n--- per D-06
               return fmt.Sprintf("--- %s ---\n%s\n---", path, string(content))
           })
       }
       ```

       Add imports: `"io"`, `"net/http"` (for `http.DetectContentType`), `"fmt"`, `"math"` (check what's already imported).

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User input → regex scan → file system read | @filepath triggers file read from user's filesystem |
| File content → LLM request | Resolved file content sent to LLM provider over network |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-12-05-01 | Tampering | fileRefPattern regex matching | mitigate | Regex is bounded — no user-controlled regex; `ReplaceAllStringFunc` operates on fixed pattern |
| T-12-05-02 | Information Disclosure | File content sent to LLM | accept | User explicitly referenced the file via @filepath; they control what files are included |
| T-12-05-03 | Denial of Service | Very large file read attempt | mitigate | 100KB hard cap before read; `os.Stat` check prevents reading files over limit |
| T-12-05-04 | Information Disclosure | Binary file sniff read | mitigate | Only reads first 512 bytes for mime detection; full read skipped if over size limit or binary |
| T-12-05-05 | Path Traversal | @../../../etc/passwd style paths | mitigate | `filepath.Clean` normalizes the path; os.Stat will fail for symlinks outside cwd only if FileRead restrictions are in place; however, the user can already read any file they have permissions to — this is by design (the user explicitly types @path) |

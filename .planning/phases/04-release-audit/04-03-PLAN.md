    **Step 1: Find all violations**

    - Expected: ~142 instances across the codebase

    **Step 2: Mechanical replacement**
    - For each violation, replace `%s` or `%v` with `%w` when the formatted value is an `error`
    - Pattern: `fmt.Errorf("context: %s", err)` -> `fmt.Errorf("context: %w", err)`
    - Pattern: `fmt.Errorf("context: %v", err)` -> `fmt.Errorf("context: %w", err)`
    - Pattern: `fmt.Errorf("context: %s: %v", op, err)` -> `fmt.Errorf("context: %s: %w", op, err)`
    - CRITICAL: Only replace when the argument is actually an `error` type, not a string

    **Step 3: Handle special cases**
    - `fmt.Errorf("no models available")` — NO error to wrap, leave as-is (this is creating a new error)
    - `fmt.Errorf("task %d: references non-existent dependency %d", ...)` — NO error to wrap, leave as-is
    - `fmt.Errorf("git %s failed: %v", operation, err)` — REPLACE `%v` with `%w` (err is an error)
    - `fmt.Errorf("models fetch returned status %d", statusCode)` — NO error to wrap, leave as-is

    **Step 4: Verify error chain preservation**

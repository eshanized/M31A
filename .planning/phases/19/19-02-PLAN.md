**SEC-1 (SSRF TOCTOU gap — DNS cache with pinned IPs):**
In `internal/tools/webfetch.go`, add a DNS cache to `WebFetch` that pins resolved IPs per hostname for the request lifecycle. Changes:

1. Add a `dnsCache` field to `WebFetch` struct:
```go
type WebFetch struct {
    sessionsDir     string
    allowPrivateIPs bool
    client          *http.Client
    dnsCache        sync.Map // map[string]*dnsCacheEntry; key=hostname, value=*dnsCacheEntry
}

type dnsCacheEntry struct {
    addrs    []net.IPAddr
    expires  time.Time
}
```

2. Add a `resolveAndCache` method that checks the cache first, resolves if expired (5-minute TTL), stores result, and returns `[]net.IPAddr`. Use `sync.Map.LoadOrStore` for thread safety.

3. In `NewWebFetch`'s `DialContext` closure (line 31), replace the inline `resolver.LookupIPAddr` call with `wf.resolveAndCache(ctx, host)`. Check ALL returned IPs against the private IP filter (not just the first one). If any IP is private and `allowPrivateIPs` is false, reject the connection.

4. Pin the first non-private IP for the connection (existing behavior), but the TOCTOU gap is closed because the resolution is cached for the request lifetime.

5. Add a doc comment on the dnsCache entry type explaining the 5-minute TTL and why DNS caching prevents rebinding attacks.

**SEC-4 (Backup pruning — keep at most 10 per file):**
In `internal/tools/filewrite.go`, after the backup write (line 134), add a `pruneBackups` helper function that:
1. Lists all files in `t.backupDir` matching the sanitized filename prefix (e.g., `main_go.*`)
2. Sorts by name (timestamp is in the name, so lexicographic sort = chronological)
3. If count > 10, deletes the oldest entries (lowest sort order) to keep exactly 10
4. Uses `os.Remove` for deletion; logs but does not fail on removal errors

Add `maxBackupsPerFile = 10` as a package-level constant.

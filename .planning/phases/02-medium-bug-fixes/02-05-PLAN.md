**Fix M17 — internal/codeintel/index.go (line 156):**

Find:
```go
idx.byName[s.Name] = append(locs[:i], locs[i+1:]...)
```

This mutates the original backing array. Replace with a safe copy:
```go
newLocs := make([]SymbolLocation, 0, len(locs)-1)
newLocs = append(newLocs, locs[:i]...)
newLocs = append(newLocs, locs[i+1:]...)
idx.byName[s.Name] = newLocs
```

Or more idiomatically:
```go
copy(locs[i:], locs[i+1:])
locs = locs[:len(locs)-1]
idx.byName[s.Name] = locs
```

Note: The copy approach modifies the slice header but creates a new length. The make approach creates a completely independent slice. Use whichever is safer given the surrounding code.

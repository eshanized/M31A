<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Config → ExtensionRegistry | User-controlled config declares external commands to execute |
| ExtensionRegistry → SubprocessManager | Registry spawns user-specified executables as child processes |
| SubprocessManager → JSON-RPC | Stdout/stdin communication with external process (untrusted) |
| External Extension → Host System | Extension runs as user, full file system/network access |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-01 | Injection | SubprocessManager.Start | high | mitigate | Validate command is absolute path or in allowlist; reject shell metacharacters; no shell=true |
| T-06-02 | Tampering | External Extension binary | high | accept | User controls extension supply chain; document verification (checksums, signatures) |
| T-06-03 | DoS | SubprocessManager.Call | medium | mitigate | Output bounding via existing exec.OutputStore; context timeout enforcement; stderr rate limiting |
| T-06-04 | Info Disclosure | SubprocessManager env vars | medium | mitigate | Scrub env vars before spawn (reuse patterns from bash_sandbox_linux.go); only pass explicitly configured Env |
| T-06-05 | Tampering | Config → ExtensionRegistry | medium | mitigate | Config validation: command must exist and be executable; timeout bounds (max 5min) |
| T-06-SC | Tampering | npm/pip/cargo installs | high | mitigate | No new package installs for core extension system; benchstat/GoReleaser already vetted |
</threat_model>

<reversibility_gate>
## D-02: pkg/extensions Public Package — Costly Reversibility

**Decision:** Create new public `pkg/extensions` package with stable Go interfaces (ExternalTool, ExternalProvider, PhaseHookHandler, ExtensionConfig, SubprocessManager, ExtensionRegistry, adapters).

**Reversibility Rating:** Costly — establishes a published contract; undoing requires migration for any external adopters.

**Migration Path if Reversed:**
1. Deprecate `pkg/extensions` in favor of internal-only interfaces
2. Provide 2 minor version deprecation window with both old and new paths
3. External adopters migrate to internal interfaces (breaking change)
4. Remove `pkg/extensions` after deprecation period

**Contract Preservation:**
- Interface signatures must not change without major version bump
- Protocol version in handshake (`MethodHandshake`) enables backward compatibility
- Document breaking change policy in `docs/extensions/api-reference.md`

**Checkpoint:** Before merging Plan 01, verify migration path documented and protocol versioning implemented.
</reversibility_gate>

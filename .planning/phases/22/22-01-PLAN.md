# Plan 22-01: Critical Bug Fixes & Config Wiring

## Objective
Fix the 3 critical bugs (BUG-01, BUG-05, BUG-06) and wire all 8 config fields to provider Options structs.

## Tasks

### Task 1: Fix First-Run Validation URLs (BUG-01)

**read_first:**
- `internal/tui/firstrun.go` (lines 614-655)
- `internal/config/types.go` (ProviderConfig struct)

**action:**
1. Modify `validateAPIKey()` signature to accept base URLs:
   ```go
   func validateAPIKey(provider, key, openrouterBaseURL, zenBaseURL string) error
   ```
2. Replace hardcoded URLs with parameter-based URLs:
   ```go
   case "openrouter":
       url = openrouterBaseURL + "/auth/key"
   case "zen":
       url = zenBaseURL + "/models"
   ```
3. Update all callers of `validateAPIKey()` to pass config base URLs
4. Add fallback to default URLs if config fields are empty

**acceptance_criteria:**
- `validateAPIKey()` accepts base URL parameters
- First-run screen uses `config.Provider.OpenRouterBaseURL` when set
- First-run screen uses `config.Provider.ZenBaseURL` when set
- Empty config fields fall back to default URLs
- `go test ./internal/tui/...` passes

### Task 2: Fix Self-Heal Trigger (BUG-05)

**read_first:**
- `internal/tui/verify.go` (lines 65-84)
- `internal/tui/app_workflow.go` (healTask function)

**action:**
1. Replace `return nil, nil` with a command that triggers healing:
   ```go
   case "y", "Y", "enter":
       for i := range m.tasks {
           if m.tasks[i].ID == m.confirmHealTask && m.tasks[i].Status == types.StatusFailed {
               m.tasks[i].Status = types.StatusPending
               break
           }
       }
       m.confirmHeal = false
       return m.healTask(m.confirmHealTask), nil
   ```
2. Ensure `healTask()` returns a `tea.Cmd` that:
   - Sets task status to running
   - Calls LLM with healing context
   - Dispatches tool calls
   - Re-verifies the task

**acceptance_criteria:**
- Pressing Y on self-heal confirmation triggers actual healing
- `healTask()` returns a valid `tea.Cmd`
- Task status transitions: failed → pending → running → done/failed
- `go test ./internal/tui/... -run TestVerify` passes

### Task 4: Wire Config Fields to Provider Options

**read_first:**
- `internal/config/types.go` (ProviderConfig, FeaturesConfig)
- `internal/provider/openrouter/client.go` (Options struct, NewClient)
- `internal/provider/zen/client.go` (Options struct, NewClient)
- `internal/tui/app.go` (provider initialization)

**action:**
1. Add config fields to provider Options during initialization:
   ```go
   openrouterOpts := openrouter.Options{
       BaseURL:            cfg.Provider.OpenRouterBaseURL,
       Referer:            cfg.Provider.OpenRouterReferer,
       Title:              cfg.Provider.OpenRouterTitle,
       CacheTTL:           time.Duration(cfg.Features.ModelCacheTTLMinutes) * time.Minute,
       CacheStaleTTL:      time.Duration(cfg.Features.ModelCacheStaleHours) * time.Hour,
       HealthCheckLiveMs:  cfg.Features.HealthCheckLiveMs,
       HealthCheckSlowMs:  cfg.Features.HealthCheckSlowMs,
   }
   ```
2. Apply same pattern for Zen provider
3. Ensure empty config fields use provider defaults

**acceptance_criteria:**
- `OpenRouterBaseURL` config field passed to OpenRouter Options
- `ZenBaseURL` config field passed to Zen Options
- `OpenRouterReferer` and `OpenRouterTitle` passed to OpenRouter
- Cache TTLs from config passed to both providers
- Health check thresholds from config passed to both providers
- Empty config fields fall back to provider defaults
- `go test ./internal/provider/...` passes

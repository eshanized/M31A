### Task 3: Add Config Validation

**read_first:**
- `internal/config/loader.go` (validateConfig function)
- `internal/config/types.go` (all config structs)

**action:**
1. Add range validation for numeric fields:
   ```go
   func validateConfig(cfg *Config) error {
       if cfg.Model.ContextWarningThreshold < 0 || cfg.Model.ContextWarningThreshold > 1 {
           return fmt.Errorf("context_warning_threshold must be between 0 and 1")
       }
       if cfg.Model.ArbitrageThreshold < 0 || cfg.Model.ArbitrageThreshold > 1 {
           return fmt.Errorf("arbitrage_threshold must be between 0 and 1")
       }
       if cfg.UI.MaxIterations < 0 {
           return fmt.Errorf("max_iterations must be non-negative")
       }
       if cfg.UI.LeaderTimeoutMs <= 0 {
           return fmt.Errorf("leader_timeout_ms must be positive")
       }
       if cfg.Permissions.TimeoutSeconds <= 0 {
           return fmt.Errorf("timeout_seconds must be positive")
       }
       if cfg.Features.ModelCacheTTLMinutes < 0 {
           return fmt.Errorf("model_cache_ttl_minutes must be non-negative")
       }
       if cfg.Features.SessionIDLength < 4 {
           return fmt.Errorf("session_id_length must be at least 4")
       }
       return nil
   }
   ```

**acceptance_criteria:**
- All numeric config fields validated
- Clear error messages for invalid values
- `go test ./internal/config/... -run TestValidation` passes

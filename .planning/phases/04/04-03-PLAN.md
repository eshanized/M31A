# Plan 4-03 — FileRead Tool

Implement the FileRead tool — safe file reading with path validation, symlink resolution, binary detection via MIME sniffing, and a 5MB file size limit.

---

## Task 04-03-A — Create FileRead struct

**Description:** Implement FileRead tool in `internal/tools/fileread.go`.

<read_first>
- internal/types/types.go (Tool interface, ToolInput, ToolResult, RiskLevel)
- internal/types/constants.go (MaxFileSize = 5MB)
- internal/errors/errors.go (ErrPermissionDenied, ErrFileTooLarge, ErrToolExecution)
- 04-RESEARCH.md (Pattern 5: FileRead — Path Safety and Binary Detection)
</read_first>

<action>
Create `internal/tools/fileread.go` with:

```go
package tools

import (
    "context"
    "mime"
    "os"
    "path/filepath"
    "strings"

    "github.com/eshanized/M31A/internal/types"
    m31errors "github.com/eshanized/M31A/internal/errors"
)

type FileRead struct {
    workDir string
}

func NewFileRead(workDir string) *FileRead

func (t *FileRead) Name() string           // returns "FileRead"
func (t *FileRead) Description() string    // tool description for LLM function calling
func (t *FileRead) RiskLevel() types.RiskLevel  // returns RiskSafe

func (t *FileRead) Execute(ctx context.Context, input types.ToolInput) (types.ToolResult, error)
```

**Parameters:**
- `path` (string, required): File path to read (relative or absolute)
- `limit` (int, optional): Max bytes to read (default: MaxFileSize = 5MB)

**Safety checks:**
1. Resolve to absolute path via `filepath.Abs(path)`
2. Resolve symlinks via `filepath.EvalSymlinks(absPath)`
3. Verify resolved path is within workDir: `strings.HasPrefix(resolved, workDir)`
4. Reject if path is a directory (`os.Stat` + `IsDir()`)
5. Check file size via `os.Stat` — reject if > `limit` with `m31errors.ErrFileTooLarge`

**Reading:**
1. Open file with `os.Open(resolvedPath)`
2. Read first 512 bytes into buffer
3. Detect binary: scan for null byte `\x00` in first 512 bytes
4. If binary: detect MIME type via `mime.DetectContentType(firstBytes)`, return `ToolResult{Output: fmt.Sprintf("[binary file, %s, %d bytes]", mimeType, fileSize)}`
5. If text: read up to `limit` bytes, return content as string
6. Return `ToolResult{Output: content, DurationMs: elapsed}`

**Error handling:**
- Missing `path` param: `"missing parameter: path"`
- File not found: wrap `os.ErrNotExist` with descriptive message
- Permission denied: `m31errors.ErrPermissionDenied`
- File too large: `m31errors.ErrFileTooLarge`
- Path outside workDir: error message "path resolves outside working directory"
- Context cancelled: return context error
</action>

<acceptance_criteria>
- `internal/tools/fileread.go` compiles with zero errors
- Reading a text file returns its contents
- Reading a binary file returns `[binary file, ...]` placeholder
- Path outside workDir returns error
- Directory path returns error
- File exceeding 5MB returns ErrFileTooLarge
- Symlink pointing outside workDir returns error
- Missing path param returns error
- `go build ./internal/tools/...` succeeds
</acceptance_criteria>

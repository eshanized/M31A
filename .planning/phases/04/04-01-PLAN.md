## Task 04-01-B — Create Glob struct

**Description:** Implement the Glob tool in `internal/tools/glob.go`.

<read_first>
- internal/tools/interface.go (PermissionRequest, PermissionResponse types, existing package conventions)
- internal/types/types.go (Tool interface, ToolInput, ToolResult, RiskLevel)
- internal/types/constants.go (BashOutputLimit pattern for reference — no specific glob limit constant needed)
</read_first>

<action>
Create `internal/tools/glob.go` with:

```go
package tools

import (
    "context"
    "os"
    "path/filepath"
    "sort"
    "strings"

    "github.com/bmatcuk/doublestar/v4"
    "github.com/eshanized/M31A/internal/types"
)

type Glob struct {
    workDir string
}

func NewGlob(workDir string) *Glob

func (t *Glob) Name() string           // returns "Glob"
func (t *Glob) Description() string    // returns tool description for LLM function calling
func (t *Glob) RiskLevel() types.RiskLevel  // returns RiskSafe

func (t *Glob) Execute(ctx context.Context, input types.ToolInput) (types.ToolResult, error)
```

**Parameters (from ToolInput.Params):**
- `pattern` (string, required) — glob pattern supports `**` for recursive matching via doublestar

**Execution:**
- Use `doublestar.Glob(filepath.Join(t.workDir, pattern))` to match files
- Sort results alphabetically by path
- Format output as a table with columns: path, size, modified timestamp
- Hard limit: 1,000 results — if exceeded, append `[... N more files]` to output
- If `rg` is available in PATH (`exec.LookPath("rg")`), use `rg --files --glob <pattern>` instead (respects .gitignore). Otherwise fall back to doublestar.
- No matches: return `ToolResult{Output: "No files matched pattern"}`

**Error handling:**
- Missing `pattern` param: return error "missing parameter: pattern"
- Invalid pattern: return error with details
- Context cancelled: return context error
</action>

<acceptance_criteria>
- `internal/tools/glob.go` compiles with zero errors
- `NewGlob(workDir)` creates a Glob with the given workDir
- `Execute` with a simple pattern returns matching files
- `Execute` with `**` recursive pattern returns nested matches
- Empty results return "No files matched pattern"
- Missing pattern param returns error
- `go build ./internal/tools/...` succeeds
</acceptance_criteria>

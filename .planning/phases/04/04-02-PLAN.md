# Plan 4-02 — Grep Tool

Implement the Grep tool — code search via `rg` (ripgrep) with JSON output parsing, falling back to pure-Go `bufio.Scanner` line-by-line regex search when rg is unavailable.

**Description:** Implement the Grep tool in `internal/tools/grep.go`.

<read_first>

- internal/types/constants.go (BashOutputLimit pattern for reference)
- 04-RESEARCH.md (Pattern 4-5: Grep — rg detection, pure-Go fallback, .gitignore)
</read_first>

<action>
Create `internal/tools/grep.go` with:

```go
package tools

import (
    "bufio"
    "context"
    "os"
    "os/exec"
    "path/filepath"
    "regexp"
    "strings"

    "github.com/eshanized/M31A/internal/types"
)

type Grep struct {
    workDir string
    hasRg   bool
}

func NewGrep(workDir string) *Grep
```

- `NewGrep`: checks for rg in PATH via `exec.LookPath("rg")`, sets `hasRg`

**Parameters:**
- `pattern` (string, required): Regex pattern to search
- `path` (string, optional): File or directory to search (default: workDir)
- `glob` (string, optional): File glob filter (e.g., "*.go", "**/*.ts")
- `max_results` (int, optional): Max results (default: 100)

**Execution with rg:**
- Build command: `rg --json --no-heading --line-number --max-count <max_results> <pattern> <path>`
- If glob provided: append `--glob <glob>`
- Parse JSON output line by line — each line is a JSON object with `type` field (`match`, `summary`, etc.)
- Format matches as `file:line: content`
- Cap at `max_results`

**Pure-Go fallback:**
- Walk directory from `path` (or workDir)
- For each file matching `glob` pattern (via `doublestar.Match` or `filepath.Match`):
  - Open file, check for binary (null bytes in first 512 bytes) — skip if binary
  - Scan line by line with `bufio.Scanner`
  - Match against compiled regex: `regexp.Compile(pattern)`
  - Collect matching lines with line numbers
- Cap at `max_results`

**Output format:**
```
src/main.go:42: func main() {
src/utils/helper.go:15: import "fmt"
```

**Respect .gitignore:**
- When using rg: automatic (rg respects .gitignore by default with `--no-ignore-global` or just default behavior)
- Pure-Go fallback: parse `.gitignore` if present in workDir, skip matching files

**Error handling:**
- Missing `pattern` param: `"missing parameter: pattern"`
- Invalid regex: return error message
- No matches: return `"No results found for pattern"`
- Binary files: skip silently
- Context cancelled: return context error
</action>

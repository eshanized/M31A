# Plan 4-04 — FileWrite Tool

Implement the FileWrite tool — atomic file write with temp-file + rename pattern, automatic backup before overwrite, directory creation, and path safety enforcement.

**Description:** Implement FileWrite tool in `internal/tools/filewrite.go`.

<read_first>

</read_first>

<action>
Create `internal/tools/filewrite.go` with:

```go
package tools

import (
    "context"
    "crypto/rand"
    "encoding/hex"
    "fmt"
    "os"
    "path/filepath"
    "strings"
    "time"

    "github.com/eshanized/M31A/internal/types"
    m31errors "github.com/eshanized/M31A/internal/errors"
)

type FileWrite struct {
    workDir   string
    backupDir string
}

func NewFileWrite(workDir, backupDir string) *FileWrite

func (t *FileWrite) Name() string           // returns "FileWrite"
func (t *FileWrite) Description() string    // tool description for LLM function calling
func (t *FileWrite) RiskLevel() types.RiskLevel  // returns RiskDestructive

func (t *FileWrite) Execute(ctx context.Context, input types.ToolInput) (types.ToolResult, error)
```

**Parameters:**
- `path` (string, required): File path to write (relative or absolute)
- `content` (string, required): Content to write
- `create_dirs` (bool, optional): Create parent directories if missing (default: true)

**Atomic write flow:**

1. **Path resolution:** Same safety checks as FileRead:
   - `filepath.Abs(path)` to get absolute path
   - `filepath.EvalSymlinks` to resolve symlinks (if file exists)
   - Verify resolved path is within workDir (`strings.HasPrefix`)
   - If file does not exist yet, resolve the directory portion only

2. **Binary content check:** Scan content for null bytes `\x00`. If found, return `m31errors.ErrNoBinaryContent`.

3. **Backup (if file exists):**
   - If target file already exists, copy it to `backupDir`:
   - Sanitized path: replace path separators in the relative path with underscores
   - Backup filename: `<sanitized_path>.<timestamp>`
   - Timestamp format: `time.Now().Format("20060102T150405")`
   - Ensure backupDir exists: `os.MkdirAll(backupDir, 0755)`

4. **Directory creation:** If `create_dirs` is true (default), call `os.MkdirAll(filepath.Dir(targetPath), 0755)`

5. **Temp file write:**
   - Generate 8 random hex bytes via `crypto/rand`, encode as hex string
   - Temp file path: `filepath.Dir(targetPath) + "/.m31a_tmp_" + randomHex`
   - Write content to temp file
   - Call `file.Sync()` (fsync) to ensure durability
   - Close temp file

6. **Atomic rename:** `os.Rename(tempFile, targetPath)` — atomic on same filesystem

7. **Cleanup:** Defer `os.Remove(tempFile)` to clean up if any step after creation fails

8. **Return:** `ToolResult{Output: fmt.Sprintf("Wrote %d bytes to %s", len(content), path)}`

**Error handling:**
- Missing `path` param: `"missing parameter: path"`
- Missing `content` param: `"missing parameter: content"`
- Binary content: `m31errors.ErrNoBinaryContent`
- Write fails: temp file cleaned up via defer
- Rename fails: both temp and original file remain intact (no data loss)
- Permission denied: `m31errors.ErrPermissionDenied`
- Path outside workDir: error message
</action>

<acceptance_criteria>
- `internal/tools/filewrite.go` compiles with zero errors
- Writing to a new file creates it with correct content
- Writing to an existing file creates a backup copy in backupDir
- Atomic write leaves no temp files after success
- Binary content returns ErrNoBinaryContent
- Missing params return appropriate errors
- Path outside workDir returns error
- `go build ./internal/tools/...` succeeds
</acceptance_criteria>

```go
func TestFileWrite_SimpleWrite(t *testing.T)
func TestFileWrite_OverwriteWithBackup(t *testing.T)
func TestFileWrite_CreateDirs(t *testing.T)
func TestFileWrite_PathOutsideWorkDir(t *testing.T)
func TestFileWrite_Atomicty(t *testing.T)
func TestFileWrite_BinaryContent(t *testing.T)
func TestFileWrite_MissingPathParam(t *testing.T)
func TestFileWrite_MissingContentParam(t *testing.T)
```

Use `t.TempDir()` for workDir. Create a dedicated backupDir in temp. Use `t.Parallel()` where independent.

**Test cases:**
- `TestFileWrite_SimpleWrite`: write to a new file, read it back, verify content matches
- `TestFileWrite_OverwriteWithBackup`: write file twice with different content, verify backup exists in backupDir with timestamp suffix, verify final content is the second write
- `TestFileWrite_CreateDirs`: write to `nested/deep/dir/file.txt`, verify directories created
- `TestFileWrite_PathOutsideWorkDir`: attempt to write outside workDir, verify error
- `TestFileWrite_Atomicty`: write file, verify no `.m31a_tmp_*` files remain in directory after successful write
- `TestFileWrite_BinaryContent`: write content with null bytes, verify ErrNoBinaryContent
- `TestFileWrite_MissingPathParam`: empty params, verify error
- `TestFileWrite_MissingContentParam`: params with path but no content, verify error
</action>

- Backup test verifies backup file exists with correct content

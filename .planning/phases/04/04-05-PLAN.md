<action>
Create `internal/tools/bash.go` with:

```go
package tools

import (
    "context"
    "fmt"
    "io"
    "os"
    "os/exec"
    "runtime"
    "strings"
    "sync"
    "syscall"
    "time"

    "github.com/eshanized/M31A/internal/types"
    m31errors "github.com/eshanized/M31A/internal/errors"
)

type Bash struct {
    workDir string
    output  strings.Builder
    mu      sync.Mutex
}

func NewBash(workDir string) *Bash

func (t *Bash) Name() string           // returns "Bash"
func (t *Bash) Description() string    // tool description for LLM function calling
func (t *Bash) RiskLevel() types.RiskLevel  // returns RiskDangerous

func (t *Bash) Execute(ctx context.Context, input types.ToolInput) (types.ToolResult, error)
```

**Parameters:**
- `command` (string, required): Shell command to execute
- `timeout` (int, optional): Override timeout in seconds (default: 1800 = 30 min)

**Execution flow:**

1. **Parameter validation:** Check `command` param exists, return error if missing

2. **Timeout:** Create context with timeout:
   ```go
   timeoutSec := 1800 // default 30 min
   if customTimeout, ok := input.Params["timeout"].(float64); ok {
       timeoutSec = int(customTimeout)
   }
   ctx, cancel := context.WithTimeout(ctx, time.Duration(timeoutSec)*time.Second)
   defer cancel()
   ```

3. **Command creation:**
   ```go
   var cmd *exec.Cmd
   if runtime.GOOS == "windows" {
       cmd = exec.CommandContext(ctx, "cmd", "/C", command)
   } else {
       cmd = exec.CommandContext(ctx, "bash", "-c", command)
   }
   cmd.Dir = t.workDir
   ```

4. **Process group (Linux/macOS):** Set `cmd.SysProcAttr = &syscall.SysProcAttr{Setpgid: true}` for clean child process cleanup on cancellation

5. **PTY allocation:**
   - On Linux/macOS: use `creack/pty` to allocate PTY
   - On Windows: use `cmd.StdoutPipe()` and `cmd.StderrPipe()`
   - Start the command

6. **Output streaming:**
   - Read from PTY/stdout in a goroutine
   - Accumulate output in `strings.Builder` (protected by `t.mu`)
   - Read from stderr (on Windows / non-PTY mode) similarly
   - Cap output at `BashOutputLimit` (50,000 chars) — if exceeded, stop reading and mark truncated

7. **Waiting for completion:**
   - `cmd.Wait()` for command exit
   - Collect exit code from `cmd.ProcessState.ExitCode()`

8. **Binary detection:** Scan first 512 bytes of output for null bytes (`\x00`):
   - If found: replace output with `fmt.Sprintf("[binary output, %d bytes]", outputLen)`
   - Otherwise: use text output as-is

9. **Signal forwarding on cancellation:**
   - On ctx cancellation/deadline, send `SIGINT` to process group:
   ```go
   if cmd.Process != nil {
       syscall.Kill(-cmd.Process.Pid, syscall.SIGINT)
       // After 5s grace, send SIGKILL
   }
   ```
   - Use `time.AfterFunc` for the SIGKILL escalation

10. **Return:** `ToolResult{Output: output, DurationMs: elapsed, Truncated: bool}`

**Error handling:**
- Missing `command` param: `"missing parameter: command"`
- Command not found: `m31errors.ErrToolExecution` with "command not found" message
- Non-zero exit: include exit code in error string, still return partial output
- Timeout: return partial output with context.DeadlineExceeded
- Permission denied: `m31errors.ErrPermissionDenied`
- Context cancelled: include partial output
</action>

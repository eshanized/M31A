2. Implement SaveRecoveryState(engine *Engine, path string) error that:
   - Snapshots all workflow state under appropriate locks

   - Loads last recovery state
   - Validates it
   - Restores engine state from recovery (phase, plan, messages)
   - Transitions state machine to recovered phase

   - After significant message batches

   - Checks if recovery file exists
   - If exists, loads and validates recovery state
   - Restores engine state
   - Returns nil on successful recovery, error if recovery impossible

   - Restore engine state (phase, plan, messages, checkpoint)

   - Log warning: "No recoverable state found, starting fresh"

   - Transitions state machine back to previous phase in history
   - Restores plan and messages from recovery state
   - Returns error if rollback not possible (e.g., already at Idle)
2. Ensure rollback is idempotent -- calling twice does not corrupt state
3. Log rollback at info level with reason

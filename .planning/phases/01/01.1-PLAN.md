## Task 01.1-B — Create ModelCache

**Description:** Implement a thread-safe model catalog cache with TTL-based expiry in `internal/provider/cache.go`.

<read_first>
- internal/types/constants.go (ModelCacheTTL = 5 * time.Minute)
- internal/types/types.go (ModelInfo struct)
- internal/provider/interface.go (provider package imports/types)
</read_first>

<action>
Create `internal/provider/cache.go` with:

```go
package provider

type ModelCache struct {
    mu       sync.RWMutex
    models   map[string]*types.ModelInfo
    fetched  time.Time
    ttl      time.Duration
    staleTTL time.Duration
}

func NewModelCache(ttl time.Duration) *ModelCache
func (c *ModelCache) Get(id string) (*types.ModelInfo, bool)
func (c *ModelCache) Set(models []types.ModelInfo)
func (c *ModelCache) IsExpired() bool
func (c *ModelCache) IsStale() bool
func (c *ModelCache) Len() int
func (c *ModelCache) FetchTime() time.Time
```

Implementation details:
- `Get()` acquires `RLock`, checks map + `IsExpired()`, returns `(*ModelInfo, true)` if found and not expired, else `(nil, false)`
- `Set()` acquires `Lock`, builds `map[string]*ModelInfo` keyed by `ModelInfo.ID`, sets `fetched = time.Now()`
- `IsExpired()` returns `time.Since(c.fetched) > c.ttl`
- `IsStale()` returns `time.Since(c.fetched) > c.staleTTL` (staleTTL = 24h)
- `staleTTL` is hardcoded to `24 * time.Hour` in `NewModelCache`
- Import `sync` and `time` from stdlib plus `github.com/eshanized/M31A/internal/types`
</action>

<acceptance_criteria>
- `NewModelCache(5*time.Minute)` creates cache with 5-minute TTL and 24-hour staleTTL
- `Set(models)` populates cache; `Get(id)` returns correct model
- `Get("nonexistent")` returns `(nil, false)`
- `IsExpired()` returns `true` after TTL elapses (test with short TTL)
- `IsStale()` returns `true` after 24h staleTTL
- `Len()` returns correct model count
- `FetchTime()` returns time close to when `Set()` was called
- Thread-safe: `go test -race` detects no races
- `go build ./internal/provider/...` succeeds
</acceptance_criteria>

## Task 01.1-C — Create SSE Parser

**Description:** Implement an SSE (Server-Sent Events) parser in `internal/provider/sse.go` that reads streaming HTTP responses and yields typed events.

<read_first>
- internal/types/types.go (StreamChunk struct)
- internal/provider/interface.go (provider package context)
</read_first>

<action>
Create `internal/provider/sse.go` with:

```go
package provider

type SSEParser struct {
    scanner *bufio.Scanner
    resp    *http.Response
}

func NewSSEParser(resp *http.Response) *SSEParser
func (p *SSEParser) Next() (eventType string, data string, err error)
func (p *SSEParser) Close() error
```

Implementation details:
- Use `bufio.NewScanner(resp.Body)` with a custom split function that splits on `\n\n` (blank line = SSE event boundary)
- Strip `data: ` prefix from each line in the event block
- Concatenate multi-line `data: ` fields within one event (join with no separator)
- Parse `event: ` lines to populate `eventType`
- Detect `data: [DONE]` sentinel → return `("", "", io.EOF)`
- `Close()` calls `resp.Body.Close()`
- If no `event: ` line is present and only `data: ` lines exist, return `eventType = ""` (most OpenAI-compatible SSE)
- Import `bufio`, `io`, `net/http`
</action>

<acceptance_criteria>
- `NewSSEParser` creates parser from `*http.Response` with body
- `Next()` on single `data: {"key":"val"}\n\n` returns `("", "{\"key\":\"val\"}", nil)`
- `Next()` on multi-line `data: line1\ndata: line2\n\n` returns `("", "line1line2", nil)`
- `Next()` with `event: message\ndata: hello\n\n` returns `("message", "hello", nil)`
- `Next()` on `data: [DONE]\n\n` returns `("", "", io.EOF)`
- `Close()` succeeds without error
- Empty stream returns `("", "", io.EOF)` on first `Next()` call
- `go build ./internal/provider/...` succeeds
</acceptance_criteria>

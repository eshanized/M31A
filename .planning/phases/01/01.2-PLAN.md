## Task 01.2-A — Create Reasoning Normalization

**Description:** Implement reasoning parameter normalization for different model families (deepseek, openai-o, anthropic, qwen).

<read_first>
- internal/types/types.go (StreamChunk struct — Type="thinking", Delta fields)
- internal/types/constants.go (no relevant constants)
- internal/provider/interface.go (provider package types)
</read_first>

<action>
Create `internal/provider/reasoning.go` with:

```go
package provider

type ReasoningConfig struct {
    ModelFamily   string
    RequestParams map[string]any
    SSEField      string
}

func GetReasoningConfig(modelID string) (ReasoningConfig, bool)
func ApplyReasoningParams(modelID string, body map[string]any) map[string]any
func ParseSSEChunk(data string, modelID string) (*types.StreamChunk, error)
```

Implementation details:
- `reasoningParamMap` (package-level `var`, not const):
  - Prefix `"deepseek"` → `ReasoningConfig{ModelFamily:"deepseek", RequestParams: map[string]any{}, SSEField:"choices[0].delta.reasoning_content"}`
  - Prefix `"openai/"` with `o-` model names → `ReasoningConfig{ModelFamily:"openai", RequestParams: map[string]any{"reasoning_effort":"medium"}, SSEField:"choices[0].delta.reasoning"}`
  - Prefix `"anthropic"` → `ReasoningConfig{ModelFamily:"anthropic", RequestParams: map[string]any{"thinking":map[string]any{"type":"enabled","budget_tokens":1024}}, SSEField:"choices[0].delta.content"}`
  - Prefix `"qwen"` → `ReasoningConfig{ModelFamily:"qwen", RequestParams: map[string]any{}, SSEField:"choices[0].delta.reasoning_content"}`
- `GetReasoningConfig`: iterate keys in `reasoningParamMap`, check if `modelID` starts with key. Note: also check for `"openai/o-"` prefix for o-series models. Return `(config, true)` or `(ReasoningConfig{}, false)`.
- `ApplyReasoningParams`: shallow merge `RequestParams` into body map, return modified body
- `ParseSSEChunk`: parse `data` as JSON into `map[string]any`. Extract `choices[0].delta.content` as content. Look up SSEField path — if field exists and is non-empty, set `StreamChunk.Type = "thinking"` with Delta from that field. If `choices[0].finish_reason` is non-nil, return type="done". If only content, return type="content". For anthropic: check if delta content has `type` field == `"thinking"`.
- Use `encoding/json` to unmarshal into `map[string]any`; use type assertions to extract nested values
- Helper: `getNestedField(m map[string]any, path string) (any, bool)` splits on `.` and walks the map tree
</action>

<acceptance_criteria>

- `GetReasoningConfig("openai/o1-mini")` returns `(config{ModelFamily:"openai"}, true)`
- `GetReasoningConfig("anthropic/claude-3-opus")` returns `(config{ModelFamily:"anthropic"}, true)`
- `GetReasoningConfig("qwen/qwen2.5")` returns `(config{ModelFamily:"qwen"}, true)`
- `GetReasoningConfig("unknown/model")` returns `(ReasoningConfig{}, false)`

## Task 01.2-B — Create Provider Registry

**Description:** Implement a thread-safe provider registry that manages multiple LLM providers.

<read_first>
- internal/provider/interface.go (LLMProvider interface, ChatRequest, ToolDefinition)
- internal/types/types.go (HealthStatus)
- internal/errors/errors.go (ErrProviderUnreachable, ErrModelNotFound)
</read_first>

<action>
Create `internal/provider/registry.go` with:

```go
package provider

import m31errors "github.com/eshanized/M31A/internal/errors"

type Registry struct {
    mu        sync.RWMutex
    providers map[string]LLMProvider
    active    string
}

func NewRegistry() *Registry
func (r *Registry) Register(name string, p LLMProvider)
func (r *Registry) Active() string
func (r *Registry) SetActive(name string) error
func (r *Registry) Get(name string) (LLMProvider, error)
func (r *Registry) List() []string
func (r *Registry) ActiveProvider() LLMProvider
```

Implementation details:
- `Register`: Lock, store `providers[name] = p`. If first registered, set `active = name`.
- `Active`: RLock, return `r.active`
- `SetActive`: Lock, check existence → `ErrModelNotFound` if missing, else set `r.active = name`
- `Get`: RLock, return provider or `ErrProviderUnreachable`
- `List`: RLock, collect sorted keys (use `sort.Strings` from stdlib)
- `ActiveProvider`: RLock, return `providers[r.active]` (nil if no active)
- Import `sync`, `sort` from stdlib + `m31errors`
</action>

<acceptance_criteria>
- `NewRegistry()` returns empty registry with empty active name
- `Register("or", client)` adds provider; `Active()` returns `"or"`
- `SetActive("or")` succeeds; `SetActive("unknown")` returns `ErrModelNotFound`
- `Get("or")` returns the registered provider; `Get("missing")` returns `ErrProviderUnreachable`
- `List()` returns registered names sorted
- `ActiveProvider()` returns the LLMProvider for the active name; returns nil when none active
- Thread-safe: `go test -race` detects no races
- `go build ./internal/provider/...` succeeds
</acceptance_criteria>

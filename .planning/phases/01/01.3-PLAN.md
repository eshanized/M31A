## Task 01.3 — Create OpenRouter Client

**Description:** Create `internal/provider/openrouter/client.go` with all methods of the `LLMProvider` interface plus the `New()` constructor.

<read_first>
- internal/provider/interface.go (LLMProvider, ChatRequest, ToolDefinition)
- internal/provider/cache.go (ModelCache type, NewModelCache)
- internal/provider/sse.go (SSEParser type, NewSSEParser)
- internal/provider/reasoning.go (GetReasoningConfig, ApplyReasoningParams, ParseSSEChunk)
- internal/types/types.go (ModelInfo, StreamIterator, StreamChunk, Usage, HealthStatus, Pricing)
- internal/types/constants.go (ModelCacheTTL, HTTPDialTimeout, DefaultContextLength)
- internal/errors/errors.go (ErrInvalidKey, ErrProviderUnreachable, ErrRateLimited, ErrContextExceeded, ErrModelNotFound)
</read_first>

<action>
Create `internal/provider/openrouter/client.go`:

**Package declaration:** `package openrouter`

**Struct:**
```go
type Client struct {
    apiKey     string
    baseURL    string
    httpClient *http.Client
    cache      *provider.ModelCache
}
```

**Imports needed:**
- `context`, `encoding/json`, `fmt`, `io`, `net`, `net/http`, `strings`, `time` (stdlib)
- `github.com/eshanized/M31A/internal/errors` (as `m31errors`)
- `github.com/eshanized/M31A/internal/provider`
- `github.com/eshanized/M31A/internal/types`

**Package-level var for version:**
```go
var Version = "dev" // overridden by ldflags at build time
```

**`New(apiKey string) (*Client, error)`:**
- If `apiKey` is empty, return `nil, m31errors.ErrInvalidKey`
- Construct `http.Client`:
  - `Transport`: `&http.Transport{DialContext: (&net.Dialer{Timeout: 30 * time.Second}).DialContext}`
  - **No Timeout field on http.Client** — streaming responses must not have a body read timeout
- `baseURL = "https://openrouter.ai/api/v1"`
- `cache = provider.NewModelCache(types.ModelCacheTTL)`
- Return `&Client{...}, nil`

**`Name() string`:**
- Return `"openrouter"`

**`FetchModels(ctx context.Context) ([]types.ModelInfo, error)`:**
- Check cache first: if not expired, return cached models
- Build GET request: `baseURL + "/models"`
- Set headers: `Authorization: Bearer <apiKey>`, `User-Agent: M31A/<Version>`
- Execute with `c.httpClient.Do(req)`
- Check status: non-200 → if cache is not stale (< 24h), return stale cached data; otherwise return error
- Decode JSON response:
  - OpenRouter returns `{"data": [...]}` — parse `data` array
  - Map each element:
    - `id` → `ModelInfo.ID`
    - `name` → `ModelInfo.Name`
    - `description` → `ModelInfo.Description`
    - `context_length` → `ModelInfo.ContextLength` (int64)
    - `pricing.prompt_token` → `ModelInfo.Pricing.InputPerMToken` (multiply by 1,000,000 — OpenRouter price is per token)
    - `pricing.completion_token` → `ModelInfo.Pricing.OutputPerMToken` (multiply by 1,000,000)
    - `architecture.modality` → parse for CapFlags. If contains `"text"`, set tools/reasoning based on additional fields (check `architecture.tokenizer` for tool support)
    - `top_provider` → `ModelInfo.TopProvider`
- Call `c.cache.Set(models)` on success
- Return models, nil

**`ChatCompletionStream(ctx context.Context, req provider.ChatRequest) (*types.StreamIterator, error)`:**
- Build request body as `map[string]any`:
  - `"model"`: req.Model
  - `"messages"`: serialize req.Messages
  - `"max_tokens"`: req.MaxTokens (if > 0)
  - `"stream"`: true
  - `"tools"`: req.Tools (if non-empty)
- If `req.ReasoningEnabled`, call `provider.ApplyReasoningParams(req.Model, body)` to merge reasoning params
- Marshal body to JSON
- POST to `baseURL + "/chat/completions"`
- Headers: `Authorization: Bearer <apiKey>`, `Content-Type: application/json`, `Accept: application/json`, `HTTP-Referer: https://github.com/eshanized/M31A`, `X-Title: M31A`, `User-Agent: M31A/<Version>`
- Execute request; handle non-200 responses:
  - 429 → return nil, `m31errors.ErrRateLimited`
  - 401 → return nil, `m31errors.ErrInvalidKey`
  - 503 → return nil, `m31errors.ErrProviderUnreachable`
  - 400 with "context_length" or "context" in body → return nil, `m31errors.ErrContextExceeded`
- Create `provider.NewSSEParser(resp)` to parse stream
- Return `&types.StreamIterator{Next: nextFn, Close: closeFn}`:
  - `nextFn`: call `sse.Next()` → (`eventType`, `data`, `err`). If `err == io.EOF`, return `(nil, io.EOF)`. Otherwise call `provider.ParseSSEChunk(data, req.Model)` to get typed `*types.StreamChunk`. Return `(chunk, nil)`.
  - `closeFn`: call `sse.Close()`, return error if any
- Handle `event: message` type events (non-standard SSE from OpenRouter): parse data field as JSON with `choices[0].delta.content`

**`EstimateCost(usage types.Usage) float64`:**
- Look up model in cache via unknown ID — this method needs a model parameter or uses the active model. Actually, let's use a modelID parameter:
  - Wait, the interface is `EstimateCost(usage types.Usage) float64` — it doesn't take a modelID. Hmm.
  - Look at the spec again: "Look up model in cache by ID" — but EstimateCost doesn't receive a model ID.
  - Since `EstimateCost` in `LLMProvider` only takes `Usage`, we need to find the model some other way.
  - **Implementation:** Iterate all cached models and use the first one's pricing as a fallback, OR we need to change the approach.
  - **Best approach:** Since we can't know the model from `Usage` alone, return 0 if no model can be determined. The method signature was defined by Phase 0 and we must keep it.
  - Iterate over cache: if only one model cached (unlikely) use its pricing. Otherwise return 0.
  - Actually, looking at this more carefully, the interface method `EstimateCost(usage types.Usage) float64` can't look up a specific model because it doesn't know which model was used. **Deviation decision:** We'll need to add a `modelID` field or the caller should use `GetModel` + compute cost themselves. For now, return the average or max pricing across all cached models, or 0.
  - **Decision:** Return 0 (not implemented in V1). The actual cost estimation will require a model ID which should be added to the interface in a future phase. Document this as a known limitation.

**`HealthCheck(ctx context.Context) types.HealthStatus`:**
- Build GET request: `baseURL + "/auth/key"` with `Authorization: Bearer <apiKey>`
- Record start time: `start := time.Now()`
- Execute with `c.httpClient.Do(req)`
- Calculate `latency := time.Since(start).Milliseconds()`
- Determine status:
  - `resp.StatusCode == 200` and `latency < 200` → `"live"`
  - `resp.StatusCode == 200` and `latency < 500` → `"slow"`
  - Otherwise → `"offline"` (include error message if non-200)
- Return `types.HealthStatus{Status: status, LatencyMs: latency}`

**`GetModel(id string) (*types.ModelInfo, error)`:**
- Call `c.cache.Get(id)`
- Return `(model, true)` or `(nil, m31errors.ErrModelNotFound)`

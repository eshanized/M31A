## Bug Fixes During Development
1. **SSE parser rewrite**: `bufio.Scanner` with line-by-line `ScanLines` instead of custom split function — fixes multi-line data concatenation and event type detection.
2. **OpenAI prefix matching**: Added `strings.HasPrefix(modelName, "o1")` and `strings.HasPrefix(modelName, "o3")` for models like `o1-mini`.
3. **SSEField format**: Changed from `choices[0].` to `choices.0.` (dot-only) — `strings.Split` on `"."` doesn't split bracket notation.
4. **budget_tokens type assertion**: Accept both `int` and `float64` for `budget_tokens` in tests (Go `json.Unmarshal` into `map[string]any` produces `float64`, but direct map literals produce `int`).
5. **Error body read order**: Read response body before calling `resp.Body.Close()` in non-200 error paths.
6. **FetchModels cache bypass**: Removed premature cache-hit return — always fetch API fresh.

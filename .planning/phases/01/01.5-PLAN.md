## Task 01.5-A — Create Auto-Fallback Logic

**Description:** Implement `ShouldFallback()` and `FindFallbackProvider()` for automatic provider switching on 429/503 errors.

<read_first>
- internal/provider/registry.go (Registry type, ActiveProvider, Get, List)
- internal/types/types.go (HealthStatus struct)
- internal/errors/errors.go (ErrProviderUnreachable, ErrRateLimited)
</read_first>

<action>
Create `internal/provider/fallback.go`:

```go
package provider

type FallbackEvent struct {
    From   string
    To     string
    Reason string // "rate_limited" | "unavailable"
}

func ShouldFallback(statusCode int) bool
func FindFallbackProvider(registry *Registry, currentProvider string) (string, *FallbackEvent, error)
```

Implementation details:
- `ShouldFallback(statusCode int) bool`: return `true` if statusCode is 429 or 503, `false` otherwise
- `FallbackEvent.From`: set to `currentProvider`
- `FallbackEvent.To`: set to the chosen alternative provider name
- `FallbackEvent.Reason`: `"rate_limited"` for 429, `"unavailable"` for 503
- `FindFallbackProvider`: 
  1. Get all registered providers via `registry.List()`
  2. For each provider that is NOT `currentProvider`, try `registry.Get(name)` → call `HealthCheck(ctx)` with a short timeout context (`context.WithTimeout`, 5 seconds)
  3. If health check returns `"live"` or `"slow"`, select this provider
  4. Set the registry active to the selected provider: `registry.SetActive(selected)`
  5. Build `FallbackEvent{From: currentProvider, To: selected, Reason: reason}`
  6. If no healthy alternative found, return `("", nil, m31errors.ErrProviderUnreachable)`
- Use `context.Background()` with a 5-second timeout for health checks during fallback
</action>

<acceptance_criteria>
- `ShouldFallback(429)` returns `true`
- `ShouldFallback(503)` returns `true`
- `ShouldFallback(200)` returns `false`
- `ShouldFallback(401)` returns `false`
- `FindFallbackProvider` with a healthy alternative provider returns the alternative name and a `FallbackEvent`
- `FindFallbackProvider` with no healthy alternative returns `ErrProviderUnreachable`
- `FallbackEvent.From`, `To`, and `Reason` fields are correctly populated
- `go build ./internal/provider/...` succeeds
</acceptance_criteria>

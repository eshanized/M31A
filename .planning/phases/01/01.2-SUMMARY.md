# Summary 01.2 — Reasoning Normalization + Provider Registry

## Files Created
- `internal/provider/reasoning.go` — `ReasoningConfig`, `GetReasoningConfig`, `ApplyReasoningParams`, `ParseSSEChunk`, `getNestedField` helper
- `internal/provider/registry.go` — `Registry` with `Register`/`SetActive`/`Get`/`List`/`Active`/`ActiveProvider`

## Deviations from Plan
- **SSEField format**: Plan used `choices[0].delta.reasoning_content` (bracket notation); actual uses `choices.0.delta.reasoning_content` (dot-only) because `strings.Split` on `"."` splits `choices[0]` as one token. Both `getNestedField` and the SSE field detection use the dot-only format consistently.
- **OpenAI prefix matching**: Plan specified prefix `"openai/o-"`; actual also handles `strings.HasPrefix(modelName, "o1")` and `strings.HasPrefix(modelName, "o3")` for models like `o1-mini` that don't start with `o-`.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CI -> external repos | Compat matrix clones untrusted OSS repos — must not execute arbitrary code beyond build |
| Release pipeline -> GitHub | GoReleaser creates releases with GITHUB_TOKEN — must not leak token |
| Tag push -> release | Malformed tags must not trigger broken releases |
| Compat matrix script -> shell execution | Script executes build commands on cloned repos — must be sandboxed |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07-05 | Tampering | Compat matrix clones | medium | mitigate | Clone to temp dirs, build with CGO_ENABLED=0, no execution of project binaries, trap for cleanup |
| T-07-06 | Information Disclosure | Release workflow | medium | mitigate | GITHUB_TOKEN scoped to repo, no secrets in build artifacts, draft release requires manual publish |
| T-07-07 | Denial of Service | Validate-release script | low | accept | Script has timeout via Makefile, fails fast with set -euo pipefail |
| T-07-08 | Elevation of Privilege | Tag-triggered release | low | mitigate | Manual approval via GitHub Environments prevents unauthorized releases |
| T-07-10 | Tampering | Compat matrix build script | medium | mitigate | Script uses set -euo pipefail, validates JSON output, no eval of repo-provided code, only runs standard build commands (go build, npm run build, etc.) |
</threat_model>

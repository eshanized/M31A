# Plan 02: Critical Coverage Gap Tests

## Objective
Address critical coverage gaps (<25%) in packages with security-sensitive code or core functionality.

## Context
Based on AUDIT_REPORT.md, these packages have critical coverage gaps:
- `internal/tools/search/` (2%) — Contains SSRF protection, web fetch, web search (SECURITY CRITICAL)
- `internal/core/types/` (15.6%) — Shared type vocabulary across all layers
- `cmd/m31a/` (21.6%) — Main entry point
- `internal/integrations/keychain/` (25.1%) — API key management (SECURITY CRITICAL)

## Tasks

<read_first>
- `internal/tools/search/webfetch.go` — Web fetch with SSRF protection

<action>
Create/extend test files:
- `internal/tools/search/webfetch_test.go` — Extend existing tests for redirect handling, DNS pinning
- `internal/tools/search/websearch_test.go` — Test IP filtering bug fix (SEC-05), result parsing

Focus on:

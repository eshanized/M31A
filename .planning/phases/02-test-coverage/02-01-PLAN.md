# Plan 01: Zero-Coverage Package Tests

## Objective
Create initial test files for packages with 0% coverage, establishing the foundation for the 75% coverage target.

## Context
Based on AUDIT_REPORT.md, five packages have 0% test coverage and need immediate attention:
- `internal/tools/exec/` — Command execution, timeout handling, sandbox behavior
- `internal/tools/fileops/` — File read/write/modify operations, atomic writes
- `internal/tools/network/` — HTTP client, network operations
- `internal/tools/ai/` — AI tool invocations
- `internal/integrations/provider/nvidia/` — Nvidia provider API integration

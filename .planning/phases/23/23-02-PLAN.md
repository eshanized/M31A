### Task 1: Add Badge Colors to Theme Struct

**read_first:**
- `internal/tui/theme/colors.go` (full file — Dark() and Light() functions)
- Find where Theme struct is defined (likely `internal/tui/theme/theme.go` or `colors.go`)

**action:**
1. Add three new fields to the Theme struct:
   ```go
   BadgeForeground string  // "#000000" for dark, "#000000" for light (both use black on colored badges)
   BadgeTextLight  string  // "#FFFFFF" — white text on dark badges
   BadgeTextDark   string  // "#000000" — black text on light badges
   ```
2. In `Dark()`, set:
   ```go
   t.BadgeForeground = "#000000"
   t.BadgeTextLight = "#FFFFFF"
   t.BadgeTextDark = "#000000"
   ```
3. In `Light()`, set the same values (both themes use black badge foreground currently)
4. Extract `buildBadgeStyles(t *Theme)` helper that sets all 8 ToolLabel/Badge styles using `t.BadgeForeground` instead of hardcoded `"#000000"` (S-9):
   ```go
   func buildBadgeStyles(t *Theme) {
       fg := lipgloss.Color(t.BadgeForeground)
       t.ToolLabel["Bash"] = lipgloss.NewStyle().Background(lipgloss.Color(t.Warning)).Foreground(fg).Padding(0, 1).Bold(true)
       t.ToolLabel["FileRead"] = lipgloss.NewStyle().Background(lipgloss.Color(t.Info)).Foreground(fg).Padding(0, 1).Bold(true)
       t.ToolLabel["FileWrite"] = lipgloss.NewStyle().Background(lipgloss.Color(t.Brand)).Foreground(fg).Padding(0, 1).Bold(true)
       t.ToolLabel["Glob"] = lipgloss.NewStyle().Background(lipgloss.Color(t.TextSecondary)).Foreground(fg).Padding(0, 1).Bold(true)
       t.ToolLabel["Grep"] = lipgloss.NewStyle().Background(lipgloss.Color(t.Info)).Foreground(fg).Padding(0, 1).Bold(true)
       t.SuccessBadge = lipgloss.NewStyle().Background(lipgloss.Color(t.Success)).Foreground(fg).Padding(0, 1).Bold(true)
       t.ErrorBadge = lipgloss.NewStyle().Background(lipgloss.Color(t.Error)).Foreground(fg).Padding(0, 1).Bold(true)
       t.WarningBadge = lipgloss.NewStyle().Background(lipgloss.Color(t.Warning)).Foreground(fg).Padding(0, 1).Bold(true)
   }
   ```
5. Call `buildBadgeStyles(t)` at end of both `Dark()` and `Light()` instead of inline style assignments
6. For Header and ModelBadge (T-2), replace hardcoded `"#FFFFFF"` with `t.BadgeTextLight`:
   ```go
   t.Header = lipgloss.NewStyle().Foreground(lipgloss.Color(t.BadgeTextLight)).Bold(true)
   t.ModelBadge = lipgloss.NewStyle().Foreground(lipgloss.Color(t.BadgeTextLight)).Bold(true)
   ```

**acceptance_criteria:**
- Theme struct has `BadgeForeground`, `BadgeTextLight`, `BadgeTextDark` fields
- `Dark()` and `Light()` set these fields
- `buildBadgeStyles()` helper exists and is called from both `Dark()` and `Light()`
- No inline `#000000` in badge style construction within `colors.go`
- No inline `#FFFFFF` for Header/ModelBadge in `colors.go`

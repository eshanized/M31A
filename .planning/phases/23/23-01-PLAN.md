# Plan 23-01: Provider Function Extraction & Bug Fixes

## Objective
Extract 8 duplicated functions from OpenRouter and Zen clients into shared files, fix 2 bugs (unbounded body read, missing ResponseHeaderTimeout), and centralize health status strings.

## Tasks

### Task 1: Create `internal/provider/common.go` with Shared Functions

**read_first:**
- `internal/provider/openrouter/client.go` (lines 266-276, 197-202, 355-362, 364-367, 307-314, 347-353, 371-421, 205-218)
- `internal/provider/zen/client.go` (lines 253-263, 179-184, 335-342, 344-347, 287-294, 327-333, 351-401, 187-200)
- `internal/provider/interface.go` (ModelCache interface if exists)
- `internal/types/constants.go`

**action:**
1. Create `internal/provider/common.go` in the `provider` package
2. Extract `isContextExceeded(statusCode int, body string) bool` — exact duplicate from both clients (S-1)
3. Extract `sanitizeProviderError(statusCode int, body string, providerName string) string` — near-duplicate with `providerName` parameter for the 2 behavioral differences: Zen appends body text for 401/502, OpenRouter does not. Use the OpenRouter rune-by-rune HTML stripping (more efficient). For 401: if providerName == "zen" and body is non-empty, append `": " + cleaned`. For 502: if providerName == "zen", use `fmt.Sprintf("Provider gateway error (HTTP %d) — try again later", statusCode)` + `": " + cleaned` (S-2)
4. Extract `setCommonHeaders(req *http.Request, apiKey string, version string)` — sets Authorization and User-Agent headers (S-6)
5. Extract `buildChatBody(req ChatRequest) map[string]any` — identical body construction for model, messages, stream, max_tokens, tools, reasoning (S-7)
6. Extract `EstimateCost(modelID string, usage Usage, cache *ModelCache) float64` — identical cost calculation (S-8)
7. Extract `GetModel(id string, cache *ModelCache) (*ModelInfo, error)` — identical cache lookup (S-8)
8. Extract `CachedModels(cache *ModelCache) []ModelInfo` — identical model collection (S-5)
9. Extract `StaleFallback(cache *ModelCache) ([]ModelInfo, error)` — identical stale cache logic (S-4)
10. Add health status string constants to `internal/types/constants.go`:
    ```go
    const (
        HealthStatusLive     = "live"
        HealthStatusSlow     = "slow"
        HealthStatusOffline  = "offline"
        HealthStatusDegraded = "degraded"
    )
    ```
    (S-12)

**acceptance_criteria:**
- `internal/provider/common.go` exists and compiles
- Contains: `isContextExceeded`, `sanitizeProviderError`, `setCommonHeaders`, `buildChatBody`, `EstimateCost`, `GetModel`, `CachedModels`, `StaleFallback`
- `internal/types/constants.go` contains `HealthStatusLive`, `HealthStatusSlow`, `HealthStatusOffline`, `HealthStatusDegraded`

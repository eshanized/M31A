### Task 1: Fix Config Bool Override Bug (G-4)

**read_first:**
- `internal/config/loader.go` (lines 187-189 — mergeField for bools)

**action:**
1. The current `mergeField` for bools only overwrites if `overlay.Bool()` is `true`, meaning `false` values in project config cannot override `true` defaults
2. Fix by tracking whether the overlay field was explicitly set. Options:
   - Use `toml.Undefined()` check if BurntSushi/toml supports it
   - Use `reflect` to check if the field was explicitly set in the TOML
   - Simplest approach: use `*bool` pointer type in the config struct — `nil` means "not set", `false` means "explicitly false"
3. If using pointer approach:
   - Change relevant bool fields to `*bool` in config structs
   - Update `mergeField` to check `overlay.IsNil()` before deciding whether to overwrite
   - Update `DefaultConfig()` to set pointer values
   - Update all config readers to dereference pointers with defaults
4. If BurntSushi/toml has `IsDefined(key)` method, use that instead (cleaner)
5. Add comment documenting the fix

**acceptance_criteria:**
- `mergeField` correctly handles `false` overriding `true`
- Setting `compact_mode = false` in project config overrides `compact_mode = true` in global config
- `go test ./internal/config/...` passes (add test if feasible)

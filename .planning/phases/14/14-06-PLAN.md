types: `WorkflowCoordinator`, `ScreenRouter`, and `StreamCoordinator`. Each
coordinator owns a coherent slice of state and the message handlers that
mutate it. `AppState.Update()` becomes a thin router that dispatches

be cleanly added without first decomposing this monolith.

import (

    tea "github.com/charmbracelet/bubbletea"

type ScreenRouter struct {
    app                      *AppState
    screen                   Screen
    prevScreen               Screen
    diffModel                DiffModel
    discussQuestions         []string
    pendingDiscussAnswers    map[int]string
    currentDiscussIndex      int
    discussAnswerTimeout     *time.Timer
}

func NewScreenRouter(app *AppState) *ScreenRouter {
    return &ScreenRouter{
        app:                  app,
        screen:               ScreenREPL,
        prevScreen:           ScreenREPL,
        pendingDiscussAnswers: make(map[int]string),
    }
}

func (sr *ScreenRouter) Handle(msg tea.Msg) (*AppState, tea.Cmd) {
    switch msg := msg.(type) {
    case AppMsg:
        return sr.handleAppMsg(msg)
    case PhaseDiscussStartedMsg:  // emitted by WorkflowCoordinator
        return sr.handleDiscussStarted(msg)
    case DiscussAnswerTimeoutMsg:  // if not handled by WorkflowCoord, SR handles
        return sr.handleDiscussTimeout(msg)
    }
    return sr.app, nil
}

func (sr *ScreenRouter) handleAppMsg(msg AppMsg) (*AppState, tea.Cmd) {
    sr.prevScreen = sr.screen
    sr.screen = msg.Screen
    return sr.app, nil
}

func (sr *ScreenRouter) Navigate(s Screen) {
    sr.prevScreen = sr.screen
    sr.screen = s
}

func (sr *ScreenRouter) Back() {
    if sr.prevScreen != sr.screen {
        sr.screen, sr.prevScreen = sr.prevScreen, sr.screen
    }
}

func (sr *ScreenRouter) Current() Screen     { return sr.screen }
func (sr *ScreenRouter) Previous() Screen    { return sr.prevScreen }
func (sr *ScreenRouter) IsRepl() bool        { return sr.screen == ScreenREPL }
func (sr *ScreenRouter) IsWorkflow() bool    { return sr.screen == ScreenPlan || sr.screen == ScreenExecute || sr.screen == ScreenVerify || sr.screen == ScreenShip }

// Plus handleDiscussStarted (sets discussQuestions, currentDiscussIndex=0),
// handleDiscussTimeout (clears the timer, advances discussQuestions if needed).
```

package tui

import (
    "sync/atomic"

    tea "github.com/charmbracelet/bubbletea"
)

type StreamCoordinator struct {
    app              *AppState
    streamBuf        []byte       // accumulated streamed content
    streamTokenCount int64
    lastStreamError  error
    streaming        atomic.Bool  // true while a stream is active
}

func NewStreamCoordinator(app *AppState) *StreamCoordinator {
    return &StreamCoordinator{
        app: app,
    }
}

func (sc *StreamCoordinator) Handle(msg tea.Msg) (*AppState, tea.Cmd) {
    switch msg := msg.(type) {
    case StreamMsg:
        return sc.handleStreamMsg(msg)
    case StreamChunkMsg:  // added in Plan 05
        return sc.handleStreamChunk(msg)
    case StreamDoneMsg:
        return sc.handleStreamDone(msg)
    case StreamErrorMsg:
        return sc.handleStreamError(msg)
    }
    return sc.app, nil
}

func (sc *StreamCoordinator) handleStreamMsg(msg StreamMsg) (*AppState, tea.Cmd) {
    sc.streamBuf = append(sc.streamBuf, []byte(msg.Content)...)
    sc.streamTokenCount++
    sc.streaming.Store(true)
    // Forward to ReplModel
    sc.app.replModel.AppendStream(msg.Content)
    return sc.app, nil
}

func (sc *StreamCoordinator) handleStreamChunk(msg StreamChunkMsg) (*AppState, tea.Cmd) {
    // Same as handleStreamMsg but with chunk metadata
    return sc.app, nil
}

func (sc *StreamCoordinator) handleStreamDone(StreamDoneMsg) (*AppState, tea.Cmd) {
    sc.streaming.Store(false)
    sc.app.replModel.FinalizeStream()
    return sc.app, nil
}

func (sc *StreamCoordinator) handleStreamError(msg StreamErrorMsg) (*AppState, tea.Cmd) {
    sc.streaming.Store(false)
    sc.lastStreamError = msg.Err
    sc.app.replModel.AppendError(msg.Err.Error())
    return sc.app, nil
}

// Query methods for View() and others
func (sc *StreamCoordinator) IsStreaming() bool { return sc.streaming.Load() }
func (sc *StreamCoordinator) Buffer() []byte     { return sc.streamBuf }
```

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Coordinator → Coordinator | Coordinators do not call each other directly. They communicate only via the shared `*AppState` back-reference. This is intentional — the dispatch happens in AppState.Update(). |
| Coordinator → AppState | Coordinators read cross-cutting state from `app` (config, dispatcher, etc.) but never mutate it directly. Mutations go through AppState methods. |
| Test → Coordinator | Tests construct coordinators with a minimal `&AppState{}` and verify state changes in isolation. No real LLM, no real provider, no real session. |
| AppState.Update() → Coordinator.Handle() | AppState is the single point of entry for messages. The dispatch is a type switch. No coordinator may call another coordinator's `Handle()`. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-14-06-01 | Tampering | Coordinator mutates cross-cutting AppState fields outside its scope | mitigate | Coordinators only mutate their own fields. Reads of cross-cutting state go through passthrough methods. Linter rule (or code review) ensures no `app.foo = bar` in coordinator Handle() bodies. |
| T-14-06-02 | Denial of Service | Coordinator goroutines leak (Bubble Tea single-threaded invariant violation) | mitigate | Coordinators do not spawn goroutines. They only mutate state in `Handle()`. Audit: `rg "go func" internal/tui/*_coordinator.go` returns zero matches. |
| T-14-06-03 | Information Disclosure | Coordinator exposes internal state to other coordinators via shared pointer | accept | Coordinators share `*AppState` (the back-reference). This is acceptable because AppState is the central state owner. Future V1.1 subagents will introduce a stricter boundary. |
| T-14-06-04 | Race Condition | Coordinator state mutated from non-Update() goroutine (e.g., timer callback) | mitigate | All coordinator state mutations are in `Handle()`. The `time.NewTimer` callback in `discussAnswerTimeout` returns a `tea.Cmd` that emits `DiscussAnswerTimeoutMsg` — the actual mutation happens in `Handle()`. |
| T-14-06-05 | Refactor Regression | Behavior change during code motion | mitigate | All existing tests must pass without modification. Per-task verification runs the full test suite. The refactor is a pure structural change. |
| T-14-06-06 | Backward Reference Cycle | WorkflowCoordinator holds *AppState, AppState holds *WorkflowCoordinator | accept | This is a known cycle and is acceptable in Go (garbage collector handles it). The cycle is broken at shutdown when AppState is destroyed. |

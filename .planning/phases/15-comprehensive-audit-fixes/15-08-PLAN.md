<objective>
Fix audit findings **H-11, H-19 (High) and M-12, M-14, M-17, M-23,
M-24 (Medium) and L-7, L-8 (Low)** — typed error rendering, dead
config wiring, and `/optimize` integration.

- **H-11** — When the provider returns `ErrContextExceeded`, the
  TUI shows a generic error banner. The user cannot distinguish
  "context full" from "network error" or "auth failed".
- **H-19** — `pkg/arbitrage` is implemented but never called. The
  `/optimize` command (and the `O` key in the Plan screen) should
  invoke `arbiter.SuggestAll(tasks)` and display the cost-savings
  suggestions. Currently the command prints a TODO.
- **M-12** — `AutoArbitrage` config flag is set in
  `internal/config/types.go` but never read anywhere. The
  orchestrator ignores it.
- **M-14** — `ArbitrageThreshold` config field (a float, default
  0.15) is never read. The arbitrage scorer should use it as the
  minimum savings ratio to accept a suggestion.
- **M-17** — `AutoCollapseTools` config flag is never honored.
  The tool card is always expanded by default.
- **M-23** — `ShowCostEstimate` config flag is read once at
  startup but not toggled at runtime. The `/cost` command exists
  but does not flip the flag.
- **M-24** — TUI debug-mode logs the error message but not the
  typed sentinel name. The operator cannot tell which sentinel
  fired.
- **L-7** — API key indicator in the header is missing. The user
  cannot tell which provider's key is loaded.
- **L-8** — The Plan screen's "O" key (accept all suggestions)
  does not invoke arbitrage. Same root cause as H-19.

**Output:** Wired `/optimize` + Plan "O" key to arbitrage, typed
error banner for `ErrContextExceeded`, config flags actually read
at runtime, API key masked indicator in header. One new test
file with 6 regression tests.
</objective>

    Replace the TODO in the `/optimize` handler with:
    ```go
    func (m *AppState) executeOptimize() tea.Cmd {
        return func() tea.Msg {
            threshold := m.config.Model.ArbitrageThreshold
            if threshold <= 0 {
                threshold = 0.15
            }
            if !m.config.Model.AutoArbitrage {
                return InfoMsg{Text: "AutoArbitrage disabled in config; pass --force to override"}
            }
            catalog, err := m.registry.Get(m.registry.Active())
            if err != nil {
                return ErrorMsg{Err: err}
            }
            models, err := catalog.FetchModels(context.Background())
            if err != nil {
                return ErrorMsg{Err: err}
            }
            recs := arbitrage.Recommend(context.Background(), m.tasks, models, threshold)
            return OptimizedMsg{Recommendations: recs}
        }
    }
    ```
    Where `OptimizedMsg` is a new typed message in
    `internal/tui/types.go`:
    ```go
    type OptimizedMsg struct {
        Recommendations []arbitrage.ArbitrageRecommendation
    }
    ```

    The Plan screen's "O" key calls the same function.

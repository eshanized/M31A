<objective>
Fix audit findings **M-6, M-7, M-16, M-18, M-19, M-20, M-27, M-28, M-29,
M-31 (Medium) and L-13, L-16 (Low)** in the session, ledger, rollback,
and AutoDream packages.

- **M-6** — `Session` struct lacks a `ResumedAt` field. The
  `/ledger` and `/rollback` commands cannot tell "first run" from
  "resumed 3 times today" because the timestamp is lost.
- **M-7** — `AutoDream.Consolidate` can be re-entered. If
  context hits 99% and the user types `/compress` in the same
  tick, two consolidation runs enter a nested state and
  double-summarize messages.
- **M-16** — `Ledger.Stats()` re-parses the entire LEDGER.md on
  every call. The Resume browser calls Stats() per session in
  a loop; on a 200-session LEDGER, this is 200 full parses.
- **M-18** — `Session.Save` writes a non-atomic JSON for
  `session.json`. A crash mid-write leaves a partial file.
- **M-19** — `pkg/session/planning.go` writes
  PROJECT.md/TASKS.md/STATE.md non-atomically. A crash mid-write
  corrupts the planning directory.
- **M-20** — `Session.Checkpoint` writes are not atomic. Same
  issue.
- **M-27** — `pkg/rollback.Chain` returns commits in
  chronological order (oldest first). The TUI list expects
  newest-first.
- **M-28** — `pkg/rollback.SoftReset` updates git but does not
  update TASKS.md. Tasks remain `StatusDone` in the file even
  though git history was rewound.
- **M-29** — `pkg/bisect.Run` returns a generic `error` when
  `git bisect reset` fails. Callers cannot distinguish
  "no commits" from "no offender found".
- **M-31** — `Ledger.Query` has no case-insensitive matching
  for project type. A query for `python` does not match
  entries stored as `Python`.
- **L-13** — `Session.ID` is not validated for length 8
  lowercase alphanumeric (per spec). A typo in a config file
  produces a session ID like `My-Session-01`.
- **L-16** — `Checkpoint` retains the prior file in addition
  to the new one, exceeding the "last 2 only" spec.

**Output:** `ResumedAt` field + Load wire-up, AutoDream re-entry
guard, ledger stats cache with mtime invalidation, atomic
session/planning/checkpoint writes, rollback chain ordering +
TASKS.md sync, typed bisect errors, ledger case-insensitive
query, session ID validation, checkpoint retention. One new
test file with 7 regression tests.
</objective>

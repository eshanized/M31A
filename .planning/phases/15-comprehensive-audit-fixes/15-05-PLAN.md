<objective>
Fix audit findings **C-2 (CRITICAL) and H-7, H-12, M-8, M-9, M-10, M-11,
M-13, M-15 (Medium/High)** in the provider resilience surface.

- **C-2** — `LLMProvider` interface is missing the `APIKey()` accessor.
  The TUI Settings screen wants to show "OpenRouter key: ••••abcd"
  to confirm a key is loaded, but the current interface cannot
  expose the key without leaking the entire provider struct.
- **H-7** — Fallback on 429 uses a fixed 10s health-check timeout and
  ignores the `Retry-After` header. Real providers (OpenRouter) return
  a Retry-After in seconds that the current code does not respect.
- **H-12** — `ProviderRegistry.SetActive(name)` does not validate that
  `name` is non-empty. Calling with `""` panics on a nil deref inside
  the registry map.
- **M-8** — Model cache `Refresh()` is not single-flight. If the TUI
  re-renders 60x/sec and 2 timers fire on the same tick, two HTTP
  GET /models requests are issued.
- **M-9** — `SSEParser.Next()` does not close the underlying
  `http.Response.Body` on iterator `Close()`. A torn-down stream
  leaks the connection.
- **M-10** — Fallback uses a callback (`FallbackCallback func(...)`)
  that the TUI must register. The callback is invoked synchronously
  from a goroutine, which can block the TUI Update loop if the
  callback writes to a full channel.
- **M-11** — `ChatCompletionStream` does not run a pre-flight
  `tokens.Estimator` check. A request that would exceed the context
  window is sent over the wire and the provider rejects it with 400,
  wasting a turn.
- **M-13** — SSE parser emits no typed error on truncated streams. A
  connection that drops mid-stream (after `data: {` but before
  `data: [DONE]`) yields an untyped `io.ErrUnexpectedEOF`.
- **M-15** — `FallbackEvent` is a `struct{...}` value, not a pointer.
  The TUI cannot tell "no event" from "an event with zero fields".

**Output:** Interface change (`APIKey()`), typed sentinel for empty
provider name, single-flight cache refresh, Retry-After aware
fallback, SSE body close + typed truncation error, pre-flight
context check, typed channel for fallback events. One new test file
with 6 regression tests.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| LLMProvider interface → Settings TUI | The TUI must not see the raw API key on a path that could log it. APIKey() returns the raw key; the TUI is responsible for masking. |
| Provider HTTP client → external provider | The dial timeout (30s) is set; the body read has no timeout (streaming). The new pre-flight check prevents requests that would obviously fail. |
| Fallback goroutine → TUI Update loop | Goroutines emit FallbackEvent via buffered channel; the TUI never blocks on it. |
| SSE parser → http.Response.Body | The parser must release the body on Close; leaked connections exhaust the connection pool. |

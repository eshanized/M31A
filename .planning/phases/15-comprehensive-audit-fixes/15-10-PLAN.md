<objective>
Sweep the **L-1..L-12, L-14, L-15, L-17, L-18 (Low) and M-30, M-33 (Medium)**
findings — a batch of small polish items across the codebase.

- **L-1** — Keychain errors are untyped. Decrypt failures (corrupt
  blob) cannot be distinguished from permission denials.
- **L-2** — Config loader silently uses defaults for invalid
  fields. The user has no idea their config has a typo.
- **L-3** — REPL submits an empty assistant bubble on empty
  input. Spammy TUI history.
- **L-4** — Sidebar refreshes at BT frame rate (60Hz) instead
  of 1Hz.
- **L-5** — Model selector does not preserve the last filter
  across `/model` invocations within the same session.
- **L-6** — `Ledger.Entries()` returns entries oldest-first,
  inconsistent with `Rollback.Chain` (which is now newest-first
  per plan 15-09).
- **L-7** — Logger does not rotate m31a.log on date change for
  long-running processes. A 30-day M31A session keeps one
  giant log file.
- **L-8** — `ThemeManager` lacks a `Current() Theme` accessor;
  the sidebar holds a redundant copy.
- **L-9** — `handleCacheRefresh` logs `"Cache refresh failed"`
  without the provider name.
- **L-10** — `git` operations log to stdout instead of slog.
- **L-11** — `main.go` version string is hardcoded; the
  Makefile's `-ldflags` injection has no target.
- **L-12** — `ProviderRegistry.New()` panics on duplicate
  provider names instead of returning an error.
- **L-14** — REPL view does not cap output length.
- **L-15** — `CommandResult.Error` is sometimes a raw string,
  not a typed error.
- **L-17** — Theme has no `Reset()` method for tests.
- **L-18** — Cache refresh interval is non-configurable.
- **M-30** — Model selector provider filter cycles
  non-deterministically.
- **M-33** — Config save returns nil on partial-write failure.

**Output:** Typed keychain error, warning logs on bad config,
REPL polish, sidebar throttle, model selector memory, log
rotation, theme accessor, provider name in cache log, git slog
usage, ldflags version, registry duplicate check, REPL output
cap, typed CommandResult, theme Reset, M-30 deterministic
filter, M-33 save error. One new test file with 5 regression
tests.

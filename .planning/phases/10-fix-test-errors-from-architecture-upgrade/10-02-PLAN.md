<objective>
Centralize shared mock types and test builder functions into `internal/testutil/mocks/` and `internal/testutil/builders/`. Currently, 4 duplicate `mockProvider` implementations exist across workflow, provider, subagent, and keychain packages. 3 duplicate `mockKeychain` implementations exist. Test setup functions like `setupTestEngine` are duplicated or inconsistent. This plan consolidates them per decisions D-01 through D-04.

Purpose: Eliminate test infrastructure duplication, establish single-source-of-truth mock implementations, and standardize naming with `New*` constructors.
Output: Centralized `testutil/mocks/` and `testutil/builders/` packages with all consumer test files updated to import from them.
</objective>

<objective>
Fix build errors introduced by Phase 9 architecture upgrade. The single root cause is a field naming mismatch in `internal/tools/fileops/filedelete.go` where the struct field `BackupDir` is referenced as `backupDir` (lowercase) throughout the file. This cascades to ALL packages that transitively depend on `fileops`: all TUI screens, workflow engine, cmd/m31a, tools, and narrative packages. Additionally, fix session tests that use `os.MkdirTemp("", ...)` instead of `t.TempDir()`, which causes disk quota errors in constrained environments.

Purpose: Unblock all compilation and testing for the entire codebase. Without this fix, `go build ./...` fails and no tests can run.
Output: Clean build (`go build ./...`) and all previously-passing tests passing again.
</objective>

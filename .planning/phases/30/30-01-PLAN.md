# Plan 30-01: Theme & Color System

## Objective

Migrate the color palette from the current purple-based scheme (`#7C3AED`) to the opencode-inspired warm-amber scheme (`#D77757`). Add missing theme fields for divider characters, compact mode, shadow color, and card padding. Create standardized border constants.

## must_haves

- Brand color `#7C3AED` → `#D77757` in both Dark() and Light()
- Background `#0F0F1A` → `#0D0D0D`, Surface `#1E1E2E` → `#1A1A1A`
- Thinking, Success, Error, Warning, TextMuted all updated per tui_plan.md
- `Theme` struct gains: DividerChar, ShadowColor, CompactMode, CardPadding
- Border constants: `NormalBorder` (RoundedBorder), `ThinBorder` (┌─┐)
- `applyThemeStyles()` recalculated for all new color values
- `CGO_ENABLED=0 go build` passes, `go test -race -cover ./internal/tui/...` passes

```go
// Standard borders used across the TUI
var (
    NormalBorder = lipgloss.RoundedBorder()  // ╭─╮ for cards, modals

    // ThinBorder is a lighter border for compact cards and tool cards
    ThinBorder = lipgloss.Border{
        Top:         "─",
        Bottom:      "─",
        Left:        "│",
        Right:       "│",
        TopLeft:     "┌",
        TopRight:    "┐",
        BottomLeft:  "└",
        BottomRight: "┘",
    }

    // DoubleBorder is reserved for important modals only
    DoubleBorder = lipgloss.DoubleBorder()
)
```

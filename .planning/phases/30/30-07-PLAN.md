### Task 2: Diff screen visual refresh

<read_first>
- internal/tui/diff_view.go — full file
- internal/tui/diff_model.go — full file
</read_first>

<action>
Update the diff viewer:

1. **Added lines**: Green background (`DiffAddedBg`) + `+` prefix in `DiffAdded` color
2. **Removed lines**: Red background (`DiffRemovedBg`) + `−` prefix in `DiffRemoved` color
3. **Context lines**: Dimmed (`t.TextMuted`), no prefix
4. **File header**: `─── a/file.go  +++ b/file.go` in muted
5. **Hunk header**: `@@ -1,5 +1,7 @@` in info/thinking color
6. **Line numbers**: Right-aligned in muted, 4-char width

```go
func renderDiffLine(t theme.Theme, line DiffLine, lineNumWidth int) string {
    switch line.Type {
    case "add":
        return lipgloss.NewStyle().
            Background(t.DiffAddedBg).
            Foreground(t.DiffAdded).
            Render("+" + line.Content)
    case "del":
        return lipgloss.NewStyle().
            Background(t.DiffRemovedBg).
            Foreground(t.DiffRemoved).
            Render("-" + line.Content)
    case "hunk":
        return lipgloss.NewStyle().
            Foreground(t.Thinking).
            Bold(true).
            Render("@@ " + line.Content + " @@")
    default:
        return lipgloss.NewStyle().
            Foreground(t.TextMuted).
            Faint(true).
            Render(" " + line.Content)
    }
}
```
</action>

<acceptance_criteria>
- Additions in green with `+` prefix
- Deletions in red with `−` prefix
- Hunk headers styled in info color
- Context lines are dimmed
- File headers in muted
- `go build ./internal/tui/...` passes
</acceptance_criteria>

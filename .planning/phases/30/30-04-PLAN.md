# Plan 30-04: REPL Screen Polish

## Objective

Polish the main REPL screen: remove bottom border, remove textarea border, lowercase user labels, thin tool card borders, panel-style thinking blocks, minimal welcome screen.

## must_haves

- REPL has no bottom border (status bar sits flush)
- Textarea has no border (inherits terminal background)
- User label: lowercase `user`, muted, no bold
- Tool cards use ThinBorder (┌─┐) instead of RoundedBorder
- Thinking blocks use panel-style with thin border header/footer
- Welcome screen: compact, no starfield decorative row
- `CGO_ENABLED=0 go build` passes, tests pass

    if width <= 0 {
        return ""
    }

Implementation:
```go
func RenderThinkingBlock(t theme.Theme, content string, durationMs int64, width int) string {
    header := lipgloss.NewStyle().
        Border(theme.ThinBorder).
        BorderForeground(t.Thinking).
        BorderTop(true).BorderBottom(false).BorderLeft(true).BorderRight(true).
        Render(" Thinking ")
    
    body := lipgloss.NewStyle().
        Foreground(t.Thinking).
        Italic(true).
        Padding(0, 2).
        Render(content)
    
    duration := fmt.Sprintf(" %s ", formatDurationMs(durationMs))
    footer := lipgloss.NewStyle().
        Border(theme.ThinBorder).
        BorderForeground(t.Thinking).
        BorderTop(false).BorderBottom(true).BorderLeft(true).BorderRight(true).
        Render(duration)
    
    return header + "\n" + body + "\n" + footer
}
```

Key properties:
- Border color: `Thinking` (`#8AB4F8`)
- Content: italic, thinking color
- Duration: right-aligned in footer, auto-updates during streaming
- Collapsible: `▼`/`▶` toggle in header (keep existing toggle behavior)
</action>

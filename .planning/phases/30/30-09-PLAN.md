# Plan 30-09: Typography & Spacing Audit

## Objective

Audit every View() method for consistent padding, margins, and truncation behavior. Ensure all content follows the same spacing rules across all 16 screens.

## must_haves

- Consistent left padding: 2 chars for body content, 0 for headers
- Section headers: 0 padding, bold
- List items: 2 chars left + 1 char gap
- Nested content: +2 chars per level
- Modals: 1, 2 padding (vertical, horizontal)
- All truncation uses `TruncateWithEllipsis`
- File paths truncate from middle
- `CGO_ENABLED=0 go build` passes, tests pass

### Task 2: Truncation consistency

<read_first>
- internal/tui/truncate.go — full file
- internal/tui/ — grep for truncation function calls
</read_first>

<action>
Ensure all long content truncation uses consistent rules:

1. **File paths**: Truncate from middle: `src/.../file.go`
2. **Model names**: Truncate from middle: `claude...slt-20241022`
3. **Command output**: Cap at viewport width with `…` ellipsis
4. **Error messages**: Show first 200 chars + `[...]`

Create/update `internal/tui/truncate.go`:

```go
func TruncateMiddle(s string, maxLen int) string {
    if utf8.RuneCountInString(s) <= maxLen { return s }
    if maxLen < 5 { return s[:maxLen] }
    half := (maxLen - 3) / 2
    runes := []rune(s)
    return string(runes[:half]) + "..." + string(runes[len(runes)-half:])
}

func TruncateEnd(s string, maxLen int) string {
    if utf8.RuneCountInString(s) <= maxLen { return s }
    return string([]rune(s)[:maxLen-1]) + "…"
}

func TruncateError(s string) string {
    if len(s) <= 200 { return s }
    return s[:200] + "[...]"
}
```

Apply to all relevant fields across screen files:
- `toolcard.go` — truncate command input
- `sidebar.go` — truncate file paths
- `plan_model.go` — truncate task descriptions
- `modelselector_view.go` — truncate model names
</action>

<acceptance_criteria>
- TruncateMiddle used for file paths and model names
- TruncateEnd used for command output
- TruncateError used for error messages
- All truncation functions handle multi-byte runes
- `go build ./internal/tui/...` passes
</acceptance_criteria>

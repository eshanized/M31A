# Plan 30-03: Status Bar Redesign

## Objective

Refine the status bar to a clean 3-zone layout: left (cwd + branch), center (operation), right (hints + cost). No background fill — inherits terminal background. Compact mode for narrow terminals.

## must_haves

- 3-zone layout: `⌂ cwd  ⎇ branch  ·  operation  ·  [hints]  [cost/tokens]`
- No background fill on status bar (transparent, inherits terminal bg)
- Cwd with `⌂` prefix, git branch with `⎇` prefix
- Separator between zones: `·` (middle dot)
- Compact mode (< 80 cols): hide hints, hide cost, shorten cwd
- `CGO_ENABLED=0 go build` passes, tests pass

## Tasks

### Task 1: Restructure status bar layout

<read_first>
- internal/tui/statusbar.go — full file, RenderStatusBar() function
- internal/tui/theme/theme.go — Theme struct styles used in statusbar
</read_first>

<action>
Rewrite `RenderStatusBar()` in `internal/tui/statusbar.go`:

1. **Left zone**: Always show cwd basename with `⌂` prefix. Git branch with `⎇` prefix if available. Format: `⌂ src/m31a  ⎇ main`.

2. **Center zone**: Current operation (streaming "responding...", thinking "thinking...", phase name, leader "ctrl+x ─ waiting ─"). When idle and no operation, show empty (no "Ready" label — lean).

3. **Right zone**: Keyboard hints (minimal, shown only during relevant operations), token usage, cost estimate. Show as compact inline: `· [hints]  $0.0042`.

4. **No background fill**: Remove `Background()` from the status bar style. The bar should be plain text. Only use foreground colors.

5. **Separator**: Use ` · ` (space-middle dot-space) between the three zones. Only show separators between non-empty zones.

6. **Remove operation parameter** — the `operation string` parameter is redundant since info carries IsStreaming, IsThinking, WorkflowPhase. Combine them.

New signature:
```go
func RenderStatusBar(t theme.Theme, width int, info *StatusBarInfo) string
```

Update `StatusBarInfo` to add fields if needed. Ensure `CwdName` and `GitBranch` are populated by the caller.
</action>

<acceptance_criteria>
- Status bar starts with `⌂` when cwd is set
- Git branch shown with `⎇` prefix
- No BACKGROUND style applied — bar is transparent
- Separator ` · ` between zones
- `go build ./internal/tui/...` passes
</acceptance_criteria>

### Task 2: Add compact mode

<read_first>
- internal/tui/statusbar.go — after Task 1
- internal/tui/constants.go — MinTerminalWidth
</read_first>

<action>
Add compact mode logic to the status bar:

```go
// Compact mode: terminal width < 80
if width < 80 {
    info.KeyboardHints = nil  // hide hints
    info.ShowCost = false      // hide cost/tokens
    // Shorten cwd to last component only
    if info.CwdName != "" {
        parts := strings.Split(info.CwdName, "/")
        info.CwdName = parts[len(parts)-1]
    }
}

// Ultra-compact: width < 60
if width < 60 {
    info.GitBranch = ""  // hide branch
}
```

Update any caller of `RenderStatusBar` to pass width and handle the updated signature.
</action>

<acceptance_criteria>
- At width < 80: no keyboard hints, no cost display
- At width < 60: git branch hidden
- `go build ./internal/tui/...` passes
</acceptance_criteria>

# Plan 30-02: Header Redesign

## Objective

Redesign the header bar to be cleaner and more informative: 1 line, no version display, no full-width background, no health indicator. Show git branch when idle, hide when workflow active.

## must_haves

- Brand `M31A` in bold, no version number
- Phase breadcrumb shown ONLY when `phase != idle`; git branch `⎇ main` shown when idle
- No health indicator in header (moved to status bar or removed)
- No full-width background on header — inherits terminal background
- Context meter: compact visual `ctx [████░░░░] 42%` style
- Provider badge: `[OR]` with brand border, `[ZEN]` with info color
- `CGO_ENABLED=0 go build` passes, tests pass

## Tasks

### Task 1: Simplify header layout

<read_first>
- internal/tui/header.go — full file, RenderHeader() function
- internal/tui/providerbadge.go — ProviderShortName()
- internal/tui/types.go — screen enum, AppMsg
</read_first>

<action>
Rewrite `RenderHeader()` in `internal/tui/header.go`:

1. **Remove version parameter** — delete `version` from function signature. Version info belongs in status bar or /version command. Update all callers in `app_view.go` or wherever `RenderHeader` is called.

2. **Remove health indicator** — delete the `healthStatus` parameter and the "● degraded"/"● offline" rendering. Health status belongs in status bar.

3. **Remove full-width background** — delete the `t.Header` style application block at the end (the `if headerStyle.GetBackground()...` block). The header should render as plain text inheriting terminal background.

4. **Add git branch fallback** — add a `gitBranch string` parameter. When `phase == idle || phase == ""`, render `⎇ <branchName>` in muted color in the center zone instead of the phase breadcrumb.

5. **Add visual context meter** — replace the plain `"5.2K/128K ctx"` text with a compact bar:
   ```
   ctx [████░░░░] 42%
   ```
   Create a helper `renderContextMeter(used, total int, t theme.Theme) string` that:
   - Renders `[█×Filled░×Remaining]` with color: muted (<60%), warning (60-80%), error (>80%)
   - Shows percentage label after the bar

6. **Simplify right zone** — model badge + provider badge + context meter. No health indicator.

New signature:
```go
func RenderHeader(
    t theme.Theme,
    activeProvider string,
    modelID string,
    modelName string,
    phase types.WorkflowPhase,
    gitBranch string,
    ctxUsed int,
    ctxTotal int,
    width int,
) string
```
</action>

- No health indicator shown
- Phase breadcrumb appears only when phase != idle
- Git branch shown when phase == idle
- Context meter uses visual bar `[██░░]` format
- `go build ./internal/tui/...` passes

    return lipgloss.NewStyle().

        BorderForeground(t.Brand).
        Padding(0, 1).
        Render(phase)

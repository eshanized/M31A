<action>
Add animated progress bar fill:

1. On progress update, use a tick-based animation to incrementally fill the bar over ~500ms
2. On task completion, flash the bar green briefly (one tick)
3. On failure, flash red briefly (one tick)

```go
type AnimatedProgress struct {
    Current   int
    Total     int
    Displayed int   // animated display value (ramps from old→new)
    Animating bool
    Color     lipgloss.Color
    StartAt   time.Time
}

func (p *AnimatedProgress) Update(oldCurrent, newCurrent, total int) {
    if newCurrent > oldCurrent {
        p.Animating = true
        p.StartAt = time.Now()
    }
    p.Current = newCurrent
    p.Total = total
}

func (p *AnimatedProgress) Tick() {
    if !p.Animating { return }
    elapsed := time.Since(p.StartAt)
    pct := math.Min(float64(elapsed)/500_000_000, 1.0)  // 500ms ramp
    p.Displayed = int(float64(p.Current-p.Total) * pct) + p.Total
    if pct >= 1.0 { p.Animating = false }
}
```

Use `tea.Tick` to send animation updates. Wire into execute screen.
</action>

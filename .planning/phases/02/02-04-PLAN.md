    ```go
        FirstRunWelcome FirstRunState = iota
        FirstRunProviderSelect
        FirstRunKeyInput
        FirstRunValidating
        FirstRunKeychainPrompt
        FirstRunComplete
    )
    ```

    Define `type FirstRunModel struct`:
    ```go
    type FirstRunModel struct {
        state         FirstRunState
        theme         theme.Theme
        cursor        int            // selection cursor for provider list
        providers     []string       // selected provider names
        apiKeyInput   textinput.Model
        apiKeyValue   string
        validating    bool
        validationErr string
        statusMsg     string
        width         int
        height        int
        configPath    string         // for keychain prompt display
    }
    ```

    Implement `func NewFirstRunModel(t theme.Theme, configPath string) FirstRunModel`:
    1. Create textinput model:
       - `ti := textinput.New()`
       - `ti.Placeholder = "sk-or-v1-..."`
       - `ti.EchoMode = textinput.EchoPassword` — mask the key
       - `ti.Focus()`
       - `ti.Width = 60`
       - `ti.CharLimit = 128`
    2. Return FirstRunModel with:
       - `state: FirstRunWelcome`
       - `providers: make([]string, 0)`
       - `configPath: configPath`

    The FirstRunModel is a sub-component (not a standalone tea.Model), managed by AppState.

    The key principle per the user spec (first-run screen with linear wizard):
    - Each step advances on user action
    - Validation triggers a health check call
    - On completion, emits AppMsg with ScreenREPL for AppState to handle

<task type="auto">
  <name>Task 2: Implement FirstRunModel Update method</name>
  <files>internal/tui/firstrun.go</files>
  <action>
    Extend `internal/tui/firstrun.go` with the Update method:

    ```go
    func (m *FirstRunModel) Update(msg tea.Msg) ([]tea.Cmd, *AppMsg)
    ```
    Returns: slice of tea.Cmd, and optionally an AppMsg for screen transition.
    When AppMsg is non-nil, AppState should process it (screen transition).

    **State machine handling:**

    `case tea.WindowSizeMsg`:
    - `m.width = msg.Width`
    - `m.height = msg.Height`

    `case tea.KeyMsg`:
    - `switch msg.String()`:
      - `"ctrl+c"`: Don't handle (AppState handles globally). Return nil.

    Now delegate by state:

    **FirstRunWelcome:**
    - Show welcome message with M31A branding
    - Key `"enter"` or `" "`: transition to `FirstRunProviderSelect`
    - Key `"q"`, `"ctrl+c"`: ignore (handled by AppState)

    **FirstRunProviderSelect:**
    - Options displayed as numbered list:
      1. OpenRouter (sk-or-v1-...)
      2. Zen (zk-...)  
      3. Both (OpenRouter + Zen)
      4. Skip — start without API key
    - Keys `"1"`, `"2"`, `"3"`, `"4"`: select that option
    - Key `"up"`: `m.cursor--` (with wrapping)
    - Key `"down"`: `m.cursor++` (with wrapping)
    - Key `"enter"`: select current cursor option
      - Option 1: `m.providers = ["openrouter"]`, transition to KeyInput
      - Option 2: `m.providers = ["zen"]`, transition to KeyInput
      - Option 3: `m.providers = ["openrouter", "zen"]`, transition to KeyInput
      - Option 4: `m.statusMsg = "No API key configured"`, transition to Complete (skip)

    **FirstRunKeyInput:**
    - Delegate to textinput: `m.apiKeyInput, _ = m.apiKeyInput.Update(msg)` — only if msg is tea.KeyMsg and not enter
    - Key `"enter"`: 
      - If input is empty: return (don't advance)
      - If non-empty: `m.apiKeyValue = m.apiKeyInput.Value()`
        - `m.validating = true`
        - Transition to `FirstRunValidating`
        - Return a tea.Cmd that validates the key format:
          ```go
          func() tea.Msg {
              // Simple format validation
              key := m.apiKeyValue
              // OpenRouter keys: start with "sk-or-v1-"
              // Zen keys: start with "zk-"
              // Don't block on actual API call — Phase 1 provider handles that
              // For Phase 2, just check non-empty and reasonable length
              if len(key) < 10 {
                  return validationResultMsg{valid: false, err: "API key too short"}
              }
              return validationResultMsg{valid: true}
          }
          ```

    **FirstRunValidating:**
    - Show "Validating API key..." with spinner
    - On `validationResultMsg`:
      - If valid: transition to `FirstRunKeychainPrompt`
      - If invalid: `m.validationErr = msg.err`, transition back to `FirstRunKeyInput`

    **FirstRunKeychainPrompt:**
    - Show: "Store API key in system keychain?"
    - Keys: `"y"` or `"enter"`: transition to Complete (would store keychain in Phase 5)
    - Keys: `"n"`: transition to Complete (skip keychain)

    **FirstRunComplete:**
    - Set `m.state = FirstRunComplete`
    - Return `AppMsg{Screen: ScreenREPL}` — signals AppState to switch to REPL

    Define internal message type:
    ```go
    type validationResultMsg struct {
        valid bool
        err   string
    }
    ```

    Also implement:
    ```go
    func (m *FirstRunModel) State() FirstRunState {
        return m.state
    }

    func (m *FirstRunModel) SelectedProviders() []string {
        return m.providers
    }

    func (m *FirstRunModel) APIKey() string {
        return m.apiKeyValue
    }

    func (m *FirstRunModel) SetTheme(t theme.Theme) {
        m.theme = t
    }
    ```
  </action>

**IMPORTANT — v1 Bubble Tea Model interface:**
```go
type Model interface {
    Init() Cmd
    Update(Msg) (Model, Cmd)
    View() string
}
```
AppState must implement this interface exactly. `View()` returns `string`, not `tea.View`.
`Init()` returns `tea.Cmd`. `Update(msg tea.Msg) (tea.Model, tea.Cmd)`.

  <action>
    Extend `internal/tui/app.go` with Init and Update methods:

    ```go
    func (m *AppState) Init() tea.Cmd
    ```

    Init() returns a batch of commands:
    - If m.registry != nil and m.activeProvider != "": also start health check ticker
      ```go
      cmds := []tea.Cmd{
          HealthCheckTicker(context.Background(), m.registry, m.activeProvider, types.HealthCheckInterval),
      }
      return tea.Batch(cmds...)
      ```
    - If firstRunModel is active: return nil (no health checks during setup)
    - Return nil otherwise

    ```go
    func (m *AppState) Update(msg tea.Msg) (tea.Model, tea.Cmd)
    ```

    **1. Handle global messages first:**

    `case tea.WindowSizeMsg`:
    - `m.width = msg.Width`
    - `m.height = msg.Height`
    - `m.initialized = true`
    - Propagate to active screen:
      - If repl: forward msg to replModel.Update()
      - If firstRun: forward msg to firstRunModel.Update()

    `case tea.KeyMsg`:
    - `switch msg.String()`:
      - `"ctrl+c"`: `return m, tea.Quit`
    - Fall through to screen delegation

    `case HealthCheckTickMsg`:
    - Only process if registry and active provider exist
    - Perform health check:
      ```go
      ctx, cancel := context.WithTimeout(context.Background(), 10*time.Second)
      defer cancel()
      
      provider := m.registry.ActiveProvider()
      if provider == nil {
          return m, NextHealthTick(types.HealthCheckInterval)
      }
      
      result := provider.HealthCheck(ctx)
      m.healthStatus = result
      m.lastActivity = time.Now()
      ```
    - Re-schedule next tick: `return m, NextHealthTick(calculateNextInterval(result))`
    - Helper: `func calculateNextInterval(status types.HealthStatus) time.Duration`
      - If status.Error contains "rate limit" or "429": return 120 * time.Second
      - If status.Status == "offline": return 120 * time.Second  
      - Default: return types.HealthCheckInterval (60s)
    - **IMPORTANT:** Do NOT call HealthCheck in a goroutine from inside Update().
      In v1 bubbletea, synchronous work in Update() blocks the event loop but
      is acceptable for short-lived operations (health check is typically < 2s).
      For Phase 3+ streaming, this will be refactored to tea.Cmd-based async.

    `case AppMsg`:
    - `m.screen = msg.Screen`
    - If msg.Health != nil: update health
    - If msg.Provider != nil: update active provider
    - If msg.InitError != nil: store for display
    - Return m, nil

    `case ErrorMsg`:
    - Store error, update status
    - Return m, nil

    **2. Delegate to active screen:**

    `switch m.screen`:

    `case ScreenFirstRun`:
    ```go
    if m.firstRunModel == nil {
        return m, nil
    }
    cmds, appMsg := m.firstRunModel.Update(msg)
    if appMsg != nil {
        m.screen = appMsg.Screen
        // Transition: create ReplModel when first-run completes
        if appMsg.Screen == ScreenREPL && m.replModel == nil {
            rp := NewReplModel(m.themeManager.Current())
            m.replModel = &rp
            m.initialized = true
            // Start health checks
            healthCmd := HealthCheckTicker(
                context.Background(), m.registry, m.activeProvider,
                types.HealthCheckInterval,
            )
            cmds = append(cmds, healthCmd)
        }
        // Apply any other AppMsg fields
        if appMsg.Health != nil {
            m.healthStatus = types.HealthStatus{
                Status: appMsg.Health.Status,
            }
        }
    }
    var allCmds []tea.Cmd
    allCmds = append(allCmds, cmds...)
    return m, tea.Batch(allCmds...)
    ```

    `case ScreenREPL`:
    ```go
    if m.replModel == nil {
        return m, nil
    }
    cmds, sent := m.replModel.Update(msg)
    if sent {
        m.lastActivity = time.Now()
        // In Phase 3+, this would trigger a streaming response
        // For Phase 2, just acknowledge
        m.currentOperation = "Ready"
    }
    var allCmds []tea.Cmd
    allCmds = append(allCmds, cmds...)
    return m, tea.Batch(allCmds...)
    ```

    `default`:
    ```go
    return m, nil
    ```

    Implement a helper:
    ```go
    func calculateNextInterval(status types.HealthStatus) time.Duration {
        if status.Error != "" && (strings.Contains(strings.ToLower(status.Error), "rate limit") ||
            strings.Contains(strings.ToLower(status.Error), "429")) {
            return 120 * time.Second
        }
        if status.Status == "offline" {
            return 120 * time.Second
        }
        return types.HealthCheckInterval
    }
    ```
    Add `"strings"` to imports.

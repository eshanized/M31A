**IMPORTANT — v1 Bubble Tea API:**
This plan uses `github.com/charmbracelet/bubbletea` (v1.x), NOT `charm.land/bubbletea/v2`.

Key v1 API differences from research examples:
- `View() string` (NOT `View() tea.View`)
- `tea.KeyMsg` (NOT `tea.KeyPressMsg`)
- `viewport.New(width, height int)` (NOT options pattern)
- `textarea.SetWidth(w)`, `textarea.SetHeight(h)` (NOT options)
- `spinner.NewModel()` (NOT `spinner.New()`)
- `spinner.Tick()` is a `tea.Cmd` in v1

Do NOT use charm.land import paths. Use github.com/charmbracelet/... everywhere.

<task type="auto">
  <name>Task 2: Implement ReplModel Update method</name>
  <files>internal/tui/repl.go</files>
  <action>
    Extend `internal/tui/repl.go` with the Update method:

    ```go
    func (m *ReplModel) Update(msg tea.Msg) ([]tea.Cmd, bool)
    ```
    Returns: slice of tea.Cmd, and a boolean `sent` indicating if the user sent a message this update.
    Return `sent=true` so AppState can handle the sent message (e.g., forward to provider).

    **Message handling:**

    `case tea.WindowSizeMsg`:
    - Store m.width = msg.Width, m.height = msg.Height
    - Compute layout: header takes 1 line, status takes 1 line, input takes 3-6 lines
    - Input height: clamp to 3 (min) to 6 (max), with 3 default
    - Viewport height: msg.Height - 2 (header+status) - inputHeight
    - `m.viewport.Width = msg.Width`
    - `m.viewport.Height = vpHeight`
    - `m.textarea.SetWidth(msg.Width)`
    - `m.textarea.SetHeight(inputHeight)` — actually in v1 bubbles textarea sets height differently
    - Use `m.textarea.SetWidth(msg.Width)`

    `case tea.KeyMsg`:
    - `switch msg.String()`:
      - `"enter"`: If input is not empty after trimming whitespace:
        1. Store input in `m.inputHistory` (append)
        2. `m.historyPos = len(m.inputHistory)` (reset position)
        3. Create `types.Message{Role: "user", Content: input, CreatedAt: time.Now()}`
        4. Append to `m.messages`
        5. Add rendered message to viewport using `m.viewport.SetContent(...)`
        6. `m.viewport.GotoBottom()`
        7. `m.textarea.Reset()`
        8. Return with `sent: true`
      - `"shift+enter"`: Insert newline into textarea (let textarea handle it — don't intercept)
      - `"up"`: Navigate input history backward
        - If `m.historyPos > 0`, decrement and set `m.textarea.SetValue(m.inputHistory[m.historyPos])`
        - `m.textarea.SetCursor(len(m.textarea.Value()))`
      - `"down"`: Navigate input history forward
        - If `m.historyPos < len(m.inputHistory)-1`, increment and set value
        - If at or past end, clear input
      - `"pgup"`: `m.viewport.HalfViewUp()`
      - `"pgdown"`: `m.viewport.HalfViewDown()`
      - `"esc"`: Clear input: `m.textarea.Reset()`
      - `"ctrl+c"`: DON'T handle here — handled by AppState globally. Return empty cmd slice.

    `case spinner.TickMsg`:
    - Forward to `m.spinner.Update(msg)` (v1: spinner model is a tea.Model)

    For all other messages, forward to both textarea and viewport:

    ```go
    var cmds []tea.Cmd
    var taCmd tea.Cmd
    var vpCmd tea.Cmd
    var spCmd tea.Cmd

    m.textarea, taCmd = m.textarea.Update(msg)
    m.viewport, vpCmd = m.viewport.Update(msg)
    m.spinner, spCmd = m.spinner.Update(msg)

    cmds = append(cmds, taCmd, vpCmd, spCmd)
    ```

    Return:
    ```go
    return cmds, false
    ```

    **Note about v1 textarea.KeyMap:**
    In v1 bubbletea, tea.KeyMsg is used. Key matching uses `msg.String()` which returns key name strings like "enter", "up", "down", "pgup", etc.
    For shift+enter: v1 tea.KeyMsg with Type == tea.KeyEnter and Alt == true or msg.String() handles it.
    In v1, shift+enter won't trigger "enter" — it triggers a different key string. So the default behavior (textarea handling it as newline) works.

    Extend `internal/tui/repl.go` with mutator methods and View:

    ```go
    func (m *ReplModel) SetTheme(t theme.Theme) {
        m.theme = t
    }

    func (m *ReplModel) SetStreaming(v bool) {
        m.streaming = v
    }

    func (m *ReplModel) SetThinking(v bool) {
        m.thinking = v
    }

    func (m *ReplModel) AddMessage(msg types.Message) {
        m.messages = append(m.messages, msg)
        // Re-render viewport content
        m.renderMessages()
        m.viewport.GotoBottom()
    }

    func (m *ReplModel) renderMessages() {
        var b strings.Builder
        for _, msg := range m.messages {
            // Use simple prefix mapping instead of deprecated strings.Title
            role := msg.Role
            if role == "user" {
                role = "You"
            } else if role == "assistant" {
                role = "Assistant"
            }
            b.WriteString(fmt.Sprintf("%s: %s\n", role, msg.Content))
        }
        m.viewport.SetContent(b.String())
    }

    func (m *ReplModel) View() string {
        // 4-region layout:
        // [Header rendered by AppState]
        // [Message viewport]
        // [Input textarea]
        // [Status bar rendered by AppState]
        //
        // This View() returns just the viewport + input area.
        // AppState wraps with header and statusbar.

        if m.width == 0 {
            return "Initializing..."
        }

        viewportStr := m.viewport.View()
        inputStr := m.textarea.View()

        return lipgloss.JoinVertical(
            lipgloss.Top,
            viewportStr,
            inputStr,
        )
    }

    func (m *ReplModel) InputValue() string {
        return strings.TrimSpace(m.textarea.Value())
    }

    func (m *ReplModel) Messages() []types.Message {
        return m.messages
    }

    func (m *ReplModel) SpinnerTick() tea.Cmd {
        return m.spinner.Tick // v1: spinner.Tick is a tea.Cmd method
    }
    ```

    Also extend with helper for status:
    ```go
    func (m *ReplModel) GetStatusText() string {
        if m.streaming {
            return "Streaming..."
        }
        if m.thinking {
            return "Thinking..."
        }
        if m.lastStatus != "" {
            return m.lastStatus
        }
        return ""
    }
    ```

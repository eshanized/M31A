    - Brand #D77757, TextPrimary #E8EAED, TextSecondary #9AA0A6
    - Thinking #8AB4F8, Success #81C995, Error #F28B82, Warning #FDD663, CodeBG #2D2D2D

    - All lipgloss.Style fields built with appropriate foreground/background colors, padding, and bold settings matching the spec

    Implement `func Light() Theme` with light palette:
    - Background #FFFFFF, Surface #F8F9FA, SurfaceElevated #FFFFFF, Border #E0E0E0
    - Brand #C45C3A, TextPrimary #1F1F1F, TextSecondary #5F6368
    - Thinking #1967D2, Success #1E8E3E, Error #D93025, Warning #F9AB00, CodeBG #F1F3F4
    - Same ToolLabel color mapping as Dark

    Implement `func Auto() Theme`:
    - Use `lipgloss.HasDarkBackground()` (v1 lipgloss feature) to detect terminal background
    - Return Dark() if dark background, Light() otherwise

    Define `type Manager struct` with `current Theme` and `mode Mode` fields.
    Implement:
    - `func NewManager(mode Mode) *Manager` — calls resolve()
    - `func (m *Manager) resolve()` — sets m.current based on m.mode (for ModeAuto calls Auto())
    - `func (m *Manager) Cycle() Mode` — cycles ModeDark→ModeLight→ModeAuto→ModeDark, calls resolve() each time, returns new mode
    - `func (m *Manager) Current() Theme` — returns m.current

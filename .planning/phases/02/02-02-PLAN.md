    Implement:
    ```go
    func RenderHeader(t theme.Theme, provider string, model *types.ModelInfo,
        health types.HealthStatus, contextUsed int64, contextTotal int64, width int) string
    ```

    This function produces a single-line header (must fit in 1 terminal row).

    **Layout (left to right, separated by spaces):**
    1. **Brand** — "M31A" rendered in `t.Header`
    2. **Provider badge** — "[OR]" or "[ZEN]" (uppercase first 2 chars of provider name)
       - Use `t.ModelBadge` as base style
       - If provider starts with "openrouter" → foreground `t.Warning` color
       - If provider starts with "zen" → foreground `t.Thinking` color
       - Unknown provider → foreground `t.TextSecondary`
    3. **Model name** — model.Name, truncated to 20 chars with "..." if longer. Rendered in `t.TextPrimary` via `t.ModelBadge`.
    4. **Context bar** — "N.NK/YK ctx" format:
       - `contextUsed` formatted: if >= 1000 → "X.XK", else "N" (divide by 1000 for K)
       - `contextTotal` formatted: if >= 1000 → "YK", else "Y" (divide by 1000 for K)
       - Color determined by ratio:
         - ratio >= 0.95 → `t.Error` color
         - ratio >= 0.80 → `t.Warning` color
         - else → `t.TextSecondary` color
       - Rendered in `t.ContextBar`
    5. **Health status** — status label:
       - health.Status == "live" → "[LIVE]" in `t.StatusLive`
       - health.Status == "slow" → "[SLOW]" in `t.StatusSlow`
       - health.Status == "offline" → "[OFF]" in `t.StatusOffline`
       - health.Status == "" → "[??]" in `t.StatusOffline`

    **Truncation logic:**
    - Join all segments with " " separator using lipgloss.JoinHorizontal(lipgloss.Left, ...)
    - If the resulting string width (use `lipgloss.Width`) exceeds `width`, truncate the model name first
    - If still too wide, truncate at the character level with "..."
    - Return the truncated string

    **Edge cases:**
    - provider == "" → show "[  ]" in TextSecondary
    - model == nil → skip model name segment
    - contextTotal == 0 → show "--/-- ctx" in TextSecondary
    - width < 20 → return "..."
  </action>

    ```go
    func RenderStatusBar(t theme.Theme, operation string, lastActivity time.Time, width int) string
    ```

    **Layout (single line):**
    1. **Left section** — operation text:
       - If operation == "" → "Ready" in `t.TextSecondary`
       - If operation != "" → operation text in `t.ModelBadge`
       - Truncated so that total line fits `width`
    2. **Right section** — timestamp:
       - If lastActivity is zero time → ""
       - Else → "Last activity: HH:MM:SS" formatted in `t.TextSecondary`

    **Implementation:**
    - Left section: `lipgloss.NewStyle().Width(width).Render(operation)` won't work because we need right-aligned timestamp
    - Use two strings and join with flex space:
      - Calculate left content width via `lipgloss.Width`
      - Calculate right content width via `lipgloss.Width`
      - Insert padding: `strings.Repeat(" ", width - leftWidth - rightWidth)`
      - If padding < 0: truncate left content with "..." and recalculate
    - Return the joined string (no lipgloss.JoinHorizontal needed — just string concatenation with padding)

    **Edge cases:**
    - width < 10 → return ""
    - operation longer than width-15 → truncate with "..."
    - lastActivity is zero → only show operation, no timestamp

    Create `internal/tui/health.go` in package `tui` with imports:
    - `"context"`, `"time"`
    - `tea "github.com/charmbracelet/bubbletea"`
    - `"github.com/eshanized/M31A/internal/provider"`
    - `"github.com/eshanized/M31A/internal/types"`

    Implement:
    ```go
    // HealthCheckInterval is the default interval between health checks.
    // Used from types.HealthCheckInterval (60s).
    const HealthCheckInterval = types.HealthCheckInterval

    // HealthCheckTicker returns a tea.Cmd that performs one health check
    // on the active provider and re-schedules itself.
    func HealthCheckTicker(ctx context.Context, registry *provider.Registry,
        activeProvider string, interval time.Duration) tea.Cmd
    ```

    **Behavior per the user spec (per D-06, D-07 decision patterns):**
    - Uses `tea.Tick(interval, func(t time.Time) tea.Msg)` to schedule the next check
    - When the tick fires, captures the time and returns a `HealthCheckTickMsg{Time: t}`
    - The actual health check execution and re-scheduling is handled by AppState's Update when it receives HealthCheckTickMsg
    - So this function ONLY generates the tick command — the app.go Update() will:
      1. Receive HealthCheckTickMsg
      2. Call registry.ActiveProvider().HealthCheck(ctx) via a tea.Cmd
      3. Emit HealthUpdateMsg
      4. Re-schedule with another HealthCheckTicker call

    - If registry == nil or registry.ActiveProvider() == nil, skip check but re-schedule
    - `activeProvider` parameter is used as the provider name in HealthUpdateMsg

    Also provide a helper:
    ```go
    // NextHealthTick returns a tea.Cmd that fires after the given duration.
    // For use by AppState.Update when re-scheduling after processing a tick.
    func NextHealthTick(interval time.Duration) tea.Cmd {
        return tea.Tick(interval, func(t time.Time) tea.Msg {
            return HealthCheckTickMsg{Time: t}
        })
    }
    ```

    **Key pattern (v1 bubbletea):**
    - `tea.Tick` takes `(time.Duration, func(time.Time) Msg) tea.Cmd`
    - The `Msg` can be any type — use `HealthCheckTickMsg`
    - Do NOT perform the actual health check in the tick function body (runs in goroutine context)
    - Instead, let AppState.Update handle the health check via a separate tea.Cmd when it receives HealthCheckTickMsg

    **Edge cases:**
    - interval <= 0 → use HealthCheckInterval (60s)
    - ctx canceled → return nil (no more ticks)
  </action>

    In `internal/core/config/merge.go`, modify `intField` (lines 39-45) and `float64Field` (lines 47-53) to add non-zero fallback matching `boolField` pattern at line 33.

    **Current (broken):**
    ```go
    func (m mergeHelper) intField(base, overlay *int, key string) {
        if m.hasKey(key) {
            *base = *overlay
        }
    }

    func (m mergeHelper) float64Field(base, overlay *float64, key string) {
        if m.hasKey(key) {
            *base = *overlay
        }
    }
    ```

    **Fixed (add `|| *overlay != 0`):**
    ```go
    func (m mergeHelper) intField(base, overlay *int, key string) {
        if m.hasKey(key) || *overlay != 0 {
            *base = *overlay
        }
    }

    func (m mergeHelper) float64Field(base, overlay *float64, key string) {
        if m.hasKey(key) || *overlay != 0 {
            *base = *overlay
        }
    }
    ```

    Per D-08: Only change the condition. Do not modify function signatures, hasKey logic, or adjacent code.

    The existing 6 failing tests in merge_test.go and extra_test.go will pass after this fix. No new tests needed per D-02 (class coverage — existing tests cover the behavior).

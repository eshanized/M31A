   - Insert between each user-assistant message pair
   - Use message.CreatedAt timestamp from types.Message

3. Redesign tool card rendering in toolcard.go:
   - Switch from RoundedBorder to DoubleBorder (╔═╗) for tool cards
   - Add status icon prefix: `✓` for done, `⟳` for running, `✗` for error
   - Add elapsed time and line count in the card header
   - Keep existing ToolLabel color map (Bash=Warning, FileRead=Thinking, etc.)
   - Cap output at MaxToolOutputChars (10,000) with `[+N lines]` toggle

4. Update REPL input frame in repl_view.go:
   - Model context line above textarea: `│ M31A · model-name · provider`
   - Bottom border: `╰───────── Enter to send · Ctrl+C cancel ────────╯`
   - Keep existing border color logic (Brand when streaming, Thinking when thinking)

5. Add git status strip above input (when sidebar is hidden):
   - Show modified files in a thin row: `MODIFIED  src/file.ts  M  src/other.ts  M`
   - Only show if there are modified files and sidebar is not visible
   - Use theme.TextMuted color

6. Add scroll indicator (▼) at right edge of last message when not at bottom:
   - Check viewport scroll position
   - Render `▼` in Brand color at the right edge of the content area

# Plan 29-11: Keybindings & Command Palette

## Objective

Implement the context-aware keybinding system and command palette overlay.

## Tasks

### Task 1: keybindings.go

<read_first>
- internal/tui/types.go
</read_first>

<action>
Create keybindings.go:

KeyContext enum:
- KeyGlobal, KeyREPL, KeyStreaming, KeyPermission,
  KeyPlan, KeyExecute, KeyVerify, KeyModelSelector, KeySettings

KeyBinding struct:
- Key string
- Description string
- Context KeyContext

KeyRegistry struct:
- bindings map[KeyContext][]KeyBinding

Methods:
- NewKeyRegistry() *KeyRegistry
- Register(ctx KeyContext, key, description string)
- GetBindings(ctx KeyContext) []KeyBinding
- AllBindings() map[KeyContext][]KeyBinding
</action>

<acceptance_criteria>
- KeyRegistry stores bindings by context
- GetBindings returns correct bindings
- AllBindings returns all contexts
</acceptance_criteria>

### Task 2: keybindings_screens.go

<read_first>
- internal/tui/keybindings.go
- internal/tui/theme/theme.go
</read_first>

<action>
Create keybindings_screens.go:

RenderWhichKey(ctx KeyContext, registry *KeyRegistry, theme *theme.Theme, width int) string
- Shows available keys for current context
- Styled key badges
- One line per binding

RenderLeaderPrompt(ctx KeyContext, theme *theme.Theme) string
- Shows ">" prefix with context hint
</action>

<acceptance_criteria>
- RenderWhichKey shows correct keys per context
- RenderLeaderPrompt shows context hint
</acceptance_criteria>

### Task 3: cmdpalette.go

<read_first>
- internal/tui/commands.go — CommandRegistry
- internal/tui/theme/theme.go
- bubbletea/bubbles/textinput
</read_first>

<action>
Create cmdpalette.go:

CommandPaletteModel struct:
- visible bool
- searchInput textinput.Model
- commands []CommandInfo
- filtered []CommandInfo
- selectedIndex int
- width, height int
- theme *theme.Theme

Methods:
- NewCommandPalette(registry *CommandRegistry, theme *theme.Theme)
- Toggle() — show/hide
- Update(msg) (tea.Model, tea.Cmd)
- View() string — centered overlay with search + filtered list
- Select() (string, []string) — returns selected command + args

Key bindings:
- type: filter commands
- up/down: navigate
- enter: select
- Esc: close
</action>

<acceptance_criteria>
- CommandPalette shows all commands
- Search filters commands
- Enter selects command
- Esc closes palette
- Centered overlay renders correctly
</acceptance_criteria>

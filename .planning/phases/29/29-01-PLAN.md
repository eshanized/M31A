# Plan 29-01: Foundation — Types, Theme, Constants

## Objective

Establish the foundation layer for the complete TUI rewrite. Create all enum types, message types, the theme system with dark/light/auto palettes, and internal TUI constants. Every subsequent plan depends on these definitions.

## must_haves

- All 16 screen enum values defined and named
- All 25+ message types defined with correct fields
- Theme struct with ~50 Lipgloss Style/Color fields
- Dark() and Light() constructors producing complete palettes
- ThemeManager with Cycle() method
- Internal constants for layout, timing, and limits

# Plan 29-02: Chrome — Header, Sidebar, StatusBar, ProviderBadge

## Objective

Create the chrome components that wrap every screen: header bar (brand + model badge + context), git status sidebar, status bar, and provider badge utilities.

## must_haves

- Header renders 1-line: brand, model badge [OR]/[ZEN], context bar, connection status
- Header caches to avoid re-render every frame
- Sidebar renders git status: branch, ahead/behind, modified/added/deleted
- Sidebar caches git status
- StatusBar renders 1-line: current operation, timestamp
- ProviderBadge returns styled badge for provider name
- ProviderShortName maps full name to abbreviation

   - Future phases with theme.PhaseFuture
</action>

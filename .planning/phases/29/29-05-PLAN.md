# Plan 29-05: Permission Modal

## Objective

Implement the permission modal that gates dangerous/destructive tool execution. Shows tool name, command, risk badge, timeout countdown, and Y/N/A key options.

## must_haves

- PermissionModal component with tool name, command, risk badge, countdown
- Countdown timer (default 300s) with 100ms tick
- Y/N/A key bindings
- Risk badge colors: safe=green, medium=blue, dangerous=yellow, destructive=red
- Auto-deny on timeout
- Queue for multiple pending requests

## Tasks

### Task 1: Create components/permission.go

<read_first>
- internal/tui/theme/theme.go
- internal/tui/constants.go
- internal/types/types.go — RiskLevel
- bubbletea — tea.Model, tea.Cmd, tea.Msg
</read_first>

<action>
Create internal/tui/components/permission.go:

1. PermissionModal struct (implements tea.Model):
   - toolName string
   - command string
   - riskLevel types.RiskLevel
   - timeoutSecs int
   - remaining int
   - allowed bool
   - remember bool
   - timerActive bool
   - width, height int
   - theme *theme.Theme
   - resultCh chan PermissionResult

2. PermissionResult struct:
   { Allowed bool, Remember bool }

3. PermissionTimerTickMsg struct:
   { Remaining int }

4. NewPermissionModal(toolName, command string, risk types.RiskLevel,
   timeoutSecs int, theme *theme.Theme) PermissionModal

5. Init() tea.Cmd — starts timer tick

6. Update(msg tea.Msg) (tea.Model, tea.Cmd)
   - tea.KeyMsg:
     - y/enter: approve (allowed=true), return result
     - n/esc: deny (allowed=false), return result
     - a: approve+remember, return result
   - PermissionTimerTickMsg: decrement remaining, auto-deny at 0
   - tea.WindowSizeMsg: update dimensions

7. View() string
   - Centered overlay with double border
   - Tool name + risk badge (colored by risk level)
   - Command text with syntax highlight
   - Countdown timer: "[Auto-deny in Ns]"
   - Key hints: "[Y] Approve  [N] Deny  [A] Approve & Remember"
</action>

<acceptance_criteria>
- PermissionModal renders centered overlay
- Risk badge colored correctly per risk level
- Countdown decrements every second
- Auto-deny triggers at 0
- Y/N/A keys produce correct result
- Timer stops on decision
</acceptance_criteria>

### Task 2: Create permission.go (AppState integration)

<read_first>
- internal/tui/components/permission.go (Task 1 output)
- internal/tui/types.go — PermissionRequestMsg, PermissionResponseMsg
- internal/tools/dispatcher.go — PermissionRequest, PermissionResponse
</read_first>

<action>
Create internal/tui/permission.go:

1. handlePermissionRequest(msg PermissionRequestMsg) (tea.Model, tea.Cmd)
   - Save current screen as previousScreen
   - Set screen to ScreenPermission
   - Create PermissionModal with request data
   - Start timer
   - Return modal cmd

2. handlePermissionResponse() (tea.Model, tea.Cmd)
   - Send PermissionResponse to dispatcher
   - Restore previousScreen
   - Dequeue next pending request if any
   - Return nil
</action>

<acceptance_criteria>
- PermissionRequestMsg shows modal
- Modal displays correct tool/command/risk
- User decision sends PermissionResponse
- Previous screen restored after decision
- Queue processes next request
</acceptance_criteria>

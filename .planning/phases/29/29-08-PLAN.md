### Task 3: SettingsModel

<read_first>
- internal/tui/types.go
- internal/tui/theme/theme.go
- internal/config/types.go — Config
</read_first>

<action>
Create settings_model.go, settings_view.go, settings_tabs.go, settings_edit.go:

SettingsModel struct:
- config *config.Config
- configPath string
- tabs []string (General, Provider, Model, Permissions, Features, Ledger)
- selectedTab int
- selectedIndex int
- editing bool
- editValue string
- dirty bool
- width, height int
- theme *theme.Theme

Tabs:
- General: theme, compact mode, token usage, cost estimate
- Provider: default, auto fallback, API keys (masked)
- Model: default model, context threshold, thinking, arbitrage
- Permissions: default mode, timeout, rules
- Features: auto backup, resume, cache TTL
- Ledger: enabled, max entries

Key bindings:
- tab/shift+tab: cycle tabs
- up/down: navigate items
- enter: edit selected item
- Esc: close or cancel edit
- s: save (if dirty)

View:
- Two-column layout: tabs left, settings right
- Tab bar at top
- Settings items with labels and values
- API keys masked as "••••••••"
- Unsaved changes indicator
</action>

<acceptance_criteria>
- Settings shows 6 tabs
- All config fields editable
- API keys masked
- Save writes to config.toml
- Unsaved changes warning
</acceptance_criteria>

# Plan 29-07: Workflow Screens

## Objective

Implement the 5 workflow phase screens: Plan (task review), Execute (task progress), Verify (results), Ship (summary), Discuss (Q&A).

## Tasks

### Task 1: PlanModel + PlanView

<read_first>
- internal/tui/types.go
- internal/tui/theme/theme.go
- internal/types/types.go — Task, TaskStatus
</read_first>

<action>
Create plan_model.go and plan_view.go:

PlanModel struct:
- tasks []types.Task
- selectedIndex int
- cost float64
- durationMs int64
- model string
- provider string
- showDiff bool
- diffContent string
- width, height int
- theme *theme.Theme

Methods:
- NewPlanModel(tasks, cost, duration, model, provider, theme)
- Update(msg) (tea.Model, tea.Cmd)
- View() string

Key bindings:
- a: accept plan → emit AppMsg{Screen: ScreenExecute}
- e: edit plan (placeholder)
- r: retry plan generation
- d: toggle diff preview
- Tab: toggle dependency graph view
- up/down: navigate task list

View:
- Left: task list with status indicators [ ]/[/]/[x]
- Right: cost estimate, estimated time, active model
- Bottom: key hints
</action>

<acceptance_criteria>
- PlanModel initializes with tasks
- View shows task list with status
- Cost/time displayed correctly
- A key transitions to Execute screen
- D key toggles diff preview
</acceptance_criteria>

# Plan 29-09: Utility Screens 2

## Objective

Implement Diff, Rollback, Ledger, and Metrics screens.

## Tasks

### Task 1: DiffModel

<read_first>
- internal/tui/types.go
- internal/tui/theme/theme.go
</read_first>

<action>
Create diff_model.go and diff_view.go:

DiffModel struct:
- content string
- files []DiffFile
- selectedIndex int
- scrollOffset int
- width, height int
- theme *theme.Theme

DiffFile struct:
- Path string
- Status string (added, modified, deleted)
- Diff string

Key bindings:
- up/down: navigate files
- pgup/pgdown: scroll diff
- Esc: close

View:
- File list on left
- Diff content on right with syntax highlighting
- Line numbers
- Additions green, deletions red, hunks brand color
</action>

<acceptance_criteria>
- DiffModel shows file list
- Diff content rendered with colors
- Navigation works
- Esc closes
</acceptance_criteria>

### Task 2: RollbackModel

<read_first>
- internal/tui/types.go
- internal/tui/theme/theme.go
- pkg/rollback/ — Rollback, RollbackEntry
</read_first>

<action>
Create rollback.go:

RollbackModel struct:
- entries []RollbackEntry
- selectedIndex int
- showDiff bool
- diffContent string
- confirmHard bool
- width, height int
- theme *theme.Theme

Key bindings:
- enter: soft rollback (with confirmation)
- d: toggle diff preview
- shift+d: hard rollback (with double confirmation)
- up/down: navigate commits

View:
- Commit list with [HEAD] marker
- Selected commit detail
- Diff preview when showDiff=true
- Confirmation overlay for hard rollback
</action>

<acceptance_criteria>
- RollbackModel lists commits
- HEAD marked correctly
- Enter does soft rollback
- Shift+D does hard rollback with confirmation
- Diff preview works
</acceptance_criteria>

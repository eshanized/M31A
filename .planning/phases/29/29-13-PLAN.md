# Plan 29-13: Reusable Components

## Objective

Implement all reusable TUI components.

## Tasks

### Task 1: ToolCard

<read_first>
- internal/tui/theme/theme.go
- internal/tui/constants.go
- internal/types/types.go — RiskLevel
</read_first>

<action>
Create components/toolcard.go:

ToolCardState: ToolCardRunning, ToolCardSuccess, ToolCardError

ToolCard struct:
- ToolName string
- Input string
- Output string
- State ToolCardState
- Duration time.Duration
- RiskLevel types.RiskLevel
- Error string

Methods:
- Render(theme) string
- SetOutput(output string)
- SetError(err string)
- Complete()
- SanitizeOutput(maxChars int) string

View:
- Tool label badge (colored by tool name)
- Command/input
- Output (collapsed if >20 lines)
- Status badge: [..] running → [OK] success → [ERR] error
</action>

<acceptance_criteria>
- ToolCard renders with correct state
- Output truncated at 20 lines
- Status badges cycle correctly
- Risk level colors correct
</acceptance_criteria>

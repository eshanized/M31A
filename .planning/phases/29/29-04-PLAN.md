# Plan 29-04: REPL Screen

## Objective

Implement the main chat interface: textarea input, scrollable message history, streaming content/thinking blocks, tool cards, slash autocomplete, and welcome screen.

## must_haves

- ReplModel struct with all required fields
- Textarea input with placeholder, character count
- Scrollable viewport for message history
- Progressive streaming: content appended token-by-token
- Thinking blocks: collapsible, duration counter, toggle with T key
- Tool cards: running/success/error states
- Welcome screen with logo, provider cards, quick actions
- Slash autocomplete dropdown
- Key bindings: enter (submit), up/down (history), ctrl+u (clear), tab (autocomplete), pgup/pgdown (scroll), ctrl+c (cancel stream)

### Task 3: Create repl_keys.go

<read_first>
- internal/tui/repl_model.go
- bubbletea — tea.KeyMsg, tea.KeyType
</read_first>

<action>
Create internal/tui/repl_keys.go:

1. handleKeyMsg(msg tea.KeyMsg) (tea.Model, tea.Cmd)
   - enter: submit message or execute slash command
   - up/down: navigate command history
   - ctrl+u: clear input
   - tab: autocomplete selected slash suggestion
   - escape: close slash suggestions
   - pgup/pgdown: scroll viewport
   - ctrl+d: scroll down half page
   - other: forward to textarea

2. handleStreamingKeyMsg(msg tea.KeyMsg) (tea.Model, tea.Cmd)
   - ctrl+c: cancel active stream
   - t: toggle thinking block visibility
   - other: ignored during streaming

3. submitMessage() (tea.Model, tea.Cmd)
   - Get textarea value
   - If starts with "/": parse as slash command, emit SlashCommandMsg
   - Otherwise: add user message to history, return message for LLM
   - Clear textarea
   - Reset history index

4. navigateHistory(direction int) (tea.Model, tea.Cmd)
   - direction +1 = up (older), -1 = down (newer)
   - Clamp to history bounds
   - Set textarea value to history entry
</action>

<acceptance_criteria>
- Enter submits message or executes slash command
- Up/down navigates command history
- Ctrl+U clears textarea
- Tab autocompletes slash suggestion
- Escape closes slash suggestions
- PgUp/PgDn scrolls viewport
- Ctrl+C cancels stream during streaming
- T key toggles thinking during streaming
- History navigation wraps correctly
</acceptance_criteria>

### Task 4: Create repl_stream.go

<read_first>
- internal/tui/repl_model.go
- internal/tui/types.go — StreamMsg, StreamDoneMsg, StreamErrorMsg
- internal/types/types.go — StreamChunk
</read_first>

<action>
Create internal/tui/repl_stream.go:

1. handleStreamMsg(msg StreamMsg) (tea.Model, tea.Cmd)
   - switch msg.Chunk.Type:
     - "content": append delta to active message content
     - "thinking": open/extend thinking block
     - "done": finalize message, extract usage
     - "tool_use": create tool card, dispatch tool call
   - Re-render viewport

2. handleStreamDone(msg StreamDoneMsg) (tea.Model, tea.Cmd)
   - Set streaming = false
   - Show input area
   - Record usage stats
   - Save session messages

3. handleStreamError(msg StreamErrorMsg) (tea.Model, tea.Cmd)
   - Set streaming = false
   - Show input area
   - Display error toast
   - Partial content preserved if any

4. startStreaming() (tea.Model, tea.Cmd)
   - Set streaming = true
   - Hide input area
   - Start spinner
   - Return StartStreamCmd

5. cancelStream() (tea.Model, tea.Cmd)
   - Cancel stream context
   - Set streaming = false
   - Show input area
   - Return nil
</action>

<acceptance_criteria>
- Content chunks append to message progressively
- Thinking chunks create/update thinking blocks
- Done chunk finalizes message with usage
- Tool use chunks create tool cards
- StreamDone shows input, records stats
- StreamError shows toast, preserves partial content
- startStreaming hides input, starts spinner
- cancelStream cancels context, shows input
</acceptance_criteria>

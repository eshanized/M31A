# Plan 29-06: AppState & Screen Routing

## Objective

Implement the root AppState model, the main Update loop, screen routing, and message dispatch. This is the central nervous system of the TUI.

## must_haves

- AppState struct with all sub-models and state
- NewApp constructor initializing all dependencies
- Init() returning batch of startup commands
- Update() routing all message types
- View() rendering active screen with chrome
- Screen routing to all 16 sub-models
- Permission handling
- Slash command routing
- Workflow message handling

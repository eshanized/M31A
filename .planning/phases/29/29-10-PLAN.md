# Plan 29-10: Slash Commands

## Objective

Implement the slash command system: registry, 30+ handlers, tab completion, and command palette.

## Tasks

### Task 1: commands.go (Registry)

<read_first>
- internal/tui/types.go
- internal/tui/theme/theme.go
</read_first>

<action>
Create commands.go:

CommandInfo struct:
- Name string
- Slash string
- Description string
- Handler CommandHandler
- RiskLevel types.RiskLevel

CommandHandler func(ctx CommandContext, args []string) (CommandResult, error)

CommandContext struct:
- Config *config.Config
- SessionManager *session.Manager
- Git *git.Git
- Ledger *ledger.Ledger
- Rollback *rollback.Rollback
- Dispatcher *tools.Dispatcher
- ClearMessages func()
- WorkDir string

CommandResult struct {
- Message string
- Screen *Screen
- Toast bool
- Error error

CommandRegistry struct:
- commands map[string]CommandInfo
- mu sync.RWMutex

Methods:
- NewCommandRegistry() *CommandRegistry
- Register(info CommandInfo)
- Execute(ctx, name, args) (CommandResult, error)
- List() []CommandInfo
- FindByPrefix(prefix string) []CommandInfo
</action>

<acceptance_criteria>
- CommandRegistry stores and retrieves commands
- Execute calls correct handler
- List returns all registered commands
- FindByPrefix filters correctly
</acceptance_criteria>

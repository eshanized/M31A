    - `"sync"`, `"time"`

    Define types and constants:

    1. `EventType` type: `type EventType string`

    2. Predefined event type constants:
       ```go
       const (
           SessionChanged      EventType = "session:changed"
           ToolExecuted        EventType = "tool:executed"
           PhaseTransitioned   EventType = "phase:transitioned"
           ModelSwitched       EventType = "model:switched"
           ProviderSwitched    EventType = "provider:switched"
           MessageAdded        EventType = "message:added"
           ContextConsolidated EventType = "context:consolidated"
       )
       ```

    3. `Event` struct:
       ```go
       type Event struct {
           Type      EventType
           Data      interface{}
           Timestamp time.Time
       }
       ```

    4. `Bus` struct with:
       - `mu sync.RWMutex` — protects subscribers map
       - `subscribers map[EventType][]chan<- Event` — event type to slice of subscriber channels
       - `closed bool` — flag to prevent publish after Close
       - `buffer int` — channel buffer size (set to 100 in New)

    5. `New()` function:
       - Returns `*Bus` with initialized map and `buffer = 100`
       ```go
       func New() *Bus {
           return &Bus{
               subscribers: make(map[EventType][]chan<- Event),
               buffer:      100,
           }
       }
       ```

    6. `func (b *Bus) Subscribe(eventType EventType, ch chan<- Event)`:
       - Lock `b.mu.Lock()`.
       - If `b.closed`, unlock and return.
       - Append `ch` to `b.subscribers[eventType]`.
       - If `eventType == "*"` (wildcard), also append to a separate `wildcard` slice or store under `"*"` key.
       - Unlock.

    7. `func (b *Bus) Publish(event Event)`:
       - Lock `b.mu.RLock()` (read lock — multiple concurrent publishers ok).
       - If `b.closed`, runlock and return.
       - Collect target channels: `channels := b.subscribers[event.Type]` plus `wildcard := b.subscribers["*"]`.
       - Unlock `b.mu.RUnlock()`.
       - For each channel in `channels` and `wildcard`:
         - Non-blocking send: `select { case ch <- event: default: }`.
         - If channel is full, drop the event (never block the publisher).

    8. `func (b *Bus) Unsubscribe(eventType EventType, ch chan<- Event)`:
       - Lock `b.mu.Lock()`.
       - Find and remove `ch` from `b.subscribers[eventType]`.
       - Remove by filtering: iterate slice, exclude matching channel.
       - If the slice becomes empty, delete the key from the map.
       - Unlock.

    9. `func (b *Bus) Close()`:
       - Lock `b.mu.Lock()`.
       - Set `b.closed = true`.
       - For each event type and its channels, close all channels.
       - Reset `b.subscribers = make(map[EventType][]chan<- Event)`.
       - Unlock.

    Implementation notes:
    - Channel buffer size of 100 is set in New(). Subscribers that don't drain will drop events but never block publishers.
    - Wildcard "*" subscription: store under key `EventType("*")` in the same map. In Publish, always include `b.subscribers["*"]` channels.
    - Use `b.mu.RLock()` in Publish for concurrent read performance.
    - Use `b.mu.Lock()` in Subscribe, Unsubscribe, Close for write safety.
    - No external dependencies — pure Go sync + time only.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Publisher → Bus → Subscriber | Events carry arbitrary Data via interface{} — type safety depends on publisher/subscriber contract |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-13-02-01 | Denial of Service | Bus publish flood | mitigate | Non-blocking publish with buffered channels; full subscriber channels drop events instead of blocking publisher |
| T-13-02-02 | Tampering | Event data injection | accept | Events carry interface{} data; subscribers must type-assert correctly. This is internal-only (no external input reaches the bus). Type safety is by convention. |
| T-13-02-03 | Spoofing | Fake event injection | accept | Bus is internal to the process; no authentication boundary exists. Any Go code with bus reference can publish. This is by design for internal decoupling. |
| T-13-02-04 | Denial of Service | Unsubscribe race | mitigate | RWMutex protects all subscriber map mutations; Close() sets closed flag checked in Publish |
| T-13-02-05 | Information Disclosure | Event data leaks | accept | Bus is in-process only; no serialization or network transport. Channel references are not externally accessible. |
</threat_model>

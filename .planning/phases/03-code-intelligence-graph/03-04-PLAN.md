DetectSCCs(graph *ImportGraph) [][]string:

3. Filter SCCs with size > 1 (single-node SCCs are not cycles)
4. Return [][]string where each inner slice is a cycle

WorkspaceRoot struct: Path string, Type string (go_work, npm_workspaces, cargo_workspace, m31a)

DetectWorkspaceRoot(startDir string) (*WorkspaceRoot, error):
1. Walk up from startDir to filesystem root
2. Check for: go.work (Type: "go_work"), package.json with "workspaces" field (Type: "npm_workspaces"), Cargo.toml with "[workspace]" section (Type: "cargo_workspace"), .m31a/ directory (Type: "m31a")
3. Return first match found
4. If none found, return nil, nil (single-repo workspace)

WorkspaceRepo struct: Path string, ModulePath string, Indexer *Indexer

Workspace struct: Root *WorkspaceRoot, Repos map[string]*WorkspaceRepo, mu sync.RWMutex

NewWorkspace(root *WorkspaceRoot) *Workspace

AddRepo(path string) error:
1. Detect module path (read go.mod for Go, package.json name for npm, Cargo.toml package.name for Rust)
2. Create Indexer for repo path
3. Build index
4. Store in Repos map

ResolveCrossRepoImport(importPath string, fromRepo string) (string, string):
1. For Go: check if importPath starts with any repo's ModulePath
2. If match, resolve to local file path within that repo
3. Return (repo path, resolved file path)

QueryAll(fn func(repo *WorkspaceRepo, indexer *Indexer) error) error:
1. Lock, iterate all repos
2. Call fn for each repo
3. Return combined errors

ImpactAll(symbol string, depth int) map[string]*ImpactResult:
1. For each repo, check if symbol is defined
2. If defined, run AnalyzeImpact in that repo
3. Also check cross-repo callers (via ResolveCrossRepoImport)
4. Return map of repo path -> ImpactResult

runIndex(args []string, workDir string, logger *slog.Logger) int:
1. flag.NewFlagSet("index", flag.ExitOnError)
2. Flags: incremental bool, progress bool
3. Create Indexer via NewIndexerWithStore(workDir, nil) (no EventStore for CLI)
4. If incremental: call BuildIncremental(ctx)
5. If not incremental: call Build(ctx) for full rebuild
6. If progress: emit JSON progress events to stdout as {"phase":"parsing","files_done":N,"total":N,"current":"path"}
7. Print summary: "Indexed N files, M symbols in Dms"
8. Return exit code 0 on success, 1 on error

Create cmd/m31a/impact.go. Per D-26 (m31a impact <symbol> [--depth N] [--format table|json|graphviz]):

runImpact(args []string, workDir string, logger *slog.Logger) int:
1. flag.NewFlagSet("impact", flag.ExitOnError)
2. Flags: depth int (default 3), format string (default "table")
3. First non-flag arg is the symbol name
4. Create Indexer, Build graph
5. Create CodeGraph, call AnalyzeImpact(graph, index, symbol, depth)
6. Format output based on --format:
   - table: "FILE:LINE  SYMBOL  RISK" columns
   - json: full ImpactResult as JSON
   - graphviz: DOT format with nodes=symbols, edges=calls, clusters=packages
7. Print to stdout
8. Return exit code 0

runArchCheck(args []string, workDir string, logger *slog.Logger) int:

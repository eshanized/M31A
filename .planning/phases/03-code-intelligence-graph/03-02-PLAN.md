Create internal/integrations/lsp/client.go. Per D-17, implement LSP client using JSON-RPC 2.0 over stdio (not HTTP).

LSPClient struct fields: cmd *exec.Cmd, stdin io.WriteCloser, stdout *bufio.Reader, stderr bytes.Buffer, mu sync.Mutex, nextID int64, workDir string, capabilities LSPCapabilities, lastUsed time.Time, closed bool

NewLSPClient(command []string, workDir string) (*LSPClient, error):
1. exec.Command(command[0], command[1:]...) with Dir set to workDir
2. cmd.StdinPipe() for stdin, cmd.StdoutPipe() for stdout
3. cmd.Stderr = &bytes.Buffer for error capture
4. cmd.Start()
5. Send "initialize" request with params: {processId: os.Getpid(), rootUri: "file://" + workDir, capabilities: {textDocument: {definition: {}, references: {}, callHierarchy: {}, typeHierarchy: {}, hover: {}}}}
6. Receive and parse initialize response
7. Send "initialized" notification
8. Negotiate capabilities from server response (see capabilities.go)
9. Return initialized LSPClient

Methods:
- Definition(file string, line, col int) ([]Location, error) — sends "textDocument/definition"
- References(file string, line, col int, includeDeclaration bool) ([]Location, error) — sends "textDocument/references"
- CallHierarchy(file string, line, col int) ([]CallHierarchyItem, error) — sends "textDocument/prepareCallHierarchy" then "callHierarchy/incomingCalls"
- TypeHierarchy(file string, line, col int) ([]TypeHierarchyItem, error) — sends "textDocument/prepareTypeHierarchy" then "typeHierarchy/supertypes"
- Hover(file string, line, col int) (*HoverInfo, error) — sends "textDocument/hover"
- Close() error — sends "shutdown" request, "exit" notification, kills process

Internal methods:
- sendRequest(method string, params interface{}) (json.RawMessage, error) — JSON-RPC 2.0 request with auto-incrementing ID
- sendNotification(method string, params interface{}) error — JSON-RPC 2.0 notification (no ID)
- recvResponse(expectedID int64) (json.RawMessage, error) — reads from stdout, matches ID
- Touch() — updates lastUsed time

Types:
- Location: URI string, Range struct { Start Position, End Position } with Line, Character int
- CallHierarchyItem: Name string, Kind string, URI string, Range Position
- TypeHierarchyItem: Name string, Kind string, URI string
- HoverInfo: Contents string

LSPPool struct: mu sync.RWMutex, clients map[string]map[string]*poolEntry, idleTTL time.Duration, logger *slog.Logger

poolEntry struct: client *LSPClient, lastUsed time.Time

NewLSPPool(idleTTL time.Duration, logger *slog.Logger) *LSPPool — default idleTTL to 5*time.Minute

GetClient(projectRoot, language string) (*LSPClient, error):
1. RLock, check clients[projectRoot][language], if found and not idle, Touch() and return
2. RUnlock, start new client via startClient
3. Lock, store in pool, return

startClient(projectRoot, language string) (*LSPClient, error):
1. ServerConfigForLanguage(language) to get command
2. Check if binary exists in PATH via exec.LookPath
3. If not found, return error with clear message: "language server %s not found in PATH — install %s for semantic analysis"
4. NewLSPClient(config.Command, projectRoot)
5. Return client

ShutdownIdle():
1. Lock, iterate all clients
2. If time.Since(entry.lastUsed) > idleTTL, call client.Close(), remove from map

ShutdownAll():
1. Lock, close all clients, clear map

func (p *LSPPool) Stats() PoolStats — returns counts of active connections per language

LSPManager struct: pool *LSPPool, configs map[string]ServerConfig, logger *slog.Logger, mu sync.Mutex, projectRoot string

NewLSPManager(projectRoot string, logger *slog.Logger) *LSPManager:
1. Create LSPPool with 5-min idle TTL
2. Load default server configs from servers.go
3. Return configured manager

EnsureStarted(ctx context.Context, language string) error:
1. Check if language is in configs — if not, return nil (no LSP for this language)
2. Check if binary exists via exec.LookPath — if not, log warning and return nil (graceful degradation)
3. pool.GetClient(projectRoot, language)
4. If error, log warning and return nil (graceful degradation, not fatal)
5. Return nil

SemanticQuery(ctx context.Context, language string, fn func(*LSPClient) error) error:
1. EnsureStarted for language
2. GetClient from pool
3. Call fn with the client
4. If client returns error indicating crash (e.g., broken pipe, process exited), attempt restart:
   a. Close the crashed client
   b. Remove from pool
   c. Create new client via pool.GetClient
   d. Retry fn once
5. Return result

StartIdleReaper(ctx context.Context, interval time.Duration):
1. Goroutine that calls pool.ShutdownIdle() at interval
2. Respects ctx cancellation
3. Default interval: 1 minute

Shutdown():
1. pool.ShutdownAll()

Helper: LanguageForFile(path string) (string, bool) — delegates to FindLanguageForFile from servers.go

The manager does NOT own the Indexer or CodeGraph — it is a standalone service that the Indexer can use for on-demand semantic queries. The Indexer calls manager.SemanticQuery("go", func(client) { ... }) when it needs definitions or references that Tree-sitter cannot provide.

Purpose: The REPL screen is permanently broken because SwitchTo() only sets activeID inside the registered-screen guard. When called during Init before Register(), activeID stays at 0 (ScreenFirstRun), which breaks Register()'s auto-activate guard for every subsequent screen.

**Step 1: Fix router.go (per D-01)**

Move `r.activeID = id` outside the `if s, ok := r.screens[id]` guard in `SwitchTo()`. The corrected method body becomes:

```go
func (r *Router) SwitchTo(id ScreenID) {
    if id == 0 {
        return
    }
    r.activeID = id
    if s, ok := r.screens[id]; ok {
        r.active = s
        if r.active != nil {
            r.active.SetDimensions(r.width, r.height)
            r.active.SetTheme(r.theme)
        }
    }
}
```

Do NOT touch any other method in router.go. Do NOT modify Register(), View(), SetTheme(), SetDimensions(), or ActiveID(). Do NOT touch app_nav.go (per D-04).

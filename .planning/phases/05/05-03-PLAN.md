    var state StateData
    scanner := bufio.NewScanner(strings.NewReader(content))
    for scanner.Scan() {
        line := strings.TrimSpace(scanner.Text())
        if line == "" || strings.HasPrefix(line, "#") { continue }
        switch {
        case strings.HasPrefix(line, "**Phase:**"):
            state.Phase = strings.TrimSpace(line[len("**Phase:**"):])
        ...
        }
    }
    return state
}

    Create `pkg/session/planning.go` in `package session`:
    - Imports: `"bufio"`, `"fmt"`, `"os"`, `"path/filepath"`, `"strings"`, `"time"`, `"github.com/eshanized/M31A/internal/types"`

    **PROJECT.md writer/parser:**

    `func (m *Manager) SaveProject(sessionID string, project *types.ProjectState) error`:
    - Write Markdown in format:
      ```
      # Project

      **Goal:** <goal>
      **Type:** <project_type>
      **Framework:** <framework>

      ## Questions

      - **Q:** <question> → **A:** <answer>
      ```
    - Iterate over `project.Answers` map to generate Q&A lines
    - If Answers is empty, omit the Questions section entirely
    - Path: `filepath.Join(m.basePathFor(sessionID), "planning", "PROJECT.md")`
    - Use atomicWrite

    `func (m *Manager) LoadProject(sessionID string) (*types.ProjectState, error)`:
    - Read file, if os.IsNotExist return nil (graceful degradation — no error for missing)
    - Parse via bufio.Scanner line-by-line:
      - `"**Goal:**"` prefix → `goal`
      - `"**Type:**"` prefix → `projectType`
      - `"**Framework:**"` prefix → `framework`
      - `"- **Q:**"` prefix → parse Q&A pairs: split on `→`, extract question and answer
    - Return `&types.ProjectState{Goal, ProjectType, Framework, Answers}`
    - Tolerate extra whitespace, blank lines, missing sections, missing file

    **TASKS.md writer/parser:**

    `func (m *Manager) SaveTasks(sessionID string, tasks []types.Task) error`:
    - Write Markdown table:
      ```
      # Tasks

      | ID | Action | Description | Deps | Status | Files |
      |----|--------|-------------|------|--------|-------|
      | 1 | Add | Create main.go | - | done | main.go |
      ```
    - Use `fmt.Sprintf` for each row. ID as int, Action as string, Description as string, Deps as comma-separated or "-", Status as string, Files as comma-separated.

    `func (m *Manager) LoadTasks(sessionID string) ([]types.Task, error)`:
    - Read file, if os.IsNotExist return empty slice (graceful degradation)
    - Skip header line, separator line (contains "|---|---|---|---|---|---|")
    - Parse each row: split on `|`, extract fields
    - Parse ID as int, Deps comma-separated as []int, Files comma-separated as []string
    - Status maps to TaskStatus string constant
    - Tolerate extra whitespace, blank lines, missing file

    **STATE.md writer/parser:**

    `func (m *Manager) SaveState(sessionID string, phase types.WorkflowPhase, progress, lastAction string) error`:
    - Write Markdown:
      ```
      # State

      **Phase:** <phase>
      **Progress:** <progress>
      **Last Action:** <lastAction>
      **Timestamp:** <RFC3339>
      ```

    `func (m *Manager) LoadState(sessionID string) (phase types.WorkflowPhase, progress, lastAction string, timestamp time.Time, err error)`:
    - Read file, if os.IsNotExist return empty values (no error)
    - Parse via bufio.Scanner:
      - `"**Phase:**"` → phase
      - `"**Progress:**"` → progress
      - `"**Last Action:**"` → lastAction
      - `"**Timestamp:**"` → parse with `time.Parse(time.RFC3339, value)`
    - Map phase to types.WorkflowPhase (types.PhaseIdle if not recognized)
    - Tolerate extra whitespace, blank lines, missing fields, missing file

    All parsers:
    - Use `bufio.Scanner` (not regex)
    - Skip blank lines and lines starting with "#" or "|---"
    - Use `strings.TrimSpace` on values
    - Use `strings.TrimPrefix` or `strings.HasPrefix` for field detection
    - Never return error for missing optional sections
  </action>

      - Append new checkpoint
      - If len > 2, keep only last 2 (trim oldest)

      - Read checkpoint.json
      - If os.IsNotExist, return empty slice (no error)
      - Unmarshal into `[]Checkpoint`, return

    - `func (m *Manager) LatestCheckpoint(sessionID string) (*Checkpoint, error)`:
      - Call LoadCheckpoints
      - If empty, return nil, m31errors.ErrCheckpointNotFound
      - Return `&checkpoints[len(checkpoints)-1]` (last item = latest)

    Use `encoding/json` for serialization. All writes via atomicWrite.

    Create `internal/config/loader.go` in existing `package config`:
    - Imports: `"fmt"`, `"os"`, `"path/filepath"`, `"strings"`, `"github.com/BurntSushi/toml"`, `"github.com/eshanized/M31A/pkg/keychain"`

    **Functions:**

    1. `func DefaultConfig() *Config`:
       - Return `&Config{}` with zero-valued fields (all TOML tags handle omitempty naturally)
       - No defaults beyond zero values (first-run flow creates config with user choices)
       - Do NOT create any files

    2. `func Load(path string) (*Config, error)`:
       - If `M31A_CONFIG` env var is set and non-empty, use it as path
       - Call `toml.DecodeFile(path, &cfg)`
       - If `os.IsNotExist(err)`, return `DefaultConfig()` with nil error (missing config file is not an error — first-run flow handles creation)
       - Apply env var overrides AFTER TOML parsing:
         - `M31A_THEME` → overrides `cfg.UI.Theme`
         - `M31A_DEFAULT_MODEL` → overrides `cfg.Model.Default`
       - Return config pointer
       - `M31A_CONFIG` variable: if set, path argument is ignored; use env var value as path

    3. `func (c *Config) Save(path string) error`:
       - If `M31A_CONFIG` env var is set, use that as path (same override as Load)
       - Marshal config to TOML bytes via `toml.Marshal(c)`
       - Use atomic write: generate temp path in same directory, write, `os.Rename` (follow same pattern as `pkg/session/atomicWrite`)
       - Ensure parent directory exists via `os.MkdirAll(filepath.Dir(path), 0755)`
       - Return nil on success

    4. `func (c *Config) ResolveAPIKeys(kc keychain.Keychain) error`:
       - Resolution order: env var → keychain → config file field
       - For OpenRouter:
         - Check `M31A_OPENROUTER_API_KEY` env var → if set, use it (skip keychain and config file)
         - If not in env var, try keychain: `kc.Get("openrouter")` → if success, use it
         - If keychain returns ErrKeyNotFound or ErrKeychainUnavailable, fall back to `c.Provider.OpenRouter.APIKey` (already loaded from config file)
       - For Zen:
         - Check `M31A_ZEN_API_KEY` env var
         - Then keychain: `kc.Get("zen")`
         - Then `c.Provider.Zen.APIKey`
       - Store resolved key in `c.Provider.OpenRouter.APIKey` / `c.Provider.Zen.APIKey`
       - Never return error for missing keys (just leave them empty — first-run or settings screen handles key input)
       - Log resolution source (env var vs keychain vs config file) — use `fmt.Printf` or structured log

    Use `fmt.Errorf` for error wrapping. Ensure `filepath` is used for path manipulation.
  </action>

    Create `internal/tokens/` directory and `internal/tokens/estimator.go`:
    - Package: `package tokens`
    - Imports: `"fmt"`, `"github.com/pkoukk/tiktoken-go"`, `"github.com/charmbracelet/lipgloss"`

    `Estimator` struct:
    ```go
    type Estimator struct {
        modelID   string
        tokenizer *tiktoken.Tiktoken // nil if model unsupported
        emaAlpha  float64
        emaFactor float64 // calibration factor, starts at 1.0
    }
    ```

    **Fields:**
    - `modelID`: model identifier string (e.g., "gpt-4o", "claude-3-sonnet", "deepseek/deepseek-r1")
    - `tokenizer`: nil if model not in tiktoken-go's map
    - `emaAlpha`: EMA smoothing factor (default 0.3)
    - `emaFactor`: running calibration factor (initial 1.0)

    **Constructor:**
    `func NewEstimator(modelID string) *Estimator`:
    - Try `tiktoken.EncodingForModel(modelID)`
    - If err != nil, tokenizer remains nil (fallback mode)
    - If success, store tokenizer
    - emaAlpha = 0.3, emaFactor = 1.0

    **Methods:**

    1. `func (e *Estimator) Estimate(text string) int`:
       - If tokenizer != nil: `len(e.tokenizer.Encode(text, nil, nil))`
       - Else fallback: `int(float64(len([]rune(text))) / 4 * 1.3)` — use rune count, not byte count, per multibyte character handling
       - Apply emaFactor: `int(float64(estimated) * e.emaFactor)`
       - Never return error for unsupported models

    2. `func (e *Estimator) Calibrate(estimated, actual int)`:
       - If estimated <= 0, return (avoid division by zero)
       - `ratio := float64(actual) / float64(estimated)`
       - `e.emaFactor = e.emaAlpha*ratio + (1-e.emaAlpha)*e.emaFactor`
       - Clamp emaFactor to [0.1, 10.0] range to prevent extreme values

    3. `func (e *Estimator) FormatUsage(used int, total int64) string`:
       - If total <= 0: return `"-- / --"`
       - Return `fmt.Sprintf("%d / %d (%d%%)", used, total, percent)` where percent = `used * 100 / total`

    4. `func (e *Estimator) ContextWarningBanner(used int, total int64, threshold float64) string`:
       - If total <= 0, return ""
       - ratio := float64(used) / float64(total)
       - If ratio < threshold, return ""
       - Return styled warning string using lipgloss:
         - Background lipgloss.Color("#FDD663"), foreground black
         - Content: `"⚠ Context at XX% — consider using /compress"`
       - Use lipgloss.NewStyle().Background().Foreground().Render()
       - Return empty string if below threshold

    5. `func (e *Estimator) ModelID() string`:
       - Return e.modelID

    Define `const DefaultWarningThreshold = 0.80` at package level.

    Use `tiktoken.EncodingForModel` import path: `github.com/pkoukk/tiktoken-go`. This is the canonical import per AGENTS.md.
  </action>

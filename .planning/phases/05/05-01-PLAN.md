    - `Delete(service string)`: Same structure.
    - Import `"github.com/godbus/dbus/v5"`.
    - D-Bus Secret Service paths: `secretServiceName = "org.freedesktop.secrets"`, `secretServicePath = "/org/freedesktop/secrets"`.
    - Validate service name: `m31a/[a-z]+` regex pattern (prevent command injection in pass CLI fallback).

    Create `pkg/keychain/keychain_darwin.go` with `//go:build darwin` build tag:
    - `type macOSKeychain struct{}`
    - `func init() { newFunc = newmacOSKeychain }`
    - `func newmacOSKeychain() (Keychain, error) { return &macOSKeychain{}, nil }`
    - `const accountName = "m31a"` (used with -a flag)
    - `Get(service string)`: `exec.Command("/usr/bin/security", "find-generic-password", "-s", servicePrefix+service, "-wa", accountName).Output()`. Use `-w` flag (not `-g`) to get only password value. Check output for "could not be found" to return ErrKeyNotFound.
    - `Set(service, value string)`: `exec.Command("/usr/bin/security", "add-generic-password", "-U", "-s", servicePrefix+service, "-a", accountName, "-w", value).Run()`. The `-U` flag updates if item already exists.
    - `Delete(service string)`: `exec.Command("/usr/bin/security", "delete-generic-password", "-s", servicePrefix+service, "-a", accountName).CombinedOutput()`. Check output for "could not be found".
    - Validate service name to prevent injection (alphanumeric only after `m31a/`).
    - Do NOT use `zalando/go-keyring` — per RESEARCH.md analysis, it wraps the same CLI with incompatible API.

    Both files: ensure service name validation rejects non-alphanumeric characters in the `service` parameter (after stripping `m31a/` prefix). Return `ErrKeyNotFound` for get/delete on missing entries.

| M31A ↔ OS Keychain | API key data crosses from M31A process to OS-level secret storage |
| M31A ↔ pass CLI | API key data exposed as argument to pass subprocess |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-01 | Information Disclosure | Config file via keychain fallback | mitigate | Resolution order: env var → keychain → config file; config file api_key is last resort |
| T-05-02 | Tampering | Service name CLI injection (darwin/linux pass) | mitigate | Validate service name as `m31a/[a-z]+` before passing to any CLI; reject non-alphanumeric chars |
| T-05-03 | Spoofing | New() returns wrong platform impl | accept | Build tags guarantee correct compilation per platform; cross-compile build matrix verifies |
</threat_model>

    ```go
    type SettingsModel struct {
        config     *config.Config
        theme      theme.Theme
        activeTab  int      // 0=General, 1=Provider, 2=Permissions, 3=Features
        width      int
        height     int
        keychain   keychain.Keychain
        storeInKC  bool     // toggle for "store keys in keychain"
        dirty      bool     // true if changes unsaved
        statusMsg  string   // confirmation/error message
    }
    ```

    **Constructor:**
    `func NewSettingsModel(cfg *config.Config, t theme.Theme, kc keychain.Keychain) *SettingsModel`

    **Tabs:**
    - Tab 0 "General": Theme (string), CompactMode (bool), ShowTokenUsage (bool), MaxIterations (int)
    - Tab 1 "Provider": Default (string), AutoFallback (bool), OpenRouter API key (masked), Zen API key (masked), "Store in keychain" toggle
    - Tab 2 "Permissions": DefaultMode (string), TimeoutSeconds (int)
    - Tab 3 "Features": AutodreamEnabled (bool), SubagentEnabled (bool), AutoBackup (bool), ResumeOnStartup (bool)

    **Update method:**
    `func (m *SettingsModel) Update(msg tea.Msg) ([]tea.Cmd, *AppMsg)`:
    - `tea.WindowSizeMsg`: store width/height
    - `tea.KeyMsg`:
      - `"tab"`: cycle activeTab: `m.activeTab = (m.activeTab + 1) % 4`
      - `"shift+tab"`: reverse cycle: `m.activeTab = (m.activeTab + 3) % 4`
      - `"enter"`: save config:
        - If keychain != nil and storeInKC:
          - Call m.keychain.Set("openrouter", m.config.Provider.OpenRouter.APIKey) (if not empty)
          - Call m.keychain.Set("zen", m.config.Provider.Zen.APIKey) (if not empty)
        - Call m.config.Save() (with M31A_CONFIG or default path)
        - Set dirty=false, statusMsg="Config saved"
        - Return `&AppMsg{Screen: ScreenREPL}`
      - `"esc"`: discard changes, return to REPL
      - Field editing: handle up/down arrow for cycling bool options, text input for string fields

    **View:**
    `func (m *SettingsModel) View() string`:
    - Render tab headers (active tab highlighted with brand color)
    - Render tab content based on activeTab
    - Use lipgloss.JoinHorizontal for tab bar
    - Use lipgloss.JoinVertical for content
    - API key fields: show `"••••••••"` if key is non-empty, `"(empty)"` otherwise (actual value stored in config struct, never displayed in plaintext)
    - Footer: "Tab/Shift+Tab: cycle tabs | Enter: save | Esc: discard"

    **Helper:**
    `func (m *SettingsModel) Save() error` — calls Save on config, optionally stores to keychain. Can be called directly by AppState on /save command.

    Boolean rendering: use `"[x]"` / `"[ ]"` pattern with lipgloss styling. String fields show current value inline.

    Key architecture: The model holds a pointer to `*config.Config`. Mutations happen in-place via Update. Save writes the mutated config to disk.

    **ResumeModel struct:**
    ```go
    type ResumeModel struct {
        list       list.Model
        manager    *session.Manager
        theme      theme.Theme
        width      int
        height     int
        confirmDel bool          // awaiting delete confirmation
        delTarget  string        // session ID to delete
    }
    ```

    **Constructor:**
    `func NewResumeModel(t theme.Theme, mgr *session.Manager) *ResumeModel`:
    - Call `mgr.ListSessions()` to populate initial items
    - Create `list.New(items, list.NewDefaultDelegate(), 0, 0)`
    - Set title to "Sessions"
    - Disable status bar: `l.SetShowStatusBar(false)`
    - Return model

    **Refresh method:**
    `func (m *ResumeModel) Refresh() error`:
    - Call `m.manager.ListSessions()` to re-populate items
    - Update `m.list.SetItems(items)`

    **Update method:**
    `func (m *ResumeModel) Update(msg tea.Msg) ([]tea.Cmd, *AppMsg)`:
    - `tea.WindowSizeMsg`:
      - Store width/height
      - Set list size: `m.list.SetSize(msg.Width-margin, msg.Height-margin)`
    - `tea.KeyMsg`:
      - If in delete confirmation mode:
        - `"y"`, `"Y"`, `"enter"`: call `m.manager.DeleteSession(m.delTarget)`, refresh list, exit confirm mode
        - `"n"`, `"N"`, `"esc"`: exit confirm mode without deleting
      - Else (normal browsing):
        - `"enter"`: get `SelectedItem().(sessionItem)`, return `&AppMsg{Screen: ScreenREPL, SessionID: item.id}`
        - `"n"`, `"N"`: return `&AppMsg{Screen: ScreenFirstRun}` (new session)
        - `"d"`, `"D"`: enter delete confirmation mode (`m.confirmDel = true`, store item.id)
        - `"esc"`: return `&AppMsg{Screen: ScreenREPL}` (back to REPL)
    - Pass message to `m.list.Update(msg)` for list navigation
    - Return `([]tea.Cmd{cmd}, nil)` where cmd is from list.Update

    **View method:**
    `func (m *ResumeModel) View() string`:
    - If in delete confirmation:
      - Render centered overlay: `"Delete session <ID>? (Y/N)"` using lipgloss.Place
    - Otherwise:
      - Render `m.list.View()` with proper height/width
      - Render footer hint: "Enter: resume | N: new | D: delete | Esc: back"

    **Custom delegate (optional):** Use `list.NewDefaultDelegate()` for initial implementation. Can customize colors:
    - Selected item: brand background + white text
    - Normal item: surface background + primary text
    - Corrupted badge: red "[!]" prefix

    Corrupted sessions: when creating sessionItem, if `info.Corrupted`, set title to `fmt.Sprintf("%s [!]", info.ID)`.

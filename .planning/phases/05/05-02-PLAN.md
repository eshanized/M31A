    Append to `pkg/session/manager.go`:

    1. `func (m *Manager) NewSession(model, provider string) (*Session, error)`:
       - Generate 8-byte ID via `crypto/rand.Read()`, hex-encode to 16-char (actually 8 bytes = 16 hex chars, but requirement says 8-char hex. Let me re-read CONTEXT.md: "Session ID: 8-char hex via crypto/rand". So read 4 bytes = 8 hex chars.)
       - Actually: `crypto/rand` produces bytes; 4 bytes → 8 hex chars. Use `make([]byte, 4)`, then `hex.EncodeToString(idBytes)` produces 8 chars.
       - Check if directory `basePathFor(id)` already exists → retry on collision (in practice astronomically unlikely but handle it)
       - Call `ensureDir(basePathFor(id))`
       - Create session via `NewSession(id, model, provider)`
       - Write `session.json` via atomicWrite with `json.Marshal(session)`
       - Create `planning/` subdirectory via `ensureDir(filepath.Join(basePathFor(id), "planning"))`
       - Return session pointer

    2. `func (m *Manager) LoadSession(id string) (*Session, error)`:
       - Build `basePathFor(id)`
       - Read `session.json` via `os.ReadFile`, `json.Unmarshal` into Session
       - Read `messages.json` into `s.Messages` (if file exists, skip if not found — graceful degradation)
       - Return session, nil. If session.json missing, return nil, ErrSessionCorrupted (from m31errors).
       - Set `s.MessageCount = len(s.Messages)` after loading

    3. `func (m *Manager) ListSessions() ([]SessionInfo, error)`:
       - Read directory entries in `baseDir`
       - For each entry that is a directory (not "archived"):
         - Try to read `session.json` inside
         - If succeeds, parse into SessionInfo (read json into SessionInfo directly)
         - If fails (missing, corrupt), append SessionInfo{ID: name, Corrupted: true}
       - Sort by `LastModified` descending (use `sort.Slice`)
       - Return `[]SessionInfo`
       - For LastModified, use the directory's ModTime via `os.Stat` on session.json

    4. `func (m *Manager) DeleteSession(id string) error`:
       - `os.RemoveAll(basePathFor(id))`
       - Return nil

    5. `func (m *Manager) ArchiveSession(id string) error`:
       - Ensure `filepath.Join(baseDir, "archived")` exists
       - `os.Rename(basePathFor(id), filepath.Join(baseDir, "archived", id))`
       - Return nil. If session doesn't exist, return error from os.Rename.

    6. `func (m *Manager) SaveSession(s *Session) error`:
       - Marshal session to JSON, call atomicWrite on `session.json` path
       - Also save messages: marshal `s.Messages`, atomicWrite on `messages.json` path

    Path layout:
    - session.json: `baseDir/id/session.json`
    - messages.json: `baseDir/id/messages.json`
    - planning/: `baseDir/id/planning/`

    All writes use the atomicWrite helper. Never use os.WriteFile for state files.
  </action>

# Plan 26-06 — Minor Polish: Sidebar Width, Frecent History, Permission Queue

## Objective

Address three minor polish items: make sidebar width configurable, make frecent history max size configurable, and add protection against permission queue overflow.

## read_first

- `internal/tui/sidebar.go` — `defaultSidebarWidth = 120` constant
- `internal/tui/commands_file.go` — frecent file history
- `internal/tui/commands_git.go` — frecent git history
- `internal/tools/permissions.go` — permission request queue
- `internal/config/types.go` — Config struct, UIConfig
- `internal/tui/app.go` — AppState struct, config usage

## action

1. Add to `UIConfig` in `internal/config/types.go`:
   ```go
   type UIConfig struct {
       // ... existing fields ...
       SidebarWidth int `toml:"sidebar_width"`
   }
   ```

2. Set default in `config.go` defaults:

       return &Config{

### Fix MIN-03: Permission Queue Overflow Protection

1. In `internal/tools/permissions.go`, add a buffer check before sending to the permission channel:
   ```go
   func (pm *PermissionManager) RequestPermission(req PermissionRequest) (PermissionResponse, error) {
       select {
       case pm.requests <- req:
           // Sent successfully
       default:
           // Queue is full — deny by default
           return PermissionResponse{Allowed: false}, errors.New("permission queue full")
       }
       
       // Wait for response
       select {
       case resp := <-pm.responses:
           return resp, nil
       case <-time.After(pm.timeout):
           return PermissionResponse{Allowed: false}, errors.New("permission timeout")
       }
   }
   ```

2. Add a configurable queue size (default 10):
   ```go
   type PermissionManager struct {
       // ... existing fields ...
       queueSize int
   }
   
   func NewPermissionManager(timeout time.Duration, queueSize int) *PermissionManager {
       if queueSize <= 0 {
           queueSize = 10
       }
       return &PermissionManager{
           requests:  make(chan PermissionRequest, queueSize),
           responses: make(chan PermissionResponse),
           timeout:   timeout,
           queueSize: queueSize,
       }
   }
   ```

3. Add warning log when queue is full:
   ```go
   default:
       log.Warn("permission queue full, denying request", "tool", req.ToolName)
       return PermissionResponse{Allowed: false}, errors.New("permission queue full")
   ```

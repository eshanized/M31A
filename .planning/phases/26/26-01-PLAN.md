# Plan 26-01 — ScreenLedger Implementation

## Objective

Implement `ScreenLedger` (enum value 11) as a fully functional screen that displays the cross-session learning journal (`~/.m31a/LEDGER.md`). The screen provides a filterable list of past sessions with aggregate statistics, triggered by the `/ledger` slash command.

## read_first

- `internal/tui/types.go` — Screen enum (ScreenLedger = 11), AppMsg, all message types
- `internal/tui/app_view.go` — View() switch statement, screen routing pattern
- `internal/tui/app_update.go` — Update() screen dispatch, SlashCommandMsg handling
- `internal/tui/resume.go` — Reference implementation for list-based screen (bubbles/list pattern)
- `internal/tui/settings.go` — Reference for tabbed screen layout
- `pkg/ledger/ledger.go` — Ledger, Entry, Stats, Query types and methods
- `internal/tui/theme/theme.go` — Theme struct for consistent styling
- `internal/tui/commands_session.go` — Where `/ledger` command is registered

## action

### 1. Create `internal/tui/ledger.go`

Create a new file implementing `LedgerModel` with the following structure:

```go
type LedgerModel struct {
    theme       theme.Theme
    width       int
    height      int
    list        list.Model          // bubbles/list for session entries
    stats       *ledger.Stats       // aggregate stats
    entries     []ledger.Entry      // all ledger entries
    filtered    []ledger.Entry      // after filter applied
    filter      string              // current filter text
    searchInput textinput.Model     // search/filter input
    showStats   bool                // toggle stats panel
    sessionMgr  *session.Manager    // for loading session details
    ledger      *ledger.Ledger      // for reading LEDGER.md
    loaded      bool
    errMsg      string
}
```

### 2. Implement methods

- `NewLedgerModel(t theme.Theme, ledger *ledger.Ledger, sessionMgr *session.Manager) *LedgerModel` — constructor with non-zero width/height
- `LoadEntries()` — parse LEDGER.md via `ledger.List()`, populate entries, compute stats via `ledger.Stats()`
- `Init() tea.Cmd` — return nil (no spinner needed)
- `Update(msg tea.Msg) ([]tea.Cmd, *AppMsg)` — handle WindowSizeMsg, KeyMsg (Esc=back, s=toggle stats, /=focus search, j/k=nav, enter=select), Spinner.TickMsg, textinput.FocusMsg
- `View() string` — render: header with brand + "/ledger" title, stats panel (if toggled), list of entries with model/provider/date/cost badges, filter input at bottom

### 3. Wire into app_view.go

Add case in `View()` switch:
```go
case ScreenLedger:
    if m.ledgerModel != nil {
        return m.ledgerModel.View()
    }
    return lipgloss.Place(m.width, m.height, lipgloss.Center, lipgloss.Center, "Loading ledger...")
```

### 4. Wire into app_update.go

Add case in `Update()` screen switch (after ScreenMetrics):
```go
case ScreenLedger:
    cmds := []tea.Cmd{permissionListenerCmd(m.shutdownCtx, m.dispatcher), questionListenerCmd(m.shutdownCtx, m.dispatcher)}
    if m.ledgerModel != nil {
        subCmds, appMsg := m.ledgerModel.Update(msg)
        if appMsg != nil {
            m.screen = appMsg.Screen
        }
        cmds = append(cmds, subCmds...)
    }
    return m, tea.Batch(cmds...)
```

### 5. Wire `/ledger` command

In `commands_session.go`, update `handleLedger` to:
```go
func handleLedger(ctx CommandContext) CommandResult {
    if ctx.Ledger == nil {
        return CommandResult{Message: "Ledger not available"}
    }
    screen := ScreenLedger
    return CommandResult{
        Screen: &screen,
        Message: "Opening ledger...",
    }
}
```

### 6. Lazy-init ledgerModel

In `app_update.go` where `ScreenLedger` is set, lazy-init:
```go
if *result.Screen == ScreenLedger {
    if m.ledgerModel == nil {
        m.ledgerModel = NewLedgerModel(m.themeManager.Current(), m.ledger, m.sessionManager)
    }
    m.ledgerModel.width = m.width
    m.ledgerModel.height = m.height
    m.ledgerModel.LoadEntries()
}
```

### 7. Add AppState field

In `app.go`, add to AppState struct:
```go
ledgerModel *LedgerModel
```

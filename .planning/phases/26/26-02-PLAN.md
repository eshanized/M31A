# Plan 26-02 — ScreenRollback Implementation

## Objective

Implement `ScreenRollback` (enum value 12) as a screen that displays the session's git commit history with `[HEAD]` marker, allows viewing diffs per commit, and supports soft/hard rollback with backup branch creation. Triggered by the `/rollback` slash command.

## read_first

- `internal/tui/types.go` — Screen enum (ScreenRollback = 12), AppMsg, DiffScreenMsg
- `internal/tui/app_view.go` — View() switch statement
- `internal/tui/app_update.go` — Update() screen dispatch
- `internal/tui/diff.go` — DiffModel for viewing diffs (reusable)
- `internal/tui/plan.go` — Reference for split-pane layout with list + detail
- `pkg/rollback/rollback.go` — Rollback, SessionCommits, SoftReset, HardReset types
- `internal/git/git.go` — Git operations (Log, Diff, Reset)
- `internal/tui/theme/theme.go` — Theme struct for consistent styling
- `internal/tui/commands_git.go` — Where `/rollback` command is registered

## action

### 1. Create `internal/tui/rollback.go`

Create a new file implementing `RollbackModel`:

```go
type RollbackModel struct {
    theme       theme.Theme
    width       int
    height      int
    commits     []git.CommitInfo  // session commits from git log
    selected    int               // currently selected commit index
    showDiff    bool              // diff preview toggle
    diffContent string            // diff for selected commit
    confirming  bool              // rollback confirmation dialog
    confirmType string            // "soft" or "hard"
    git         *git.Git
    rollback    *rollback.Rollback
    sessionID   string
}
```

### 2. Implement methods

- `NewRollbackModel(t theme.Theme, g *git.Git, rb *rollback.Rollback, width, height int) *RollbackModel`
- `LoadCommits(sessionStartHash string) error` — call `rb.SessionCommits(sessionStartHash)` to populate commit list
- `Init() tea.Cmd` — return nil
- `Update(msg tea.Msg) ([]tea.Cmd, *AppMsg)` — handle WindowSizeMsg, KeyMsg:
  - `j/k` or arrows: navigate commit list
  - `Enter`: start rollback (show confirmation)
  - `d`: toggle diff preview for selected commit
  - `Esc`: close (return to previous screen)
  - `y/Enter` during confirmation: execute rollback
  - `n/Esc` during confirmation: cancel
- `View() string` — render: header with "Rollback" title, commit list with `[HEAD]` marker on first entry, diff preview pane (if toggled), confirmation dialog (when active)

### 3. Wire into app_view.go

```go
case ScreenRollback:
    if m.rollbackModel != nil {
        return m.rollbackModel.View()
    }
    return lipgloss.Place(m.width, m.height, lipgloss.Center, lipgloss.Center, "Loading rollback...")
```

### 4. Wire into app_update.go

```go
case ScreenRollback:
    cmds := []tea.Cmd{permissionListenerCmd(m.shutdownCtx, m.dispatcher), questionListenerCmd(m.shutdownCtx, m.dispatcher)}
    if m.rollbackModel != nil {
        subCmds, appMsg := m.rollbackModel.Update(msg)
        if appMsg != nil {
            m.screen = appMsg.Screen
        }
        cmds = append(cmds, subCmds...)
    }
    return m, tea.Batch(cmds...)
```

### 5. Wire `/rollback` command

In `commands_git.go`, update `handleRollback` to:
```go
func handleRollback(ctx CommandContext) CommandResult {
    if ctx.Rollback == nil || ctx.Git == nil {
        return CommandResult{Message: "Rollback not available"}
    }
    screen := ScreenRollback
    return CommandResult{
        Screen: &screen,
        Message: "Opening rollback...",
    }
}
```

### 6. Implement rollback actions

In `RollbackModel.Update()`:
- **Soft rollback**: Call `rb.SoftReset(selectedCommit.Hash)`, update task statuses to `StatusPending`, return to REPL with toast
- **Hard rollback**: Create backup branch `m31a/rollback-backup-<timestamp>`, call `rb.HardReset(selectedCommit.Hash)`, return to REPL with toast
- **Diff preview**: Call `git.Diff(selectedCommit.Hash + "^.." + selectedCommit.Hash)` and display in diff pane

### 7. Add AppState field

```go
rollbackModel *RollbackModel
```

## acceptance_criteria

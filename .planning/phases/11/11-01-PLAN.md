    Add two new methods to `pkg/session/manager.go` in `package session`:

    **1. `func (m *Manager) ForkSession(parentID string) (*Session, error)`**

    Logic (per D-02):
    - Load the parent session via `m.LoadSession(parentID)`. If error, return nil, error.
    - Generate a new 8-char session ID via `generateID()` with collision retry loop (follow existing `NewSession` pattern: max 10 attempts).
    - Create the new session directory via `m.ensureDir(m.basePathFor(newID))`.
    - Create the new `Session` struct:
      - `NewSession(newID, parent.Model, parent.Provider)` for base fields.
      - Set `ParentID = parentID` on the new session's `types.Session` (embedded).
      - Copy `parent.Messages` into new session's Messages (slice copy: `append([]types.Message{}, parent.Messages...)`).
      - Set `MessageCount = len(newSession.Messages)`.
      - Copy `parent.Project` if non-nil (deep copy: marshal/unmarshal or struct literal copy).
    - Update parent session's `ChildrenIDs`: append `newID` if not already present.
    - Save both sessions via `m.SaveSession(newSession)` and `m.SaveSession(parent)`.
    - Return newSession, nil.

    Import note: `"encoding/json"` is already imported for the deep copy of ProjectState.

    **2. `func (m *Manager) SiblingSessions(sessionID string) ([]SessionInfo, int, error)`**

    Returns all child sessions of the parent (siblings of the given session), plus the index of the given session within that list.

    Logic:
    - Load the current session via `m.LoadSession(sessionID)`. If error, return nil, -1, error.
    - If `current.ParentID == ""` (root session), return nil, -1, nil (no siblings — root has none).
    - Load the parent session via `m.LoadSession(current.ParentID)`. If error, return nil, -1, error.
    - Collect `SessionInfo` for each child ID in `parent.ChildrenIDs`:
      - For each childID, try `m.LoadSession(childID)`.
      - On success, construct `SessionInfo{ID, Model, Provider, StartedAt, MessageCount}`.
      - On failure (corrupt/deleted), skip that child.
    - Find the index of `sessionID` within the parent's `ChildrenIDs` list.
    - Return `(sessions, index, nil)`.

    **3. Helper: `func (m *Manager) ListChildren(parentID string) ([]SessionInfo, error)`**

    Convenience method:
    - Load parent session. If error, return nil, error.
    - For each ID in `parent.ChildrenIDs`, load and construct SessionInfo (same as sibling logic).
    - Return collected SessionInfo slice.

    Keep all new methods free of `slog` or TUI concerns — they are pure session management.

        mgr, dir := newTestManager(t)

        // Create parent
        parent, err := mgr.NewSession("gpt-4o", "openrouter")
        if err != nil { t.Fatalf("NewSession failed: %v", err) }
    
        // Add a message
        parent.Messages = append(parent.Messages, types.Message{
            Role: "user", Content: "Hello", CreatedAt: time.Now(),

        if err := mgr.SaveSession(parent); err != nil {
            t.Fatalf("SaveSession failed: %v", err)
        }
    
        // Fork
        child, err := mgr.ForkSession(parent.ID)
        if err != nil { t.Fatalf("ForkSession failed: %v", err) }
    
        // Verify child
        if child.ParentID != parent.ID {
            t.Errorf("Expected ParentID=%s, got %s", parent.ID, child.ParentID)
        }
        if len(child.Messages) != 1 {

            t.Errorf("Expected copied message content 'Hello', got %q", child.Messages[0].Content)

        // Verify parent ChildrenIDs updated

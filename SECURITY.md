# Reporting Security Issues

To report a security vulnerability in M31A, please open a private security
advisory on GitHub:

- **GitHub Security Advisories:**
  [https://github.com/eshanized/M31A/security/advisories](https://github.com/eshanized/M31A/security/advisories)

Please include steps to reproduce, affected versions, and any relevant logs or
environment details (with credentials redacted).

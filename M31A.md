# M31A Project Context

M31A is an open-source AI coding agent in the terminal powered by **NVIDIA NIM**
models. It is designed to be terminal-first, extensible, and safe by default.

## Project Overview

- **Purpose:** Provide a terminal coding interface with file/shell/search tools,
  MCP integration, workspace policies, skills, and session persistence.
- **Main Technologies:**
  - **Runtime:** Node.js (>=20.0.0)
  - **Language:** TypeScript
  - **UI Framework:** React (using Ink for CLI rendering)
  - **Testing:** Vitest
  - **Bundling:** esbuild
  - **Linting/Formatting:** ESLint, Prettier
- **Architecture:** Monorepo structure using npm workspaces.
  - `packages/cli`: Terminal UI (`m31a`), command parsing, ACP server, and
    interactive state.
  - `packages/core`: Core agent loop, NVIDIA NIM client, prompt construction,
    tools, policies, and services.
  - `packages/genai`: Structural request/response types bridged to NVIDIA NIM.
  - `packages/devtools`: Integrated developer tools (Network/Console inspector).
  - `packages/test-utils`: Shared test utilities and test rig.

## Building and Running

- **Install Dependencies:** `npm install`
- **Build Packages & Bundle:** `npm run build`
- **Run in Development:** `npm run start`
- **Run in Debug Mode:** `npm run debug`
- **Bundle Project:** `npm run bundle`
- **Clean Artifacts:** `npm run clean`

## Testing and Quality

- **Unit Tests:** `npm run test`
- **Workspace-Specific Tests:**
  `npm test -w @m31a/core -- src/routing/modelRouterService.test.ts`
- **Integration Tests (E2E):** `npm run test:e2e`
- **Individual Checks:** `npm run lint` / `npm run format` / `npm run typecheck`
- **Full Validation:** `npm run preflight`

## Development Conventions

- **Contributions:** Follow `CONTRIBUTING.md`.
- **Commit Messages:** Follow
  [Conventional Commits](https://www.conventionalcommits.org/).
- **Imports:** Keep imports scoped within each workspace package (enforced by
  ESLint).
- **License Headers:** Keep required source file headers intact (enforced by
  ESLint).

## Testing Conventions

- **Environment Variables:** Stub with `vi.stubEnv('NAME', 'value')` in
  `beforeEach` and restore with `vi.unstubAllEnvs()` in `afterEach`.

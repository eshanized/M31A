# `m31a-git-attribution`

Git commit trailer builder, provenance tracking, and AI co-authorship metadata synthesizer for **M31A**.

---

## Overview

`m31a-git-attribution` standardizes provenance tracking for code authored or modified by M31A agents. It synthesizes `Co-authored-by` Git commit trailers, records session thread identifiers, and logs model IDs in accordance with Git conventions.

---

## User-Facing Capabilities

- **Transparent AI Attribution**: Commits generated by M31A include attribution trailers:
  ```git
  Co-authored-by: M31A Assistant <assistant@m31a.tonmoyinfrastructure.org>
  M31A-Model: nvidia/nemotron-3.5-lightning-30b-a3b
  M31A-Session: 019483ab-41c3-7a20-b3e1-2384784918ef
  ```
- **CLI Attribution Inspection (`m31a attribution`)**: Inspects repository history for AI-assisted contributions.

---

## Developer Guide & Architecture

### Key Types

- `CommitTrailerBuilder`: Fluent builder configuring agent name, email, session ID, model slug, and custom trailer key-value pairs.
- Integrates with `git2` to read and format repository commit objects.

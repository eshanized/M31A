# `m31a-elicitation`

Interactive user preference elicitation, clarifying questions, and tool approval models for **M31A**.

---

## Overview

`m31a-elicitation` manages human-in-the-loop interactions. When an autonomous agent encounters ambiguous requirements, multiple competing architectural choices, or requires human authorization for mutating shell commands, this crate coordinates the question-answer flow and approval states.

---

## User-Facing Capabilities

- **Interactive Question Dialogs**: Presents multiple-choice questions or free-form prompts generated by the model before proceeding with critical changes.
- **Approval Dialogs**: Prompts users to `Allow`, `Allow Always`, `Deny`, or `Edit` mutating commands.

---

## Developer Guide & Architecture

### Key Modules

- [`approval`](src/approval.rs): `ApprovalState`, `ApprovalDecision` (Allow, AllowAlways, Deny, EditCommand), and `ApprovalKind`.
- [`questions`](src/questions.rs): `QuestionItem` containing question prompt, options, multi-select flag, and user response captures.

# M31A Roadmap

M31A is an open-source, MIT-licensed terminal coding agent built around **NVIDIA
NIM** backends and local developer workflows.

## Guiding Principles

- **Fast & Capable:** First-class support for NVIDIA NIM coding & reasoning
  models with configurable thinking levels and context limits.
- **Extensible:** Built-in tools, MCP servers, hooks, skills, and ACP
  integration.
- **Safe by Default:** Workspace trust controls, policy rules, and sandboxing.
- **Open Source:** Community contributions are tracked on GitHub at
  [github.com/eshanized/M31A](https://github.com/eshanized/M31A).

## Focus Areas

- **Providers & Auth:** Streamlined NVIDIA NIM API key auth and
  OpenAI-compatible protocol mapping.
- **Core Runtime:** Refining the OpenAI-compatible runtime, context compaction,
  tool execution, and streaming reliability.
- **User Experience:** Polished TUI (`m31a`), command palette, session
  search/resume, and clear documentation.
- **Tooling & MCP:** Reliable file editing, ripgrep search, shell execution, and
  MCP compatibility.
- **Quality & CI:** Lean workspace builds, cross-platform tests, and fast
  verification.

# Follow-Up Questions

You are generating follow-up questions after the initial discuss phase.
Some questions were skipped or answered incompletely.

## Rules

- Generate **at most 2** follow-up questions
- Focus ONLY on the areas listed as "not yet covered"
- Questions must be specific and actionable — not yes/no
- Number them starting from 1
- Include a suggested default answer after an em-dash
- Do NOT repeat any of the original questions

## Format

```
1. What specific question? — Suggested default answer.
2. Another specific question? — Another suggested default.
```

If all important areas are already covered, write: "No follow-ups needed."

# M31A Core Tools Reference

This document provides a complete catalog of all 28 core tools available in the M31 Autonomous (M31A) runtime, their parameter schemas, execution risks, and canonical error taxonomy.

## Tool Execution Architecture

Every model-proposed tool call executes through a protected lifecycle:
1. **Schema Validation**: Arguments are validated against JSON schema contracts generated by `schemars`.
2. **Policy Evaluation**: The `PolicyGate` evaluates tool identifier, target paths, and arguments.
3. **Budget Pre-allocation**: Required tokens and steps are reserved before invocation.
4. **Execution & Confinement**: The tool executes within OS sandboxes and streaming byte limits.
5. **Output Redaction & Quota**: Secrets are redacted and oversized streams are stored in the artifact store.

## Canonical Tool Error Taxonomy

Tools return strongly typed errors categorized into standard classifications (`ToolError`):

| Category | Description | Typical Remediation |
|:---|:---|:---|
| **`Validation`** | Malformed arguments, missing required fields, or type errors. | Model refines JSON payload structure. |
| **`ResourceNotFound`** | Specified file, path, branch, or artifact does not exist. | Model queries directory structure with `list_files` or `glob`. |
| **`PreconditionFailed`** | Target file was modified concurrently or git worktree is dirty. | Model refreshes state and resolves drift. |
| **`PermissionDenied`** | Target path is outside workspace root or blocked by policy veto. | Model requests alternative path or asks operator. |
| **`ExecutionFailed`** | Subprocess returned a non-zero exit code (e.g. test failure). | Model inspects stderr and diagnoses failure cause. |
| **`ResourceExhausted`** | Output bytes exceeded artifact quota or timeout expired. | Model chunks output or limits scope. |
| **`CapabilityUnavailable`** | Required system provider (e.g. Docker, network) is not installed. | Model adapts strategy to available capabilities. |

## Catalog of 28 Core Tools

### 1. Filesystem Tools (7)

| Tool ID | Parameters | Risk Class | Description |
|:---|:---|:---|:---|
| **`read_file`** | `path: String`, `offset: Option<u64>`, `limit: Option<u64>` | ReadOnly | Reads file content within the workspace root with optional byte pagination. |
| **`write_file`** | `path: String`, `content: String`, `create_parents: bool` | WorkspaceMutation | Overwrites or creates a new file at the specified workspace path. |
| **`edit_file`** | `path: String`, `edits: Vec<TextEdit>` | WorkspaceMutation | Applies targeted line/range substitutions to an existing file. |
| **`apply_patch`** | `patch: String`, `strip: Option<u32>` | WorkspaceMutation | Applies a unified diff patch (`git diff` format) to workspace files. |
| **`list_files`** | `path: Option<String>`, `recursive: bool` | ReadOnly | Lists entries in a workspace directory with file size and type attributes. |
| **`glob`** | `pattern: String`, `base_path: Option<String>` | ReadOnly | Finds workspace files matching a glob pattern (e.g. `src/**/*.rs`). |
| **`grep`** | `query: String`, `path: Option<String>`, `case_insensitive: bool` | ReadOnly | Searches file contents using regular expressions or literal strings. |

### 2. Repository Intelligence Tools (3)

| Tool ID | Parameters | Risk Class | Description |

### 3. Process & Background Job Tools (5)

| Tool ID | Parameters | Risk Class | Description |
|:---|:---|:---|:---|

| **`start_job`** | `command: String`, `args: Vec<String>`, `env: HashMap<String, String>` | HighRiskMutation | Launches an asynchronous background job with streaming spool output. |
| **`job_status`** | `job_id: String` | ReadOnly | Inspects current status (`Running`, `Completed`, `Failed`) of a background job. |
| **`job_output`** | `job_id: String`, `offset: Option<u64>`, `limit: Option<u64>` | ReadOnly | Reads streaming stdout/stderr output from a running or completed job. |
| **`job_stop`** | `job_id: String`, `force: bool` | HighRiskMutation | Sends `SIGTERM` / `SIGKILL` to a background job process tree. |

### 4. Git Version Control Tools (8)

| Tool ID | Parameters | Risk Class | Description |
|:---|:---|:---|:---|
| **`git_status`** | *None* | ReadOnly | Returns clean/dirty state, staged changes, and untracked files. |
| **`git_diff`** | `staged: bool`, `commit: Option<String>` | ReadOnly | Computes unified diff of working tree changes or specific commits. |
| **`git_log`** | `limit: Option<usize>`, `revision: Option<String>` | ReadOnly | Retrieves commit history with hashes, author info, and trailer blocks. |
| **`git_show`** | `object: String` | ReadOnly | Shows detailed commit metadata, commit message, and full patch diff. |

| **`git_checkout`** | `target: String`, `create: bool` | WorkspaceMutation | Checks out a branch or reverts specified files to HEAD revision. |
| **`git_add`** | `paths: Vec<String>` | WorkspaceMutation | Stages specified file modifications or untracked files for commit. |
| **`git_commit`** | `message: String`, `trailers: Option<HashMap<String, String>>` | WorkspaceMutation | Creates a new Git commit with RFC-compliant M31A attribution trailers. |
